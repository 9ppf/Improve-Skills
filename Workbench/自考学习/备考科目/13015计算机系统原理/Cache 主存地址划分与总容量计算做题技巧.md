# Cache 主存地址划分与总容量计算做题技巧

## 零、 概念辨析（极易混淆，必须理清）

在看地址划分前，先搞清这三个名词的对应关系，不要混淆：

1. **Tag = 标记位** ✅ 
   - 完全同一个东西。用来区分“虽然映射到了同一个组，但到底是不是我要的那个主存块”。
2. **索引（Index） ≠ 整个 Cache** ❌
   - 索引是**地址字段**，它的作用是“指路”，告诉 CPU 去 Cache 的哪一组找数据。
   - 准确说：索引 = **Cache 的组号（或行号）**。
3. **块内地址 = 偏移（Offset）** ✅
   - 完全同一个东西。用来选中一个块（Block）里面的具体哪个字节。

**💡 用“旅馆找房间”打个比方（强烈建议记住）：**
- **索引（组索引） = 楼层号**：先根据地址里的索引，确定去 Cache 的哪一层（哪一组）。
- **Tag（标记位） = 房间号**：到了那一层，对比 Tag，看是不是你要找的那个房间（主存块）。
- **偏移（块内地址） = 床铺号**：进了房间，根据偏移找到具体的哪个字节（哪张床）。

## 一、 核心规律：主存地址分几部分？

主存地址的划分完全由**“组索引（Index）”是否存在**决定。

- **有索引（3部分）**：直接映射、N路组相联映射。
- **无索引（2部分）**：全相联映射。

**为什么全相联没有索引？**
全相联映射意味着主存中任何一块都可以放入 Cache 的任何一行，整个 Cache 只有 1 个组（组数 = 1）。组索引的作用是“选择第几组”，现在只有 1 组，不需要选，所以索引位数为 \(\log_2(1) = 0\) 位，字段自然消失。

**结论规律：**
1. 题目说 **“直接映射”** -> 肯定有组索引，地址分 **3部分** (Tag + 索引 + 偏移)。
2. 题目说 **“N路组相联”** -> 肯定有组索引（只要组数>1），地址分 **3部分** (Tag + 索引 + 偏移)。
3. 题目说 **“全相联映射”** -> 没有组索引，地址分 **2部分** (Tag + 偏移)。

## 二、 万能解题流程（“切蛋糕”法）

拿到题目，按以下顺序依次计算：

### 第一步：算主存地址总位数
- **公式**：主存地址总位数 = \(\log_2(主存容量)\)
- **注意**：题目若给的是 MB/GB，先化成 \(2^n\) B，指数 n 就是总位数。

### 第二步：切最低位（块内偏移）
- **公式**：块内偏移位数 = \(\log_2(块大小)\)
- **位置**：地址最低位，\(A_{n-1} \sim A_0\)

### 第三步：算 Cache 行数
- **公式**：Cache 行数 = Cache 数据区容量 ÷ 块大小
- **注意**：如果题目给的是“Cache容量”，这里默认是“数据区容量”。

### 第四步：算组数，决定有没有“索引”
- **全相联**：组数 = 1（没有索引，跳到第五步）
- **直接映射**：组数 = 行数（有索引）
- **N路组相联**：组数 = 行数 ÷ N（有索引）

### 第五步：切中间位（组索引）
- **公式**：组索引位数 = \(\log_2(组数)\)（全相联直接算 0）
- **位置**：紧挨在块内偏移的上面，\(A_{m+n-1} \sim A_{n}\)

### 第六步：切最高位（Tag）
- **公式**：Tag位数 = 总位数 - 索引位数 - 偏移位数
- **位置**：地址最高位，剩下全部给 Tag。

### 第七步：写格式
- **有索引**：`[Tag] + [组索引] + [块内偏移]`
- **无索引**：`[Tag] + [块内偏移]`

## 三、 Cache 总容量计算方法

Cache 总容量 = **数据区容量** + **行附加信息** + **LRU替换位**

### 1. 数据区容量（位）
- **公式**：数据区容量 × 8
- **注意**：单位是位（bit），不要漏乘 8。

### 2. 行附加信息（每行）
- **Tag**：前面算出的 Tag 位数
- **有效位（Valid）**：默认都有，**1 位**
- **脏位（Dirty）**：**写回策略**才有，**1 位**（写直达没有）
- **公式**：每行附加位 = Tag + 有效位 + 脏位
- **总行附加**：Cache 行数 × 每行附加位

### 3. LRU 替换位（按组算，不按行算）
- **直接映射**：不需要 LRU 位（0 位）
- **全相联**：1 组，LRU 位数 = \(\log_2(路数)\)
- **N路组相联**：LRU 位数 = 组数 × \(\log_2(路数)\)
- **注意**：4 路组相联，每组需要 \(\log_2(4) = 2\) 位。

### 4. 最终总容量公式
\[
Cache总容量 = 数据区位数 + (行数 \times 每行附加位) + LRU位数
\]

---

## 四、 避坑指南（易错点）

1. **按字节编址**：默认 1B = 8 位，地址位数算出来后，容量算“位”时一定要乘 8。
2. **块内偏移只看块大小**：不要用 Cache 容量去算偏移。
3. **组索引看组数**：不是看行数！只有直接映射时组数才等于行数。
4. **写回策略才有脏位**：题目若没提写策略，默认写回（有时默认写直达，看题目习惯）。
5. **LRU 位按组算**：4 路组相联每组 2 位，共有多少组就乘多少。
6. **Cache 数据区容量 ≠ Cache 总容量**：总容量必须加 Tag、有效位、脏位、LRU 位。

## 五、 例题速查

| 题目条件 | 主存地址部分数 | 地址格式 |
| :--- | :---: | :--- |
| 直接映射 | 3 部分 | Tag + 索引 + 偏移 |
| 4路组相联 | 3 部分 | Tag + 索引 + 偏移 |
| 全相联映射 | 2 部分 | Tag + 偏移 |

**示例：4路组相联，64MB主存，4KB Cache，64B块**
- 总位数：\(\log_2(64MB) = 26\) 位
- 偏移：\(\log_2(64B) = 6\) 位
- 行数：4KB / 64B = 64 行
- 组数：64 / 4 = 16 组
- 索引：\(\log_2(16) = 4\) 位
- Tag：26 - 4 - 6 = 16 位
- 地址格式：`Tag(16) | 索引(4) | 偏移(6)`
