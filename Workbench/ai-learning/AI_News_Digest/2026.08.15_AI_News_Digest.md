## 二、行业趋势

- **Agent 赛道进入规模化落地前夜**：OpenAI Agent API 公测（持久记忆 + 工具调用 + 多步规划，$0.003/步）、Meta AI Agent 框架开发者装机量突破 1000 万并设立 5 亿美元生态基金、Cloudflare+Stripe 上线首个无人工干预全链路商用 Agent。[$TRAE_REF](https://juejin.cn/post/7649312912218751027)
- **MCP 成为 Agent 生态“统一接口”**：MCP（Model Context Protocol）被视作解决工具互联孤岛的统一交互标准，类比编程领域的 LSP，2026 年在 Agent 生态中的标准化趋势明显。[$TRAE_REF](https://www.nowcoder.com/discuss/890950190642847744?urlSource=home-api)
- **多模态 RAG 进入系统化阶段**：华科、复旦等团队发布全模态 RAG 综述，覆盖文本/图像/音频/视频/3D 等所有模态组合；GraphRAG + Multi-Agent + 多模态集成平台登上 Nature Scientific Reports，多跳 QA 相对提升 46%。[$TRAE_REF](https://juejin.cn/post/7649312912218751027)
- **开源模型继续改写竞争规则**：DeepSeek V4 Flash 登顶斯坦福 HELM 基准全项第一并开源，周调用量达 3.69 万亿 Token；国家超算互联网 AI 社区已汇聚 1700 余款开源大模型。[$TRAE_REF](https://juejin.cn/post/7649312912218751027)[$TRAE_REF](https://tech.ifeng.com/c/8vbfO0XDVh0)
- **AI 编程工具整合升温**：SpaceX 以 600 亿美元全股票收购 Cursor 母公司 Anysphere；a16z 合伙人 Martin Casado 宣布离开 Cursor 董事会加入 SpaceX。[$TRAE_REF](https://m.36kr.com/p/3856591177618690)[$TRAE_REF](https://www.infoq.cn/aibriefs)

## 三、政策与补贴

- **人工智能训练师为上海 A 类重点支持工种**：五级至一级补贴标准分别为 1950、2600、3250、3900、4550 元/人；在职人员按补贴标准 80% 申领，灵活就业/失业登记等人员按 100% 申领。[$TRAE_REF](http://m.sh.bendibao.com/edu/305323.html)
- **三级证书可叠加多项红利**：三级（高级工）证书除市级补贴外，还可叠加浦东区级补贴、工会专项补贴等，最高约 6350 元；非沪籍持证者满足“人岗匹配”等条件可积 60 分居住证积分。[$TRAE_REF](http://www.ssme.sh.gov.cn/public/product!serviceDetail.do?productId=2c9e883c9dbfea22019e3a1ffb534dfc)
- **申领渠道与时限**：可通过“随申办”APP/小程序线上申请，或到各区就业促进中心线下窗口办理；补贴须在证书颁发之日起 1 年内申领（部分人员可 2 年）。[$TRAE_REF](http://m.sh.bendibao.com/edu/306222.html)
- **嘉定区线下办理点**：嘉定区就业促进中心，地址嘉新公路 88 号，联系电话 69989086（09:00-17:00）。[$TRAE_REF](http://m.sh.bendibao.com/edu/306222.html)
