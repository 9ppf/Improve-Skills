# 腾讯云轻量服务器部署指南 — 此刻便是春天工作台

## 一、前期准备

### 1.1 购买服务器

1. 打开 [腾讯云轻量应用服务器](https://cloud.tencent.com/product/lighthouse)
2. 点击 **立即选购**
3. 配置选择：

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| 地域 | 上海 / 广州 / 北京 | 选离你近的，国内访问速度差不多 |
| 镜像 | 系统镜像 → **Ubuntu 22.04 LTS** | 不要选 Windows，Linux 跑服务器更稳 |
| 套餐 | 2核2G（最便宜的） | 完全够用，内存占用 < 500MB |
| 购买时长 | 1个月 | 先试试，好用再续 |
| 带宽 | 3Mbps 或 4Mbps | 默认就行，刷题够用 |

4. 支付：微信 / 支付宝 / 储蓄卡都支持

### 1.2 获取登录信息

购买完成后，在 [腾讯云控制台](https://console.cloud.tencent.com/lighthouse) 找到你的服务器：

1. 记下 **公网 IP**（例如 `1.2.3.4`）
2. 点击服务器 → 右上角 **重置密码** → 设置一个 root 密码（复杂一点，包含大小写+数字）
3. 左侧菜单 **防火墙** → **添加规则**，开放 8000 端口：
   - 类型：自定义
   - 协议：TCP
   - 端口：8000
   - 来源：0.0.0.0/0

## 二、连接服务器

### 方式一：用腾讯云网页终端（最简单）

1. 在服务器详情页，点击右上角 **登录**
2. 选择 **标准登录方式** → 输入用户名 `root` 和你设置的密码
3. 成功进入命令行界面

### 方式二：用本地 SSH 工具（Windows PowerShell）

打开 PowerShell，输入：

```bash
ssh root@你的公网IP
# 例如：ssh root@1.2.3.4
```

输入密码即可登录。

## 三、部署步骤

登录服务器后，依次执行以下命令。每一条复制粘贴回车就行。

### 3.1 更新系统 + 安装基础工具

```bash
apt update && apt upgrade -y
apt install -y python3 python3-pip python3-venv git
```

### 3.2 创建项目目录

```bash
mkdir -p /opt/improve-skills
cd /opt/improve-skills
```

### 3.3 上传代码

**方式 A：从 GitHub 拉取（推荐，方便后续更新）**

如果你的代码在 GitHub 上：

```bash
git clone 你的GitHub仓库地址 .
# 例如：git clone https://github.com/你的用户名/Improve-Skills.git .
```

**方式 B：手动上传（如果没有 GitHub）**

在本地电脑的项目目录（`E:\self-improvement\Improve-Skills`）里，打包成 zip：

```powershell
# 在本地 PowerShell 里执行
cd E:\self-improvement\Improve-Skills
Compress-Archive -Path * -DestinationPath ..\improve-skills.zip -Force
```

然后用 scp 传到服务器（在本地 PowerShell 执行）：

```powershell
scp E:\self-improvement\improve-skills.zip root@你的公网IP:/opt/improve-skills/
```

回到服务器终端解压：

```bash
cd /opt/improve-skills
apt install -y unzip
unzip improve-skills.zip
```

### 3.4 安装 Python 依赖

```bash
cd /opt/improve-skills
pip3 install -r requirements.txt
```

### 3.5 构建项目

```bash
python3 build.py
```

看到 `Writing workbench` 字样就说明构建成功。

### 3.6 配置 DeepSeek API Key

```bash
# 编辑环境变量文件
nano /etc/improve-skills.env
```

在里面写入：

```
DEEPSEEK_API_KEY=你的DeepSeek密钥
```

按 `Ctrl+O` 保存，`Ctrl+X` 退出。

### 3.7 配置 systemd 服务（开机自启 + 崩溃自动重启）

创建服务文件：

```bash
nano /etc/systemd/system/improve-skills.service
```

写入以下内容：

```ini
[Unit]
Description=Improve Skills Workbench
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/improve-skills
EnvironmentFile=/etc/improve-skills.env
ExecStart=/usr/bin/python3 dev_server.py --no-build --no-watch
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```

保存退出，然后启动服务：

```bash
# 重新加载服务配置
systemctl daemon-reload

# 启动服务
systemctl start improve-skills

# 设置开机自启
systemctl enable improve-skills

# 查看运行状态
systemctl status improve-skills
```

看到 `active (running)` 就说明启动成功了。

## 六、安全建议

### 6.1 修改 SSH 端口（可选，提高安全性）

默认 22 端口容易被扫描，可以改成别的端口：

```bash
nano /etc/ssh/sshd_config
# 找到 #Port 22，改成 Port 你选的端口（比如 2222）
systemctl restart sshd
```

改完后防火墙也要开放新端口，并且下次登录用新端口：

```bash
ssh -p 2222 root@你的公网IP
```

### 6.2 配置防火墙

只开放必要的端口：

```bash
# 查看当前防火墙规则（腾讯云轻量用的是云防火墙，在控制台管理）
# 确保只开放了 SSH(22) 和 应用(8000)
```

### 6.3 定期更新系统

```bash
apt update && apt upgrade -y
```

## 七、常见问题

### Q: 浏览器打不开页面？

A: 检查：
1. 服务器是否运行中（腾讯云控制台看状态）
2. 防火墙是否开放了 8000 端口
3. 服务是否启动：`systemctl status improve-skills`
4. 端口是否被占用：`netstat -tlnp | grep 8000`

### Q: AI 功能用不了？

A: 检查：
1. API key 是否正确配置：`cat /etc/improve-skills.env`
2. 重启服务：`systemctl restart improve-skills`
3. DeepSeek 账户余额是否充足

### Q: 数据会丢吗？

A: 存在服务器硬盘上，只要服务器不删、硬盘不挂，就不会丢。建议每周备份一次 `data/` 目录。

### Q: 手机访问慢？

A: 腾讯云国内节点访问速度应该很快。如果慢，检查：
1. 服务器地域是否选太远了
2. 图片/照片是否太大
3. 可以考虑加 CDN 加速（一般不需要）

### Q: 想换成域名访问？

A: 买个域名（比如阿里云/腾讯云域名），解析到服务器 IP，然后可以配置 Nginx 反向代理 + HTTPS。需要的话再折腾，先用 IP 也行。
