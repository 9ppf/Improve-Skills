## 第一部分 · 选择题精练

### 第一章 计算机系统概述

**例 1** 构成冯·诺依曼结构计算机的五个基本部件是（　）
- A 寄存器，运算器，存储器，加法器，控制器
- B 运算器，控制器，存储器，输入设备，输出设备
- C 加法器，控制器，存储器，输入设备，输出设备
- D 运算器，控制器，内存，外存，打印机

> **答案：B** — 五大部件：运算器、控制器、存储器、输入设备、输出设备。

**例 2** 冯·诺依曼关于通用数字计算机的构想，其核心是二进制和（　）
- A 执行一系列指令　B 存储程序控制　C 由总线连接各个部件　D 运算器和控制器分开

> **答案：B** — 冯·诺依曼首次提出以**二进制**和**存储程序控制**为核心的通用电子数字计算机体系结构原理，奠定了当代通用电子计算机体系结构的基础。

**例 3**（填空式选择）将计算机五大部件连接起来，成为它们之间相互传递信息的公共通路，这种公共通路称为 **总线**。

**例 4** 在程序执行前，必须将程序要执行的一条指令的存储单元地址送入 **程序计数器（PC）**。

**例 5** 关于 C 语言编译过程，下列排序中正确的是（　）
- A 编译、预处理、汇编和链接
- B 预处理、汇编、编译和链接
- C 汇编、预处理、编译和链接
- D 预处理、编译、汇编和链接

> **答案：D** — 预处理 → 编译 → 汇编 → 链接。

**例 6** 反映计算机基本功能的是（　）
- A 操作系统　B 系统软件　C 指令系统　D 数据库系统

> **答案：C** — 指令集架构（ISA）或指令系统，是软件和硬件之间接口的一个完整定义。

**例 7** 以下不是用来衡量计算机基本性能的是（　）
- A 机器价格　B 机器字长　C 内存容量　D 运算速度

> **答案：A** — 价格不是衡量性能的指标。

**例 8** 下列选项中表示计算机浮点操作速度的指标是（　）
- A CPI　B MIPS　C MFLOPS　D 时钟频率

> **答案：C** — MFLOPS（每秒百万次浮点运算）。

**例 9**（　）表示执行一条指令所需的时钟周期数。
- A MIPS　B CPI　C GHz　D bp/s

> **答案：B** — CPI（Cycles Per Instruction）。

**例 10** 下列计算机系统性能评价的描述中正确的是（　）
- A 程序 MIPS 值越高，计算机的性能越高
- B 程序的 CPI 值越低，计算机的性能越高
- C 主频高的机器性能一定高
- D 同一程序在不同机器的 MIPS 不一定相同

> **答案：D** — MIPS 依赖于指令集与程序，同一程序在不同机器上 MIPS 不一定相同，不能跨机器直接比较。

### 第二章 数据的表示和运算

**例 1** 若十进制数为 133.625，则相应的十六进制数为（　）
- A 21.5　B 25.5　C 85.5　D 85.A

> **答案：D** — 133 = 85H，0.625 = 0.AH，故为 85.AH。

**例 2** 若二进制数为 1111.101，则相应的十进制数为（　）
- A 15.625　B 15.5　C 14.625　D 14.5

> **答案：A** — 按位权展开：8+4+2+1+0.5+0.125 = 15.625。

**例 3** 补码相对于原码和反码的优势是（　）
- A 直观　B 计算复杂　C 可以做乘法　D 便于减法运算

> **答案：D** — 补码可用加法实现减法（模运算系统，符号位一起参与运算）。

**例 4** 在 IEEE 754 浮点数标准中规定（　）
- A 尾数为原码，阶码为补码
- B 尾数为原码，阶码为移码
- C 尾数为补码，阶码为移码
- D 尾数为补码，阶码为补码

> **答案：B** — 尾数用原码（符号—数值），阶码用移码（偏置常数 127 / 1023）。

**例 5** 下列编码中用于汉字显示输出的编码是（　）
- A 拼音码　B 五笔字型码　C 汉字内码　D 汉字字模点阵码

> **答案：D** — 输出用字形码，即汉字字模点阵码。

**例 6** 通常是指 CPU 内部用于整数运算的数据通路的宽度是（　）
- A 字节　B 字长　C 主频　D 容量

> **答案：B** — 字长的定义。

**例 7 / 例 8**（原题重复，仅列一次）设有十六进制数 123456H，若字节存储单元地址从小到大表示为从左到右的顺序，采用**大端方式**存储的各字节存储单元内容排列顺序是（　）
- A 12H, 34H, 56H　B 34H, 12H, 56H　C 56H, 34H, 12H　D 56H, 12H, 34H

> **答案：A** — 大端方式：高位字节存低地址（LSB 从大地址开始存放）。

**例 3（章内编号）**（填空式）机器指令以什么方式提供操作数或操作数地址，称为 **寻址方式**。

### 第三章 程序的转换及机器级表示

**例 1** 一条机器指令中通常包含的信息有（　）
- A 操作码、控制码　B 操作码、立即数　C 地址码、寄存器号　D 操作码、地址码

> **答案：D** — 指令结构 = 操作码 + 地址码。

**例 2** 下列关于指令系统的说法正确的是（　）
- A RISC 指令系统比 CISC 指令系统复杂，指令条数多
- B CISC 指令系统指令周期比 RISC 指令系统指令周期短
- C RISC 指令系统中指令的长度一致
- D CISC 指令系统计算机采用硬连线控制器

> **答案：C** — RISC 特点：指令条数少、格式规整（定长指令字）、只有 Load/Store 访存、大量通用寄存器。

**例 3** 对于 CISC 指令系统，下列描述正确的是（　）
- A 指令格式规整　B 指令周期短　C 采用微程序控制　D 采用硬连线控制器

> **答案：C** — CISC 指令复杂，通常采用微程序控制（RISC 用硬连线控制器）。

**例 4** 不属于 ISA 的内容的是（　）
- A 操作数所能存放的存储空间的大小和编址方式
- B 可执行的指令的集合
- C 可以接受的操作数的类型
- D 网络传输使用的协议

> **答案：D** — 网络协议属于网络范畴，与 ISA 无关。

**例 5** 堆栈指针 SP 的内容是（　）
- A 栈顶地址　B 栈顶内容　C 栈底地址　D 栈底内容

> **答案：A** — SP 指向栈顶，BP 指向栈底。

**例 6** 下列寻址方式中，执行速度最快的是（　）
- A 寄存器寻址　B 寄存器间接寻址　C 直接寻址　D 相对寻址

> **答案：A** — 寄存器访问速度最快，无需访存。

**例 7** 机器指令以什么方式提供操作数或操作数地址，称为 **寻址方式**。

**例 8** 下列指令助记符中表示"逻辑与"的操作是（　）
- A ADD　B SUB　C AND　D OR

> **答案：C**

**例 9**（　）则是指跳转目标地址间接存储在某寄存器或存储单元中
- A 间接跳转　B 相对跳转　C 偏移跳转　D 直接跳转

> **答案：A**

**例 10** 编译的模块代码之间必须遵循一些调用接口约定，这些约定称为调用约定，由（　）定义
- A TCP/IP　B CPU　C ISA　D ABI

> **答案：D** — 调用约定（Calling Convention）由 **ABI** 规范定义。

**例 11 / 例 12**（原题重复）用于函数返回的指令的是（　）
- A CALL　B RET　C MOV　D CMP

> **答案：B** — RET 为返回指令。

**例 13** 下列数据类型，（　）型数组被分配在栈
- A static　B extern　C auto　D 以上都是

> **答案：C** — auto（自动变量）在栈中分配。

### 第四章 可执行文件的生成和加载执行

**例 1** 从一条指令的启动到下一条指令的启动的间隔时间称为（　）
- A 时钟周期　B 机器周期　C 工作周期　D 指令周期

> **答案：D**

**例 2**（　）的功能是将编译生成的汇编语言代码转换为机器语言代码
- A 预处理　B 汇编　C 链接　D 编译

> **答案：B**

**例 3** 可重定位文件中的代码区和数据区都是从地址（　）开始的
- A 0　B 0xC0000000　C 0x004d4　D 任意地址

> **答案：A**

**例 4** 下列中，用于存放代码的是（　）
- A .text　B .rodata　C .bss　D symtab

> **答案：A** — .text 存放目标代码。

**例 5** 下列中，用于存入所有未初始化或初始化为 0 的全局变量和静态变量的是（　）
- A .text　B .rodata　C .bss　D symtab

> **答案：C**

**例 6** 程序计数器是指（　）
- A 可存放指令的寄存器
- B 可存放程序状态字的寄存器
- C 本身具有计数逻辑与移位逻辑的寄存器
- D 存放下一条指令地址的寄存器

> **答案：D**

**例 7** 下列不属于包含在符号表中的符号的类型的是（　）
- A 全局符号　B 外部符号　C 本地符号　D COMMON 符号

> **答案：D** — 三种符号类型：全局、外部、本地。

**例 8** 下列属于 COMMON 类型的是（　）
- A 函数名　B 具有特定初始值的全局变量　C 未初始化全局变量　D 被初始化为 0 的全局变量

> **答案：C** — COMMON 伪节对应未初始化的全局变量。

**例 9** 下列关于动态链接库和静态链接库的优缺点描述**错误**的是（　）
- A 静态库的代码装载速度比动态库快
- B 启动使用相同动态库的多个应用程序时，动态库需要装载多次
- C 静态库被多个应用程序使用时，会被装载多次，浪费内存
- D 动态链接库可以共享，即多个应用程序可以使用同一个动态库

> **答案：B** — 多个应用使用同一动态库时，只需装入内存一次。

**例 10** 关于进程和程序的说法**不正确**的是（　）

- B 一个程序可以对应多个进程
- C 进程有生命周期
- D 一个程序只能对应一个进程

- A execve　B fork　C main　D shell

**例 13** CPU 取出并执行一条指令的时间称为（　）
- A 指令周期　B 时钟周期　C 进程周期　D 运行周期

**例 14** 下列不属于内部异常的是（　）
- A 结果溢出　B 访问超时　C 非法操作码　D I/O 操作

> **答案：D** — I/O 操作属于外部中断。

**例 15**（　）通常是在 CPU 中设置一个原因寄存器，该寄存器中有一些标识异常原因或中断类型的标志信息
- A 随机识别　B 程序识别　C 硬件识别　D 软件识别

### 第五章 程序的存储访问

**例 1** 按存储介质分类，存储器不应包括（　）
- A 半导体存储器　B 磁表面存储器　C 外存储器　D 材料存储器

> **答案：C** — 按存储介质分为半导体、磁表面、光材料存储器；"外存储器"是按**所处位置**分类。

**例 2** 在常用磁盘的各磁道中（　）
- A 最外圈磁道的位密度最大
- B 最内圈磁道的位密度最大
- C 中间磁道的位密度最大
- D 所有磁道的位密度一样大

> **答案：B** — 各磁道存储容量相同，周长越小 → 位密度越大。

**例 3** 若存储器的容量为 16KB，则访问它的地址线应有（　）
- A 4 根　B 10 根　C 14 根　D 16 根

> **答案：C** — 2^14 B = 16KB。

**例 4** CPU 可直接编程访问的存储器是（　）
- A 光盘存储器　B 虚拟存储器　C 磁盘存储器　D 主存储器

> **答案：D** — CPU 可直接访问主存，不能直接访问外存。

**例 5** 存储器的随机访问方式是指（　）
- A 可随意访问存储器
- B 按随机文件访问存储器
- C 可对存储器进行读出与写入
- D 可按地址访问存储器任一编址单元，其访问时间相同且与地址无关

> **答案：D**

**例 6** 往内存传送读/写命令，使用的是（　）
- A 数据总线　B 地址总线　C 控制总线　D 系统总线

> **答案：C** — 控制总线传送控制信息。

**例 7 / 例 8**（原题重复）下列存储器中，读取数据的速度与存储位置相关的存储器是（　）
- A 硬盘　B 高速缓存　C 主存　D ROM

> **答案：A** — 硬盘在不同盘面、磁道，存取时间不一样。

**例 9** 在一个计算机系统中，下列说法正确的是（　）
- A 主存容量远大于 Cache，主存速度比 Cache 快
- B 主存容量远小于 Cache，主存速度比 Cache 快
- C 主存容量远大于 Cache，主存速度比 Cache 慢
- D 主存容量远小于 Cache，主存速度比 Cache 慢

> **答案：C**

**例 10** 总是选择近期最少使用的主存块被替换掉的是（　）算法
- A FIFO　B LRU　C 随机替换算法　D LFU

> **答案：B** — LRU（最近最少用）。

**例 11** 在计算机的层次化存储器结构中，虚拟存储器是指（　）
- A 将主存储器当作高速缓存使用
- B 将高速缓存当作主存储器使用
- C 将辅助存储器当作主存储器使用
- D 将主存储器当作辅助存储器使用

> **答案：C**

**例 12** 下列关于页式虚拟存储器的说法，正确的是（　）
- A 页面设置很小，则主存存放页面数多，缺页频率低，换页次数少
- B 可以将整个运行的程序全部装入内存
- C 可以从逻辑上极大地扩充内存容量，并提高内存的利用率和灵活性
- D 页面大小由程序的模块划分确定

> **答案：C**

**例 13** 存储器访问，需要进行地址转换（　）
- A MMU　B CPU　C MDR　D 北桥芯片

> **答案：A** — MMU 负责地址转换。

**例 14** 虚拟地址空间分为两大部分：内核空间和（　）
- A 进程空间　B 程序空间　C 内存空间　D 用户空间

> **答案：D**

**例 15** 下列关于虚拟地址的说法正确的是（　）
- A 访问内存时实际使用的地址
- B 程序中使用的地址
- C 虚拟地址空间比物理地址空间小
- D 某个虚拟地址可能对应多个物理地址

> **答案：B**

### 第六章 程序中 I/O 操作的实现

**例 1** 下列不属于 I/O 子系统特性的是（　）
- A 共享性　B 复杂性　C 异步性　D 同步性

> **答案：D** — 三大特性：共享性、复杂性、异步性。

**例 2** 下列属于陷阱指令的是（　）
- A CMP　B INT　C RET　D CALL

> **答案：B** — 陷阱指令 `int $0x80`，执行后从用户态切换到内核态。

**例 3** I/O 硬件在操作系统（　）软件的控制下完成具体的 I/O 操作
- A C 语言空间 I/O　B 用户空间 I/O　C 运行时系统空间 I/O　D 内核空间 I/O

### 第一章 计算机系统概述

1. 计算机由 **运算器**、**控制器**、**存储器**、**输入设备** 和 **输出设备** 五个基本部件组成。
2. 存储器不仅能存放 **数据**，而且也能存放 **指令**。
3. 计算机内部以 **二进制** 形式表示 **指令和数据**。
4. 在计算机系统中，从层次结构上可以将存储器分为 **寄存器**、**高速缓存**、**主存** 和 **辅存**。
5. 存储器分为内存和外存，内存包括 **主存** 和 **高速缓存**，外存包括 **辅存** 和 **海量后备存储器**。
6. 按照在计算机上完成任务的不同，可以把使用计算机的用户分成 **系统程序员**、**应用程序员**、**最终用户**、**系统管理员** 四类。
7. 源程序文件到可执行目标文件的转换过程：**预处理阶段**、**编译阶段**、**汇编阶段** 和 **链接阶段**。
8. 机器代码与汇编表示之间可以进行转换：从汇编表示转换为机器代码的过程称为 **汇编**，从机器代码转换为汇编表示的过程称为 **反汇编**。
9. 系统总线通常由 **数据线**、**地址线** 和 **控制线** 三组线构成。
10. 通常把控制部件、运算部件和各类寄存器互联组成的电路称为 **中央处理器（CPU）**。
11. CPU 送到地址线的主存地址应先存放在 **主存地址寄存器（MAR）** 中，发送或从数据线取来的信息存放在 **主存数据寄存器（MDR）** 中。
12. **指令** 是用 0 和 1 表示的一串 0/1 序列，用来表示 CPU 完成一个特定的 **原子** 操作。
13. **汇编语言** 和 **机器语言** 都属于低级语言，它们统称为 **机器级语言**。
14. 被翻译的语言和程序分别称为 **源语言** 和 **源程序**。
15. 翻译生成的语言和程序分别称为 **目标语言** 和 **目标程序**。
16. 翻译程序有以下 3 类：**汇编程序**、**解释程序** 和 **编译程序**。
17. ISA 层下面是 **硬件** 部分，上面是 **软件** 部分。

### 第二章 数据的表示和运算

1. IEEE 754 单精度浮点数用二进制表示时，阶码长度为 **8** 位，尾数长度为 **23** 位，阶码的移码偏置常数为 **127**。
2. CPU 内部的 ALU 部件的基本功能是实现 **算术运算** 和 **逻辑运算**。
3. 在计算机系统中，常用的进位记数制有 **二进制**、**八进制**、**十进制**、**十六进制**。
4. 根据不同的控制描述方式，控制器分为 **硬连线控制器** 和 **微程序控制器**。
5. 定点数编码表示方法主要有以下 4 种：**原码**、**补码**、**反码** 和 **移码**。
6. 运算部件的组成主要由 **加法器**、**ALU** 和 **移位器** 三部分构成。
7. 将计算机五大部件连接起来，成为它们之间相互传递信息的公共通路，这种公共通路称为 **总线**。
8. 指令所处理的基本数据类型分为 **数值数据** 和 **非数值数据** 两种。
9. **逻辑值**、**字符** 等数据都是非数值数据。
10. 汉字系统必须处理以下几种汉字代码：**输入码**、**内码** 和 **字形码**。
11. 汉字的字形主要有两种描述方法：**字模点阵描述** 和 **轮廓描述**。

### 第三章 程序的转换及机器级表示

1. 使用通用寄存器来存放运算过程中所用的临时数据。指令的操作数有三种：**立即数**、**寄存器** 和 **存储单元**。
2. 按指令格式的复杂度，指令系统可分为 **CISC** 与 **RISC** 两种类型。

6. 用若干个 **助记符** 表示的与机器指令对应的指令称为 **汇编指令**。
7. 用来将汇编语言源程序中的汇编指令翻译成机器指令的程序称为 **汇编程序**，而将机器指令反过来翻译成汇编指令的程序称为 **反汇编程序**。
8. 两个专用寄存器分别是 **指令指针寄存器 EIP** 和 **标志寄存器 EFLAGS**。
9. 指令包括 **操作码** 和 **地址码**。
10. 条件标志包括 **溢出标志（OF）**、**进/借位标志（CF）**、**符号标志（SF）** 和 **零标志（ZF）**。
11. 控制标志包括 **方向标志（DF）**、**中断允许标志（IF）** 和 **陷阱标志（TF）**。

### 第四章 可执行文件的生成和加载执行

1. **.data** 节用来存入已初始化且初值不为 0 的全局变量和静态变量。

6. 打断程序正常执行的事件分为两大类：**内部异常** 和 **外部中断**。
7. ELF 目标文件的两种视图包括：**链接视图** 和 **执行视图**。

9. 包含在符号表中的符号有三种不同类型：**全局符号**、**外部符号** 和 **本地符号**。

11. 绑定属性可以是 **本地**、**全局**、**弱** 等。
12. CPU 最基本的部件是 **数据通路** 和 **控制部件**。
13. CPU 对异常和中断的响应过程可分为三个步骤：**保护断点和程序状态**、**关中断** 和 **识别异常和中断事件并转相应处理程序**。
14. 指令执行过程主要包括 **取指**、**译码**、**取数**、**运算** 和 **存结果**。
15. 打断程序正常执行的事件包括 **非法操作码、页故障、运算结果溢出或除 0 错误等** 和 **CPU 收到外部中断请求信号**。

### 第五章 程序的存储访问

1. 按信息的可更改性，将存储器分为 **读写存储器** 和 **只读存储器**。
2. 按断电后信息的可保存性，将存储器分为 **非易失性存储器** 和 **易失性存储器**。
3. 按照存取方式分类，存储器分为 **随机存取存储器**、**顺序存取存储器** 和 **直接存取存储器**。
4. 程序访问的局部性包括：**时间局部性** 和 **空间局部性**。
5. Cache 是一种高速缓冲存储器，是为了解决 CPU 和主存之间 **速度** 不匹配而采用的一项重要技术。
6. 主存与 Cache 的地址映射方式有 **直接映射**、**全相联映射** 和 **组相联映射** 三种方式。
7. 解决 cache 与主存一致性问题的 cache 写操作一般有 **通写法** 和 **回写法** 两种。
8. 磁盘存储器的平均存取时间主要包括 **寻道时间**、**旋转等待时间** 和 **数据传输时间** 三个部分。
9. 访存指令主要有两类：**取数指令** 和 **存数指令**。
10. 常用的替换算法有 **先进先出（FIFO）**、**最近最少用（LRU）**、**最不经常使用（LFU）** 和 **随机替换算法**。

### 第六章 程序中 I/O 操作的实现

1. I/O 子系统包含以下两大部分：**I/O 软件** 和 **I/O 硬件**。
2. I/O 子系统三大特性包含：**共享性**、**复杂性** 和 **异步性**。
3. 文件分成 **ASCII 文件** 和 **二进制文件** 两类。
4. 输出缓存区的属性有三种：**全缓冲**、**行缓冲** 和 **非缓冲**。
5. 常见的输入/输出传输控制方式有 **程序直接控制** 方式、**中断控制** 方式和 **DMA 控制** 方式。
6. I/O 接口是介于 **I/O 总线** 和 **外设** 之间的硬件部分。
7. 通常将 I/O 设备分成两种：**字符设备** 和 **块设备**。
8. 通常将总线分成三种：**处理器总线**、**存储器总线** 和 **I/O 总线**。
9. 对 I/O 接口中可访问的寄存器编址，其方式有 **统一编址** 和 **独立编址**。
10. I/O 接口的功能主要包括 **数据缓冲**、**错误或状态监测**、**控制和定时**、**数据格式转换**。
11. 在 Intel 处理器中将外部中断分为 **可屏蔽中断** 和 **不可屏蔽中断** 两类。
12. 程序直接控制 I/O 方式的基本思想是：直接通过 **查询程序** 来控制主机与外设的 **数据交换**。
13. 中断控制 I/O 方式的基本思想是：外设完成 I/O 操作后，向 CPU 发送一个 **中断请求信号**，CPU 检测到该信号后，则进行上下文切换，调出相应的中断服务程序执行。
14. 直接存储器访问（DMA）控制 I/O 方式使用专门的 **DMA 接口硬件** 直接控制在外设和主存之间交换数据，此时数据不经过 **CPU**。通常把该接口硬件称为 **DMA 控制器**。
15. 中断系统中存在两种中断优先级：**中断响应优先级** 和 **中断处理优先级**。

### 第一章 计算机系统概述

- **中央处理器（CPU）**：计算机系统的核心部件，负责执行程序中的指令、处理数据，并控制各部件协调工作。包含算术逻辑单元（ALU）和控制单元，执行算术运算、逻辑运算、数据传送和 I/O 操作的控制。〔2024 年 4 月考过〕
- **算术逻辑部件（ALU）**：CPU 中的关键组件，负责执行算术运算（加、减、乘、除）和逻辑运算（与、或、非、异或）。接收来自控制单元的操作码并执行相应运算。
- **通用寄存器**：CPU 内部的高速存储单元，用于暂存指令、数据和地址，可被 CPU 快速访问，从而加速数据处理。
- **程序计数器（PC）**：特殊寄存器，用于存储**下一条将要执行的指令的地址**。CPU 执行一条指令时，PC 自动加 1（或按跳转指令更改）。
- **指令寄存器（IR）**：用于暂存**当前正在执行的指令**，CPU 从主存读出一条指令后放入 IR，解码并执行。
- **控制器**：CPU 中的关键组件，负责从主存取出指令、对指令译码，并按指令要求有序、协调地指挥和控制计算机各部件自动工作。
- **主存储器**：计算机中的主要存储部件，用于存储程序和数据。CPU 可直接访问，不需通过其他外部设备。
- **总线**：计算机各部件之间传输信息的公共通道，由导线组成，用于在 CPU、主存、I/O 设备之间传输数据和控制信号。
- **主存地址寄存器（MAR）**：存放欲访问的主存单元的地址，其地址由 CPU 中的程序计数器给出；与主存地址译码电路相连。
- **主存数据寄存器（MDR）**：暂存从主存读出的一条指令或一个数据字，或准备写入主存的字；与主存数据总线相连，与 MAR 配合实现 CPU 与主存的数据交换。
- **机器指令**：CPU 能直接识别并执行的指令，由操作码和操作数地址码组成。每条指令完成一个基本的微操作。
- **指令操作码**：机器指令的一部分，用于指定该指令所要执行的操作类型（如加法、减法、存储等）。
- **高级程序设计语言**：接近于人类自然语言和数学语言的程序设计语言，易于编写和理解，经编译或解释后能转换成机器语言执行。
- **汇编语言**：用助记符表示的指令系统中的指令，是一种低级程序设计语言，需要汇编程序翻译成机器语言才能执行。
- **机器语言**：直接用二进制代码指令表达的计算机语言，是计算机**唯一能直接识别和执行**的语言。
- **机器级语言**：与特定机器或处理器直接相关的低级编程语言，包括机器语言和汇编语言。
- **源程序**：用高级程序设计语言编写的、尚未编译或解释的程序。
- **目标程序**：源程序经编译或解释后得到的机器语言程序，可以直接被计算机执行。
- **编译程序**：将高级语言源程序翻译成目标程序的软件工具。过程通常包括词法分析、语法分析、语义分析、优化和代码生成等阶段。
- **解释程序**：直接执行高级语言源程序的软件工具，对源程序**逐句扫描和解释并立即执行**，不生成独立的目标程序。
- **汇编程序**：将汇编语言源程序翻译成机器语言目标程序的软件工具（也称汇编器），包括指令转换与内存地址分配等。
- **语言处理系统**：用于处理各种程序设计语言的软件工具集合，包括编译器、解释器、汇编器等。
- **设备控制器**：计算机中的硬件部件，负责控制和管理外部设备（如打印机、磁盘驱动器等）与 CPU 之间的数据传输。
- **最终用户**：直接使用计算机系统和应用程序的个人或组织，通过用户界面与计算机交互完成任务。
- **系统管理员**：负责管理和维护计算机系统的专业人员，负责安装、配置、监控和维护硬件、软件和网络等。
- **应用程序员**：负责开发、编写和维护各种应用程序的专业人员，使用高级程序设计语言进行程序设计。
- **系统程序员**：负责设计、开发和维护系统软件的专业人员，编写操作系统、编译器、数据库管理系统等核心软件。
- **指令集体系结构（ISA）**：定义计算机指令的格式、数量和功能，以及 CPU 如何执行这些指令。
- **微体系结构**：处理器设计的关键部分，定义处理器内部各组件的结构、功能及交互方式，决定处理器如何执行指令、管理数据、处理中断，影响性能、功耗和效率。
- **透明**：某个方面对使用者不可见或不需要考虑。例如内存管理的某些细节对程序员透明，由操作系统或硬件自动管理。
- **响应时间**：系统或组件从接收到输入/请求到产生相应输出/响应所需的时间。
- **吞吐率**：系统或组件在单位时间内处理输入或输出数据的数量或速度，衡量整体效率。
- **用户 CPU 时间**：CPU 执行用户程序所花费的时间（区别于系统 CPU 时间——执行操作系统内核任务所花费的时间）。
- **时钟周期**：处理器中的基本时间单位，表示处理器执行一个基本操作所需的时间。
- **主频**：处理器每秒钟的时钟周期数，单位 Hz / MHz / GHz。主频越高，处理器执行指令的速度通常越快。〔2024 年 10 月考过〕
- **CPI**：处理器执行一条指令所需的平均时钟周期数。CPI 越低，指令执行速度越快。
- **基准程序**：一组用于测试和评估计算机系统性能的预定义程序和测试套件，用于比较不同系统性能、找出瓶颈。
- **MIPS**：每秒能执行的**百万条指令数**，MIPS 越高说明处理器性能越好。
- **峰值 MIPS**：处理器在理想条件下（无任何瓶颈）能够达到的最高 MIPS 值。
- **相对 MIPS**：用于比较不同处理器或系统性能的 MIPS 指标，通常是某系统 MIPS 除以基准系统 MIPS 得到的相对比值。
- **MFLOPS / GFLOPS / TFLOPS / PFLOPS / EFLOPS**：每秒百万次 / 十亿次 / 万亿次 / 千万亿次 / 百亿亿次浮点运算。

### 第二章 数据的表示和运算

- **真值**：数学上的值，即实际想要表示的数，不考虑计算机内部如何表示。
- **机器数**：计算机内部用来表示数值的二进制编码，因编码方式（原码、补码等）和机器特性而不同。
- **数值数据**：可以表示数量或大小的数据，如整数、浮点数等。
- **非数值数据**：不能表示为数量或大小的数据，如字符、文本、图片等。
- **无符号整数**：非负的二进制数，只表示大小，不表示正负。
- **带符号整数**：可表示正数或负数，通常用最高位作符号位，其余位表示数值大小。
- **定点数**：小数点位置固定的数值表示方法，主要用于表示整数或小数。
- **浮点数**：小数点位置可浮动的数值表示方法，通常由尾数（mantissa）和阶码（exponent）两部分组成，用于表示非常大或非常小的数。
- **尾数**：浮点数中用于表示数值大小的部分。
- **阶和阶码**：阶是浮点数中小数点实际位置与默认位置之间的偏移量；阶码是这个偏移量的编码表示。
- **溢出**：运算过程中结果超出机器能表示的范围，可能导致不正确的结果或错误。
- **规格化数**：满足特定条件的浮点数（如二进制尾数的最高位为 1），可提高浮点数的精度和范围。
- **左规**：浮点数运算中尾数向左移动、阶码相应减小的过程（通常发生在尾数溢出时）。
- **右规**：浮点数运算中尾数向右移动、阶码相应增加的过程（通常发生在尾数下溢时）。
- **ASCII 码**：American Standard Code for Information Interchange，用于表示英文字符和其他控制字符的编码系统。
- **汉字输入码**：用户通过键盘等设备输入汉字时使用的编码，如拼音码、五笔字型码。
- **汉字内码**：计算机内部用于表示汉字的编码，如 GB2312、GBK、UTF-8 等。
- **字长**：计算机内部处理数据的位数（如 32 位或 64 位），决定计算机一次能处理的数据量。
- **大端方式（Big Endian）**：高位字节存储在内存的**低地址端**，低位字节存储在高地址端。
- **小端方式（Little Endian）**：低位字节存储在内存的**低地址端**，高位字节存储在高地址端。
- **ALU**：计算机中的重要组件，负责执行算术运算（加、减、乘、除）和逻辑运算（与、或、非）。

### 第三章 程序的转换及机器级表示

- **机器语言程序**：由二进制代码组成的程序，是计算机硬件直接执行的指令集合。
- **汇编指令**：由助记符表示的机器指令，与机器语言一一对应，可被汇编器转换成机器语言指令。
- **汇编语言程序**：使用汇编语言编写的程序，以助记符形式表示指令序列，需经汇编器转换为机器语言程序。
- **汇编助记符**：汇编语言中使用的符号，代表对应的机器指令。
- **汇编程序（汇编器）**：将汇编语言程序转换成机器语言程序的程序。
- **反汇编程序**：将机器语言程序转换回汇编语言程序的程序。
- **机器级代码**：直接在计算机硬件上执行的指令，通常由汇编器将汇编语言转换而来。
- **CISC**：复杂指令集计算机，指令集包含多种复杂指令。
- **RISC**：精简指令集计算机，指令集相对简单，每条指令的执行时间相对较短。
- **通用寄存器**：用于存储临时数据和地址的寄存器，通常存放计算过程中的中间结果。
- **变址寄存器**：用于存储地址计算中的偏移量，通常用于数组、结构体等数据结构的访问。
- **基址寄存器**：用于存储内存地址基址，通常与变址寄存器一起用于计算实际内存地址。
- **栈指针寄存器**：用于存储**栈顶地址**的寄存器，用于函数调用和局部变量存储等操作。
- **指令指针寄存器**：用于存储当前正在执行指令的地址，通常指向下一条要执行的指令。
- **标志寄存器**：用于存储程序运行状态标志的寄存器，如零标志、进位标志等。
- **条件标志（条件码）**：标志寄存器中的一部分，表示上一条指令的执行结果，通常用于控制条件跳转指令的执行。
- **寻址方式**：指定操作数的寻址方式，如立即寻址、寄存器寻址、相对寻址等。
- **立即寻址**：直接将操作数的值嵌入到指令中。
- **寄存器寻址**：使用寄存器存储操作数的地址。
- **相对寻址**：使用相对于某个基址的偏移量来寻址。
- **存储器操作数**：指令中的操作数直接引用存储器中的数据。
- **实地址模式**：CPU 直接使用物理地址访问内存的模式。
- **保护模式**：一种 CPU 工作模式，操作系统可在其中对内存和其他资源进行保护和管理。
- **有效地址**：执行指令时计算出的操作数在内存中的真实地址。
- **比例变址**：根据一个基址寄存器和一个比例系数来计算操作数的地址。
- **非比例变址**：仅根据一个基址寄存器来计算操作数的地址。
- **比例系数（比例因子）**：用于比例变址计算的一个数值。
- **MMX 指令**：Intel 处理器中用于多媒体处理的指令集。
- **SSE 指令集**：Intel 处理器的扩展指令集，用于实现单指令多数据（SIMD）操作。
- **SIMD**：单指令多数据，一种并行计算技术，能同时处理多个数据。
- **多媒体扩展通用寄存器**：用于 SIMD 指令集操作的寄存器。
- **栈（Stack）**：一种后进先出（LIFO）的数据结构，用于临时存储函数调用的上下文和局部变量。
- **调用者保存寄存器**：函数调用过程中由**调用者**负责保存和恢复的寄存器。
- **被调用者保存寄存器**：函数调用过程中由**被调用者**负责保存和恢复的寄存器。
- **帧指针寄存器**：用于指向当前函数调用的栈帧的寄存器。
- **当前栈帧**：当前函数调用的栈帧，存储函数的参数、局部变量和返回地址等信息。
- **按值传递参数**：将参数的值传递给函数。
- **按地址传递参数**：将参数的地址传递给函数，函数可以直接访问参数的值。
- **嵌套调用**：在一个函数内部调用另一个函数的过程。
- **递归调用**：函数直接或间接地调用自身的过程。

### 第四章 可执行文件的生成和加载执行

- **链接**：将多个源文件或目标文件中的代码和数据组合成一个可执行文件或共享库文件的过程。
- **可重定位文件**：包含程序的代码和数据，但还没完成地址的最终分配，可在链接时进行地址重定位，得到可执行文件。
- **可执行文件**：经过链接之后完成了地址最终分配，可以直接在操作系统上执行的文件。
- **符号解析**：链接过程中，将符号（函数名、变量名）与其在程序中的地址或者其他符号相关联的过程。
- **重定位**：将程序中的符号引用与其真正的地址或者其他符号关联起来的过程。〔2024 年 10 月考过〕
- **ELF 头**：Executable and Linkable Format 头，描述可执行文件和共享库文件结构的数据结构。
- **节头表**：包含文件中各个节（section）的信息，如起始地址、大小等。
- **程序头表**：包含文件中各个程序段（segment）的信息，如加载地址、大小等。
- **只读代码段**：存放程序的代码，只允许读取，不允许写入。
- **可读/写数据段**：存放程序的数据，允许读取和写入。
- **全局符号**：在整个程序中都可见的符号，可以被其他文件引用。
- **外部符号**：在当前文件中未定义，但在其他文件中定义的符号。
- **本地符号**：仅在当前文件中可见的符号，对其他文件不可见。
- **强符号**：链接过程中优先选择的符号。
- **COMMON 符号**：未被初始化的全局变量或未定义的外部变量的符号。
- **静态链接**：在编译时将所有的库文件链接到可执行文件中的链接方式。
- **共享库文件**：包含可执行文件所需的代码和数据，可在多个进程间共享使用的文件。
- **动态链接**：在程序运行时将共享库文件链接到内存中的链接方式。
- **动态链接器**：负责在程序运行时将共享库文件链接到内存中的系统程序。
- **动态链接库**：包含可执行文件所需的代码和数据，可在程序运行时被动态链接到内存中使用的库文件。
- **进程**：计算机中正在运行的程序的实例，是操作系统进行资源分配和调度的基本单位。〔2024 年 4 月考过〕
- **进程描述符**：操作系统中用于描述进程的数据结构。
- **命令行解释程序**：接收用户输入的命令行，并将其解释为操作系统能够执行的命令的程序。
- **指令周期**：CPU 执行一条指令所经历的时间周期。
- **指令译码器**：负责将指令解码成对应的操作控制信号的硬件模块。
- **内部异常**：由程序执行过程中的错误或不正常情况引起的异常。
- **外部中断**：由外部设备（如硬件中断、时钟中断）引起的中断。
- **数据通路**：CPU 中负责数据传输和处理的部件的集合。
- **执行部件**：CPU 中负责执行指令的部件，包括算术逻辑单元（ALU）等。
- **功能部件**：CPU 中用于实现特定功能的部件，如乘法器、除法器等。
- **控制器**：CPU 负责控制整个运算过程的部件。
- **时钟信号**：CPU 内部的时钟信号，用于同步各个部件的工作。
- **指令流水线**：CPU 中用于提高指令执行速度的技术，将指令执行过程划分为多个阶段并行处理。

### 第五章 程序的存储访问

- **随机存取存储器（RAM）**：临时存储设备，用于存储当前正在处理的数据和程序，读写快，但断电后信息丢失。
- **只读存储器（ROM）**：一旦写入就不能被修改或删除的存储设备，通常用于存放基本启动指令或固件。
- **易失性存储器**：断电后数据会丢失的存储设备，如 RAM。
- **记忆单元（Cell）**：存储设备中最基本的存储单位，用于存储一个二进制位（bit）。
- **存储阵列（Bank）**：一组物理上相互独立的内存模块，每个模块有自己的地址和数据总线，允许并行访问以提高性能。
- **编址单位**：在内存或其他存储设备中用于标识和访问单个数据元素的最小单位。
- **编址方式**：如何给存储设备中的每个单元分配地址的方法，影响访问速度和效率。
- **存储周期**：存储器进行连续两次独立的存储操作（如读或写）之间所需的最小时间间隔。
- **静态 RAM（SRAM）**：用双稳态电路存储数据，不需要刷新，速度快但功耗较高。
- **动态 RAM（DRAM）**：用电容存储数据，因电容漏电需定期刷新来保持数据。
- **闪存（Flash 存储器）**：非易失性存储设备，使用浮栅晶体管存储数据，常用于 U 盘、SSD 和移动设备。
- **SDRAM**：同步动态 RAM，内部命令的发送与接收采用时钟同步方式。
- **行地址选通信号（RAS）**：在 DRAM 中用于指定要访问的存储单元的行地址。
- **列地址选通信号（CAS）**：在 DRAM 中用于指定要访问的存储单元的列地址。
- **磁盘驱动器**：用于读取和写入磁盘（如硬盘）数据的设备。
- **磁盘控制器**：管理和控制磁盘驱动器操作的硬件或软件组件。
- **寻道时间**：磁盘驱动器将读写头移动到指定磁道所需的时间。
- **旋转（等待）时间**：从开始寻找数据到数据所在扇区旋转到读写头下方所需的时间。
- **数据传输率**：存储设备在单位时间内可以传输的数据量。
- **平均存取时间**：从发出数据访问请求到数据实际可用所需的平均时间。
- **固态硬盘（SSD）**：使用闪存技术存储数据的存储设备，比传统机械硬盘更快、更耐用。
- **时间局部性**：如果一个信息项被访问，那么在未来不久它很可能再次被访问。
- **空间局部性**：如果程序访问了某个存储单元，那么不久的将来其附近的存储单元也很可能被访问。
- **主存块**：主存中可以被作为一个单元整体地传输到缓存中的一组数据。
- **cache 行（槽）**：缓存中用于存储数据的基本单元。
- **命中率**：缓存中访问成功的次数与总访问次数的比例。
- **命中时间**：缓存命中时，从发出数据请求到数据实际可用所需的时间。
- **缺失损失**：缓存未命中时，从慢速存储器（如主存）获取数据所需的额外时间和开销。
- **直接映射**：每个主存块直接映射到缓存中的特定行（页面）。方法简单，但可能导致缓存冲突。
- **全相联映射**：主存中的任一页面可以映射到缓存中的任一位置，没有固定对应关系。
- **组相联映射**：介于直接映射和全相联之间的映射方式。主存块映射到**固定组**中，组内各行可任意放置。
- **替换策略**：缓存满时如何选择数据项进行替换的策略，影响缓存效率和性能。
- **FIFO 算法**：先进先出算法，缓存满时最早进入的数据项被首先移出。
- **LRU 算法**：最近最少用算法，认为最近最少使用的数据项未来被访问可能性最小，故优先替换。
- **LRU 位**：用于跟踪缓存中数据项的使用情况，以实现 LRU 算法。
- **cache 写策略**：决定 CPU 修改 cache 数据时如何更新主存，常见有写回法和写通法。
- **回写法（写回法）**：修改 cache 时不立即写回主存，等到该块被替换或显式执行写回时才写回。
- **通写法（写通法）**：修改 cache 时立即写回主存，保证主存数据始终最新。
- **虚拟地址（逻辑地址）**：用户程序中的地址表示方式，不直接对应物理内存实际地址，需经地址映射/重定位转换为物理地址。
- **虚拟页号**：虚拟地址的一部分，用于标识虚拟内存中的页面。
- **物理地址**：内存中各存储单元的编号，即存储单元的真实地址，是可识别、可寻址并实际存在的，CPU 访问内存时使用。
- **页框（页帧）**：物理内存中的一个固定大小的块，用于存储从虚拟内存加载的数据。
- **物理页号**：物理地址的一部分，用于标识物理内存中的页面。
- **未分配页**：尚未被进程申请使用的虚拟内存页面，不占用物理内存或磁盘空间。
- **未缓存页**：在虚拟内存中但尚未加载到物理内存的页面，需要时会被加载。
- **请求分页**：允许程序在需要时从磁盘等辅助存储中加载页面到物理内存的内存管理技术。
- **页故障（缺页）**：访问尚未加载到物理内存的虚拟页面时发生的情况，系统需执行页面替换和加载操作。
- **页表**：操作系统用于记录虚拟页与物理页映射关系的数据结构，CPU 据此完成地址转换。
- **页表基址寄存器**：存放当前运行程序的页表起始地址，与虚拟地址拼接找到对应页表项。
- **有效位（装入位）**：标识页面是否有效或已加载。在缓存/内存中为 1，否则为 0。
- **修改位（脏位）**：标识页面是否被修改过（1 表示已修改），用于决定是否需写回主存。
- **访问权限**：定义程序或用户对特定内存区域的访问级别，如可读、可写、可执行。
- **快表（TLB）**：缓存虚拟地址到物理地址转换表的一部分，加速地址解析。
- **特权指令**：只能由操作系统或具有特权级别的程序执行的指令，用于访问硬件、修改系统状态等。
- **特权模式**：操作系统的一种运行模式，此模式下程序可执行特权指令并直接访问系统资源。
- **内核态**：操作系统内核的运行模式，具有最高权限级别，可执行所有指令、访问所有内存区域。
- **用户态**：程序运行在非特权级别，不能执行特权指令，也不能直接访问系统资源。
- **存储保护**：防止程序访问或修改其不应访问的内存区域，确保系统稳定性和安全性。
- **地址越界**：程序尝试访问其权限范围之外的内存地址，通常导致程序崩溃或系统错误。
- **访问越权**：程序或用户尝试执行超出其权限范围的操作，如访问受保护内存区域或执行特权指令。

### 第六章 程序中 I/O 操作的实现

- **I/O 硬件**：输入/输出设备，如键盘、鼠标、显示器、磁盘等，用于与计算机进行数据传输。
- **I/O 软件**：一组程序和工具，用于管理和控制 I/O 硬件的操作，包括设备驱动程序、中断处理程序、缓冲管理及相关的系统调用等。
- **用户空间 I/O 软件**：运行在用户空间中的程序，处理 I/O 操作，通常通过系统调用与内核空间 I/O 软件交互。
- **内核空间 I/O 软件**：操作系统内核中负责处理 I/O 操作的部分，管理设备驱动程序、处理中断，并提供系统调用接口。
- **系统调用处理程序**：操作系统内核中负责处理来自用户空间系统调用请求的部分，实现用户程序与内核之间的交互。
- **系统调用服务例程**：系统调用处理程序调用的内核函数，用于实现具体的系统调用功能。
- **设备驱动程序**：用于控制计算机硬件设备（打印机、键盘、鼠标、音视频设备等）的软件，使其能与计算机系统协调工作，通常由设备制造商提供并与操作系统紧密集成。
- **中断服务程序**：操作系统内核中用于处理特定中断事件的程序。
- **系统级 I/O 函数**：操作系统提供的用于执行 I/O 操作的 API（如 C 语言 stdio 函数库）。
- **虚拟文件系统**：用于网络环境的分布式文件系统接口，允许不同的文件系统与操作系统交互，无需考虑具体实现细节。
- **文件描述符**：由无符号整数表示的句柄，进程使用它来标识打开的文件，与文件对象（打开模式、位置、初始类型等信息）相关联。
- **文件元数据**：关于文件自身的信息，如创建时间、修改时间、大小、权限等。
- **流缓冲区**：用于提高 I/O 效率和性能，在数据读/写时暂存，以减少系统调用次数和内存访问延迟。
- **索引节点**：文件系统中的关键数据结构，包含文件的元数据（大小、权限、创建时间等），用于定位和访问文件。
- **目录文件**：文件系统中的特殊文件，用于存储多个文件目录的信息。
- **目录项**：文件系统中用于记录文件或目录信息的条目，包含名称、属性及其他元数据。
- **系统打开文件表**：操作系统内核维护的数据结构，记录当前打开的文件及其相关信息。
- **磁盘高速缓存**：操作系统用缓存最近访问过的磁盘数据块来提高磁盘 I/O 性能，减少物理访问次数。
- **高速缓存 RAM**：用于暂时存储数据和程序的内存设备，读写快，通常用于存放 CPU 经常访问的数据。
- **I/O 控制方式**：管理 I/O 操作的方法和技术，常见有程序直接控制、中断驱动、DMA 等。
- **程序直接控制 I/O**：用户程序直接通过特定的 I/O 指令或系统调用进行 I/O 操作，不依赖操作系统提供的 I/O 软件。
- **就绪状态**：描述进程或线程已准备好执行，等待被调度到 CPU 上运行的状态。
- **中断控制 I/O**：外部设备准备好数据传输时向 CPU 发中断信号，CPU 暂停当前任务转去执行中断处理程序完成 I/O。
- **中断屏蔽字**：用于控制中断响应的寄存器或变量，通过设置可屏蔽或允许特定中断请求，实现中断优先级管理。
- **多重中断**：在一个中断处理程序执行过程中，又发生了另一个中断，需保存当前上下文并处理新中断。
- **中断嵌套**：与多重中断类似，更强调中断之间的层次关系，即一个中断可在另一个中断的处理过程中被触发和处理。
- **DMA 方式**：直接存储器访问，允许某些硬件子系统直接访问主存而无需通过 CPU 传输数据，提高效率、减少 CPU 介入。
- **DMA 控制器**：实现 DMA 方式数据传输的硬件设备，负责在内存和设备之间直接传输数据，无需 CPU 干预。
- **设备控制器**：硬件设备与计算机之间的接口电路，负责控制和管理硬件设备的操作，如磁盘控制器、显卡控制器。
- **I/O 端口**：CPU 与外部设备通信的接口，用于发送和接收数据以及控制信号。
- **控制端口**：用于发送和接收控制信号的端口，控制设备的操作和行为。
- **数据端口**：用于传输数据的端口。
- **状态端口**：I/O 端口的一种，用于读取或设置硬件设备的状态信息。
- **I/O 地址空间**：计算机内存中用于映射 I/O 端口和设备控制器的地址范围，使 CPU 可通过内存访问方式与 I/O 设备通信。
- **独立编址方式**：I/O 端口地址和内存地址相互独立，使用不同地址空间，互不干扰。
- **统一编址方式**：I/O 端口地址和内存地址统一编址，使用相同地址空间，简化访问方式，但可能浪费内存空间。
- **存储器映射 I/O**：将 I/O 端口或设备控制器映射到内存地址空间，使 CPU 可以像访问内存一样访问 I/O 设备。
- **I/O 指令**：CPU 执行的用于启动 I/O 操作（如读取或写入数据）的指令。
- **可编程中断控制器**：用于管理中断请求的硬件设备，允许操作系统对中断进行优先级排序、屏蔽和响应控制。
- **中断请求寄存器**：记录当前待处理的中断请求的寄存器，供 CPU 或中断控制器处理。
- **中断响应优先级**：用来决定哪个中断应首先被**响应**的优先级规则。
- **中断处理优先级**：用来决定哪个中断处理程序应首先被**执行**的优先级规则。

## 第四部分 · 简答题 / 问答题（按章）

### 第一章 计算机系统概述

**（1）冯·诺依曼计算机由哪几部分组成？各部分的功能是什么？**
> 冯·诺依曼计算机主要由五大部分组成：输入设备、输出设备、运算器、控制器和存储器。
> - **输入设备**：接收用户输入的数据和指令，如键盘、鼠标等。
> - **输出设备**：展示计算机处理后的结果，如显示器、打印机等。
> - **运算器**：执行各种算术和逻辑运算。
> - **控制器**：控制各部件协同工作，负责指令的读取、解释和执行。
> - **存储器**：存储数据和程序，包括内存和外存。

**（2）什么是"存储程序"工作方式？**
> 将程序和数据以二进制代码形式预先存放在存储器中，计算机运行时从存储器中取出指令并加以执行。这种方式使计算机能自动、连续地执行程序，大大提高了工作效率。

**（3）一条指令的执行过程包含哪几个阶段？**
> ① 取指令：从存储器中取出指令；② 分析指令：对指令译码，确定其操作性质；③ 执行指令：按要求进行具体操作（数据运算、地址计算等）；④ 存储结果：将执行结果存回存储器。

**（4）计算机系统的层次结构如何划分？**
> - 微程序机器层（与硬件直接相关，由微指令和微程序组成）
> - 机器语言机器层（由机器指令组成）
> - 操作系统机器层（通过系统调用提供汇编、编译、连接、编辑等软件）
> - 汇编语言机器层
> - 高级语言机器层

**（5）计算机系统的用户可分为哪几类？每类用户工作在哪个层次？**
> - **高级用户 / 最终用户**：工作在应用层，使用高级语言进行编程和应用开发。
> - **系统程序员**：工作在系统层，负责设计、开发和维护操作系统、编译器等系统软件。
> - **机器语言程序员**：直接工作在机器语言层，使用机器语言或汇编语言编写程序。

**（6）程序的 CPI 与哪些因素有关？**
> ① 指令类型（不同指令执行时间不同）；② 指令的执行顺序（影响流水线效率）；③ 数据的存取方式（内存访问延迟、cache 命中率）；④ 程序的优化程度。

**（7）为什么说性能指标 MIPS 不能很好地反映计算机的性能？**
> ① MIPS 只考虑指令执行速度，不考虑指令类型和复杂性，而不同指令执行时间相差很大；② 忽略了内存访问、I/O 操作等重要因素；③ 是理论指标，实际运行受操作系统调度、并发执行等影响。因此还需结合响应时间、吞吐量、功耗等综合评价。

### 第二章 数据的表示和运算

**（1）为什么计算机内部采用二进制表示信息？**
> ① 二进制只有 0 和 1 两种状态，与逻辑电路的开关状态一致，表示和计算直接简单；② 运算规则简单，运算更高效；③ 只涉及两种状态，抗干扰能力强，对噪声和干扰容忍度高。

**（2）既然计算机内部所有信息都用二进制表示，为什么还要用到十六进制或八进制数？**
> 为了方便人类理解和操作。十六进制（每 1 位对应 4 个二进制位）、八进制（每 1 位对应 3 位）在表示较长的二进制数时更加简洁，便于阅读和书写；在程序设计和调试中更便于查看和操作内存地址与数据。

**（3）在浮点数的基数和总位数一定的情况下，浮点数的表示范围和精度分别由什么决定？**
> 由**阶码**和**尾数**决定：阶码决定浮点数的表示范围（最大、最小数值）；尾数决定浮点数的精度（数值的精确度）。

**（4）为什么要对浮点数进行规格化？有哪两种规格化操作？**
> 规格化是为了提高浮点数的精度和运算效率。两种操作：
> - **右规**：尾数绝对值小于规定最小值时，尾数小数点右移，阶码增加；
> - **左规**：尾数绝对值大于规定最大值时，尾数小数点左移，阶码减小。
>
> 规格化确保尾数满足一定条件（如最高位为 1），从而提高表示范围和精度。

**（5）为什么计算机处理汉字时会涉及不同的编码（输入码、内码、字模码）？哪些用二进制编码，哪些不用？**
> 汉字数量庞大，需要有效的编码方式来存储、传输和显示。
> - **输入码**（拼音码、五笔码等）：**不用**二进制编码，它是为方便用户输入而设计的，有特定的输入规则和逻辑；
> - **内码**：**用**二进制编码，是计算机内部存储和传输汉字的唯一标识码，需保证唯一性和识别准确性；
> - **字模码**：**用**二进制编码，用于显示汉字字形，通常以二进制图像或点阵形式表示。

### 第三章 程序的转换及机器级表示

**（1）一条机器指令通常由哪些字段组成？各字段的含义分别是什么？**
> ① 操作码：指示操作类型（加、乘等）；② 操作数：指令要操作的数据或数据的存储地址；③ 寻址方式：指定如何获取操作数地址；④ 操作数长度：指定操作数的长度（位/字节）。

**（2）将一个高级语言源程序转换成计算机能直接执行的机器代码通常需要哪几个步骤？**
> 词法分析（分割为词法单元）→ 语法分析（组合成语法结构）→ 语义分析（检查是否符合语言规范）→ 代码生成（翻译为目标机器代码）→ 代码优化（提高执行效率）。

**（3）IA-32 中的逻辑运算指令如何生成条件标志？移位指令可能会改变哪些条件标志？**
> 逻辑运算指令（AND、OR、XOR）会根据运算结果生成条件标志（如 ZF、CF 等）；移位指令（SHL、SHR）可能改变零标志 ZF、进位标志 CF 和溢出标志 OF。

**（4）执行条件跳转指令时所用到的条件标志信息从何而来？请举例说明。**
> 来自**上一条影响条件标志的指令**。例如执行 JZ（零标志为 1 则跳转）时，需要根据上一条指令的执行结果确定是否跳转。

**（5）无条件跳转指令和调用指令的相同点和不同点是什么？**
> 相同点：都能改变程序执行流程，跳转到指定地址执行。不同点：无条件跳转只是改变 PC 的值；调用指令还会把当前的程序状态（如返回地址）**保存到栈中**，以便后续返回。

**（6）按值传递参数和按地址传递参数两种方式有哪些不同点？**
> 按值传递：把参数的值复制给形式参数，函数内部对形参的修改**不影响**实参；
> 按地址传递：把参数的地址传给函数，函数内部对形参的修改**会影响**实参。

**（7）为什么在递归深度较深时递归调用的时间开销和空间开销都会较大？**
> 每次递归调用都会占用额外的栈空间（空间开销），频繁的函数调用和返回又增加了时间开销。

**（8）为什么数据在存储器中最好按地址对齐方式存放？**
> 许多计算机体系结构对数据访问有地址对齐要求。若数据未按正确对齐方式存放，可能导致额外的内存访问，降低访问效率。

### 第四章 可执行文件的生成和加载执行

**（1）如何将多个 C 程序模块组合生成可执行文件？简述从源程序到可执行文件的转换过程。**
> 主要包括**编译、汇编、链接**三个阶段：
> - 编译阶段：对每个 C 模块编译，生成对应的目标文件（含汇编代码，尚未分配地址）；
> - 汇编阶段：汇编器将汇编代码转换为机器语言代码，生成可重定位文件；
> - 链接阶段：将所有可重定位文件及所需库文件链接，解析符号引用并进行地址重定位，生成最终的可执行文件。

**（2）可重定位目标文件和可执行目标文件的主要差别是什么？**
> 可重定位目标文件是经编译和汇编但**尚未链接**的文件，地址还未确定；可执行目标文件经编译、汇编和链接，**地址已最终确定**，可直接在操作系统上执行。

**（3）链接器主要完成哪两方面的工作？**
> ① **符号解析**：解析各模块间的符号引用，确定符号对应的地址；② **重定位**：将各模块的地址关联起来，生成最终的可执行文件。

**（4）可重定位文件的 .text、.rodata、.data、.bss 节中分别主要包含什么信息？**
> - **.text**：存放程序的代码
> - **.rodata**：存放只读数据，如常量字符串等
> - **.data**：存放已初始化的全局和静态变量
> - **.bss**：存放未初始化的全局和静态变量

**（5）可执行目标中有哪两种可装入段？哪些节组合成只读代码段？哪些节组合成可读/写数据段？**
> 两种可装入段：**只读代码段**和**可读/写数据段**。
> - 只读代码段 = .text 节 + .rodata 节
> - 可读/写数据段 = .data 节 + .bss 节

**（6）加载可执行文件时，加载器根据其中哪个表的信息对可装入段进行映射？**
> 根据**程序头表**（段头表）中的信息对可装入段进行映射。

**（7）静态链接和动态链接的差别是什么？**
> 静态链接在**编译时**就把所有库文件链接进可执行文件，所有符号引用在编译时已确定；动态链接是在**程序运行时**将共享库链接到内存中，允许多个程序共享同一库文件，需要动态链接器在运行时解析符号引用。

**（8）在可执行文件中将可装入段映射到虚拟地址空间，以形成每个进程独立的虚拟地址空间，这种做法有什么好处？**
> 可以形成每个进程独立的虚拟地址空间，避免进程间的地址冲突，提高系统的安全性和稳定性。

**（9）简述通过 shell 命令行解释程序进行程序加载的过程。**
> ① 用户输入命令行；② shell 解释命令行，识别要执行的程序；③ shell 创建一个新的进程来执行该程序；④ 加载器把可执行文件加载到内存中；⑤ 加载器执行程序入口点。

**（10）CPU 的基本组成和基本功能各是什么？**
> 基本组成：算术逻辑单元（ALU）、控制单元（CU）、寄存器组。基本功能：执行指令、进行算术和逻辑运算、控制程序执行流程。

**（11）如何控制一条指令执行结束后能够接着另一条指令执行？**
> 通过**程序计数器（PC）的自增**实现：每执行一条指令，PC 自动加 1，指向下一条指令的地址。

**（12）通常一条指令的执行要经过哪些步骤？每条指令的执行步骤都一样吗？**
> 通常经过取指令、译码、执行、访存、写回几个步骤。每条指令的执行步骤**并不完全相同**，不同指令可能有不同执行路径和需要访问的数据。

**（13）流水线方式下，一条指令的执行时间缩短了还是加长了？程序的执行时间缩短了还是加长了？**
> 流水线方式下**单条指令的执行时间**（从开始到结束的绝对时间）并未缩短（甚至因寄存器延迟略有加长），但由于多条指令并行执行，整体上**程序的执行时间缩短**；不过若存在数据相关或控制相关导致流水线停顿/冒险，则会影响效率。

**（14）具有什么特征的指令系统易于实现指令流水线？**
> 指令长度固定、指令之间无数据相关性、指令之间无控制相关性、指令执行步骤相对简单等（即 RISC 风格）。

### 第五章 程序的存储访问

**（1）计算机内部为何要采用层次结构存储体系？层次结构存储体系如何构成？**
> 原因：① 解决快速 CPU 与慢速主存之间的速度差异；② 解决主存容量不足的问题。
> 构成：由多个存储设备按逻辑关系排列组合而成，主要包括**缓存层**（高速缓存、RAM，最快，用于加快访问）、**磁盘层**（硬盘、SSD，用于存储数据）、**磁带库层**（备份数据）、**云存储层**（海量数据）。

**（2）为什么采用地址对齐方式能减少访问 DRAM 中数据的时间？**
> DRAM 的访问以块为单位，若数据跨越多个块就需要多次访问。地址对齐可保证数据按块大小组织，从而一次访问即可取得所需数据，减少访问次数、提高效率。

**（3）为什么在 CPU 和主存之间引入 cache 能提高 CPU 的访存效率？**
> cache 存取速度快，能快速响应 CPU 的数据请求。CPU 需要访问主存时可先在 cache 中查找，命中则直接从 cache 读取，避免了对慢速主存的访问（利用了程序访问的局部性）。

**（4）为什么直接映射方式不需要考虑替换策略？**
> 直接映射下每个主存块只映射到 cache 中的固定行，新块调入时直接覆盖该固定行，无需选择替换哪一行，因而不存在替换策略问题。

**（5）为什么要考虑 cache 的写策略问题？**
> CPU 对主存的访问与修改会引发 cache 内容变化。若不加以控制，cache 与主存内容会不一致。为保证数据一致性，需要采用适当的写策略（**写回法**或**写通法**）决定何时以及如何将 cache 数据写回主存。

**（6）什么是物理地址？什么是逻辑地址？地址转换由硬件还是软件实现？为什么？**
> - **物理地址**：内存中各存储单元的编号，是存储单元的真实地址，可识别、可寻址并实际存在，CPU 访问内存时使用。
> - **逻辑地址**：用户程序经编译或汇编形成的目标代码中的地址，通常采用相对地址形式。
> - 地址转换通常由**硬件**实现（如 CPU 中的 MMU 地址映射机制），因为硬件转换速度更快，能满足 CPU 快速访存的需求；软件也可实现，但速度较慢，一般用于更复杂的地址管理任务。

**（7）在存储器层次化结构中，"cache—主存""主存—外存"这两个层次有哪些不同？**
> - **cache—主存**：主要解决主存**速度不够快**的问题，用高速缓存提高访问速度；
> - **主存—外存**：主要解决主存**容量不足**的问题，用外存扩展存储容量。
>
> 另外在访问频率和数据重要性上也有差异：cache 中多为频繁访问的热点数据，外存中多为长期保存但访问频率较低的数据。

### 第六章 程序中 I/O 操作的实现

**（1）I/O 子系统的层次结构是怎样的？**
> 从上至下依次为：**用户层 I/O 软件 → 设备独立性软件 → 设备驱动软件 → 中断处理软件 → 硬件**（包括机械部件和电子部件）。这种层次结构使 I/O 操作更加模块化和抽象化，便于软件开发和维护。

**（2）系统调用封装函数对应的机器级代码结构是怎样的？**
> 通常包括**若干条传送指令后跟一条陷阱指令**。传送指令用于传递系统调用的参数，陷阱指令（如 `int $0x80`）用于使 CPU 陷入内核进行处理。

**（3）为什么系统调用的开销很大？**
> 系统调用涉及从**用户态切换到内核态**，需要时间进行上下文切换；内核态执行时 CPU 工作在管理员模式，涉及特殊的堆栈和内存环境，需要在系统调用开始时建立并在结束后恢复，运行环境的切换以及对资源的访问控制都增加了开销。

**（4）C 标准 I/O 库函数是在用户态执行还是在内核态执行？**
> **用户态**执行。printf、scanf 等库函数提供用户程序与 I/O 设备之间的接口，但实际的 I/O 操作由内核在内核态完成，用户程序通过系统调用请求内核执行。

**（5）与 I/O 操作相关的系统调用封装函数是在用户态执行还是内核态执行？**
> **内核态**执行。用户程序通过系统调用接口请求内核执行 I/O 操作，内核切换到内核态执行相应的服务例程，完成后再返回用户态。

**（6）什么是程序直接控制 I/O 方式？说明其工作原理。**
> CPU 直接通过 I/O 指令对 I/O 设备进行操作：CPU 向设备发送控制命令和数据，然后等待设备完成操作并返回状态信息。缺点是 CPU 需频繁查询设备状态，效率降低。

**（7）为什么在保护现场和恢复现场的过程中，CPU 必须关中断？**
> 中断会打断当前执行流程。若在保护/恢复现场期间允许中断发生，可能干扰正在处理的信息，导致恢复现场时状态不一致甚至出错。关中断可确保恢复现场之前不会有其他中断打断处理过程。

**（8）什么是中断控制 I/O 方式？说明其工作原理。**
> 当 I/O 设备准备好数据传输时，向 CPU 发送中断信号；CPU 收到后暂停当前任务，转去执行中断处理程序完成 I/O。该方式可实现 CPU 与设备的**并行操作**，提高系统效率。

**（9）DMA 方式能够提高成批数据交换效率的主要原因何在？**
> DMA 允许数据直接在内存和设备之间传输而无需 CPU 介入，减少了 CPU 开销，使 CPU 可执行其他任务；同时还能实现高速数据传输，从而提高成批数据交换效率。

**（10）DMA 控制器在什么情况下发出中断请求信号？**
> 在**数据块传输完毕时**发出中断请求信号，通知 CPU 进行后续处理或启动新的数据传输任务。

**（11）I/O 端口的编址方式有哪两种？各有何特点？**
> - **独立编址**：I/O 端口地址与内存地址相互独立，使用不同地址空间，互不干扰。
> - **统一编址（存储器映射 I/O）**：I/O 端口地址与内存地址统一编址、使用同一地址空间，简化访问方式，但可能浪费内存空间。

**（12）为什么中断控制器把中断类型号放在 I/O 总线的数据线上而不是放在地址线上？**
> 中断类型号标识发生中断的具体原因或来源，本质是要**传送给 CPU 的数据**，放在数据线上可确保传输的准确性和可靠性；而地址线用于在内存或 I/O 设备中定位特定存储单元或端口，与中断处理不直接相关。因此放在数据线上更合理。

### 1.1 用户 CPU 时间与时钟频率（第一章）

**重点公式**

```
用户 CPU 时间 = 程序总时钟周期数 ÷ 时钟频率 = 程序总时钟周期数 × 时钟周期
程序总时钟周期数 = 用户 CPU 时间 × 时钟频率 = 用户 CPU 时间 ÷ 时钟周期
```

**例 1** 某频繁使用的程序 P 在机器 M1 上运行需要 15s，M1 时钟频率为 3GHz。设计人员想开发一台与 M1 具有相同 ISA 的新机器 M2。采用新技术可使 M2 的时钟频率增加，但同时也会使 CPI 增加。假定 P 在 M2 上执行时的时钟周期数是在 M1 上的 2 倍，则 M2 的时钟频率至少达到多少才能使程序 P 在 M2 上的运行时间缩短为 10s？

> **参考答案**
> 1. P 在 M1 的时钟周期数 = 用户 CPU 时间 × 时钟频率 = 15s × 3GHz = **45G**
> 2. P 在 M2 的时钟周期数是 M1 的 2 倍 = 45G × 2 = **90G**
> 3. M2 的时钟频率 = M2 的时钟周期数 ÷ 用户 CPU 时间 = 90G ÷ 10s = **9GHz**

**例 2** 程序 P 在 M1 上运行需要 20s，M1 时钟频率为 2GHz。P 在 M2 上执行时的时钟周期数是在 M1 上的 1.5 倍，则 M2 的时钟频率至少达到多少才能使 P 在 M2 上的运行时间缩短为 10s？

> **参考答案**
> 1. P 在 M1 的时钟周期数 = 20s × 2GHz = **40G**
> 2. P 在 M2 的时钟周期数 = 40G × 1.5 = **60G**
> 3. M2 的时钟频率 = 60G ÷ 10s = **6GHz**

### 1.2 指令条数与 CPI（第一章）

**重点公式**

```
指令条数 = 各指令类型条数加和
程序所含时钟周期数 = 程序所含指令数 × CPI
执行时间 = 时钟周期数 ÷ 时钟频率
```

**例 1** 一个高级语言程序被两个不同编译器编译生成两种指令序列 F1 和 F2，在时钟频率 1GHz 的机器上运行，用到的指令类型有 A、B、C、D 四类。各类指令的 CPI 和两个序列所用的指令条数如下表。求：(1) F1、F2 各有多少条指令？所含时钟周期数各多少？(2) F1、F2 的 CPI 各为多少？执行时间各为多少？（保留 1 位小数）

> **参考答案**
> （1）
> - F1：3+3+4+2 = **12 条**指令；时钟周期数 = 1×3 + 2×3 + 3×4 + 4×2 = **29**
> - F2：4+3+2+2 = **11 条**指令；时钟周期数 = 1×4 + 2×3 + 3×2 + 4×2 = **24**
>
> （2）
> - F1：CPI = 29 ÷ 12 ≈ **2.4**；执行时间 = 29 ÷ 1G = **29ns**
> - F2：CPI = 24 ÷ 11 ≈ **2.2**；执行时间 = 24 ÷ 1G = **24ns**
>
> 结论：指令条数少的 F2 反而 CPI 更低、执行更快。

**例 2** 某程序用到的 A、B、C、D 四类指令条数分别为 4、5、2、3，CPI 分别为 1、2、3、4，时钟频率 1GHz。求该程序的 CPI 和执行时间（ns，保留 1 位小数）。

> **参考答案**
> 指令数 = 4+5+2+3 = **14 条**
> 时钟周期数 = 4×1 + 5×2 + 2×3 + 3×4 = **32**
> CPI = 32 ÷ 14 ≈ **2.3**
> 执行时间 = 32 ÷ 1G = **32.0 ns**

### 2.1 IEEE 754 浮点数标准（第二章）

**解题思路（背下来就是模板）**

1. 所求的数若不是二进制，先转为二进制；
2. 转为二进制科学计数法：`1.F × 2ⁿ`；
3. 确定符号、阶码、尾数三部分；
4. **符号**：0 正，1 负（1 位）；
5. **阶码**：n + 127（单精度 32 位）／ n + 1023（双精度 64 位）；
6. **尾数**：F，后面补 0 补够 23 位；
7. 四合一，若题目要求则转为十六进制。

> 单精度格式：`(-1)^s × 1.f × 2^(E-127)`，符号 1 位 + 阶码 8 位 + 尾数 23 位。

**例 1** 将十进制数 100 转换为 IEEE 754 单精度（32 位）浮点数格式，最后用十六进制表示。

> **参考答案**
> 1. 转二进制：100 → `1100100`
> 2. 科学计数法：`1.100100 × 2⁶`
> 3. 符号：正 → **0**
> 4. 阶码：6 + 127 = 133 → `1000 0101`
> 5. 尾数：`100100` 后面补 17 个 0（共 23 位）
> 6. 最终结果：`0 10000101 10010000000000000000000`
> 7. 十六进制：**42C8 0000H**

**例 2** 将十进制数 67.375 转换成 IEEE 754 的 32 位标准浮点数的二进制格式，并写出其十六进制格式。

> **参考答案**
> 1. 转二进制：67.375 → `1000011.011`（整数、小数部分分别转换）
> 2. 科学计数法：`1.000011011 × 2⁶`
> 3. 符号：**0**
> 4. 阶码：6 + 127 = 133 → `1000 0101`
> 5. 尾数：`000011011` 后补 14 个 0（共 23 位）
> 6. 最终结果：`01000010100001101100000000000000`
> 7. 十六进制：**4286 C000H**

**例 3** IEEE 754 单精度浮点数的机器数为 `41A50000H`，将其转换为十进制表示的实数。

> **参考答案**
> 1. 转二进制：`41A50000H = 0100 0001 1010 0101 0000 0000 0000 0000 B`
> 2. 符号 s = **0**，该实数为正数
> 3. 阶码 = `10000011`₂ = 131；还原后的指数 = 131 − 127 = **4**，即 2⁴
> 4. 尾数（小数部分）= `0.0100101`₂ = **0.2890625**
> 5. 该浮点数 = 0.2890625 × 2⁴ = **20.625**
>
> （推荐写法：`(1.0100101)₂ × 2⁴ = (10100.101)₂ = 20.625`）

| 序号 | 指令 | 后缀 | 源操作数 | 目的操作数 |
|---|---|---|---|---|
| (1) | `mov 8(%ebp, %ebx, 4), %ax` | w | 基址+比例变址+偏移 | 寄存器 |
| (2) | `mov %al, 12(%ebp)` | b | 寄存器 | 基址+偏移 |
| (3) | `add ( , %ebx,4), %ebx` | l | 比例变址 | 寄存器 |

| 序号 | 代码 | 错误原因 |
|---|---|---|
| (1) | `movl 0xFF, (%eax)` | 源操作数是立即数 0xFF，前面需加 `$` |

| (6) | `movl %bx, %eax` | 源、目的寄存器长度不一致 |
| (7) | `andl %esi, %esx` | 不存在 ESX 寄存器 |

| 序号 | src_type | dst_type | 机器级表示 |
|---|---|---|---|

### 5.1 直接映射（第五章）

> ⚠️ **重点：一定一定要看清楚单位**，B、KB = 2¹⁰B、MB = 2²⁰B。

**解题思路（四个概念）**

1. **确定主存地址位数**：如主存空间 256KB → log₂(256×1024) = 18 位
2. **确定块内地址位数**：如主存块 64B → log₂64 = 6 位
3. **确定 cache 行号位数**：如 cache 数据区 1KB、块 64B → 1KB/64B = 16 行 → log₂16 = 4 位
4. **确定标记位数**：① − ② − ③

**例 1** 某计算机主存地址空间大小 8MB，按字节编址。主存与 Cache 之间采用**直接映射**，块大小 2K 字节，Cache 数据区大小 16KB。
(1) 该 Cache 共有多少行？(2) 主存地址需多少位？如何划分？

> **参考答案**
> (1) Cache 行数 = Cache 数据区大小 ÷ 块大小 = 16KB ÷ 2KB = **8 行**
> (2) 主存地址位数：log₂(8×1024×1024) = **23 位**
> 分三个字段：**标记 + cache 行号 + 块内地址**
> - 块内地址：块 2KB → log₂(2×1024) = **11 位**（主存地址低 11 位）
> - cache 行号：16KB/2KB = 8 行 → log₂8 = **3 位**（主存地址中间 3 位）
> - 标记：23 − 11 − 3 = **9 位**（主存地址高 9 位）

**例 2** 主存地址空间 4MB，按字节编址，直接映射，块大小 1KB，Cache 数据区 8KB。

> **参考答案**
> (1) Cache 行 = 8KB ÷ 1KB = **8 行**
> (2) 主存地址 = **22 位**，分为标记 **9 位** + cache 行号 **3 位** + 块内地址 **10 位**

### 5.2 组相联映射（第五章）

**解题思路**

1. 确定主存地址位数：如主存 256KB → 18 位
2. 确定块内地址位数：如块 64B → 6 位
3. 确定 cache **组号**位数：如 cache 数据区 1KB、块 64B → 16 行；2 路组相联 → 16/2 = 8 组 → log₂8 = 3 位
4. 确定标记位数：① − ② − ③

> 注意：Cache 总容量除存放主存块的数据区外，还包括**有效位、标记以及修改位和使用位（如 LRU 位）**等控制位。

**例 1** 主存与 Cache 采用 **2 路组相联**映射，块大小 1K 字节，Cache 数据区容量 16K 字节，主存空间 2M 字节，按字节编址。
(1) 主存地址划分为哪几部分？各几位？(2) Cache 总容量是多少（含有效位 V）？(3) 主存地址 12345H 映射到 Cache 的哪一组？

> **参考答案**
> (1) 主存地址：log₂(2×1024×1024) = **21 位**，分为 **标记 8 位 + cache 组号 3 位 + 块内地址 10 位**
> - 块 1KB → 块内地址 10 位（低 10 位）
> - 16KB/1KB = 16 行，2 路组相联 → 16/2 = 8 组 → 组号 3 位（中间 3 位）
> - 标记 = 21 − 10 − 3 = 8 位（高 8 位）
>
> (2) Cache 总容量 = 16KB + (8+1)bit × 16 = 16KB + 18B = **16402 B = 131216 bit**
> （每行都有标记 8 位 + 有效位 1 位）
>
> (3) `12345H = 0001 0010 0011 0100 0101`₂，中间 3 位（组号）为 `000` → 映射到**第 0 组**

**例 2** 主存与 cache 采用 **4 路组相联**映射，块大小 1024 字节，cache 数据区容量 64K 字节，主存空间 1M 字节，按字节编址。
(1) 主存地址划分为哪几部分？各几位？(2) cache 总容量是多少？

> **参考答案**
> (1) 主存地址 = **20 位**，分为 **标记 6 位 + cache 组号 4 位 + 块内地址 10 位**
> （64KB/1KB = 64 行，4 路组相联 → 64/4 = 16 组 → 组号 4 位；标记 = 20 − 10 − 4 = 6 位）
>
> (2) Cache 总容量 = 64KB + (6+1)bit × 64 = **524736 bit**

### 易混辨析速查

| 易混点 | 结论 |
|---|---|
| RISC vs CISC | RISC：指令少、定长、只有 Load/Store 访存、硬连线控制；CISC：指令复杂、变长、微程序控制 |
| 大端 vs 小端 | 大端：高位字节存**低地址**；小端：低位字节存**低地址** |
| 通写法 vs 回写法 | 通写：改 cache 立即写主存；回写：等替换时才写回（需脏位） |
| 内部异常 vs 外部中断 | 溢出、非法操作码、除 0、页故障 = 内部异常；I/O 请求 = 外部中断 |
| 用户态 vs 内核态 | 用户程序在用户态；设备驱动、中断服务、系统调用服务例程在内核态；`int $0x80` 陷入内核 |
| 物理地址 vs 逻辑地址 | 物理地址真实存在、CPU 访存使用；逻辑地址是程序中的地址，需 MMU 转换 |
| SP vs BP | SP 指向栈顶，BP 指向栈底 |
| 静态链接 vs 动态链接 | 静态：编译时装入，多程序多份副本、浪费内存；动态：运行时装入，多程序**只装一次**、可共享 |
| .text/.rodata/.data/.bss | 代码 / 只读数据 / 已初始化全局静态变量 / 未初始化（或初值为 0）全局静态变量 |
| 三种符号类型 | 全局（本地定义被他模块引用）、外部（他模块定义本模块引用）、本地（本模块定义并引用） |
| 中断屏蔽字 | 只屏蔽**某些**中断，不是一切中断 |
| DMA 传送期间 | 不需 CPU 干预，也**不需软件介入**，总线控制权归 DMA 控制器 |
| MIPS 的局限 | 只看指令条数，忽略指令复杂度、访存与 I/O，不能跨机器直接比较 |
