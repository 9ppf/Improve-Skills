## 一、高频简答考点（锚点 + 口诀 + 答题要点）

### 第一章 计算机系统概论

#### 考点 1：简述冯·诺依曼结构计算机的基本思想

> 🔑 **锚点**：存储程序 + 五大部件 + 二进制

1. 采用**"存储程序"**工作方式
2. 计算机由**运算器、控制器、存储器、输入设备、输出设备**五大基本部件组成
3. 存储器能存放**数据和指令**，形式上没有区别，但计算机应能区分它们
4. 计算机内部以**二进制**形式表示指令和数据

> 🧠 **口诀**：存程序，五部件，数据指令不分离，二进制里藏乾坤

---

#### 考点 2：简述程序和指令的执行过程

> 🔑 **锚点**：取数 → 存数 → 运算 → 传送

1. **取数指令（load）**：从主存单元取出数据存放到通用寄存器
2. **存数指令（store）**：将通用寄存器内容写入主存单元
3. **加法指令（add）**：将两个通用寄存器内容相加后送入结果寄存器
4. **传送指令（mov）**：将一个通用寄存器内容送到另一个通用寄存器

> 🧠 **口诀**：取存加传四兄弟，寄存器是老家，主存是远方

---

#### 考点 3：简述翻译程序的分类

> 🔑 **锚点**：汇编→机器；解释→逐条；编译→整体

1. **汇编程序（Assembler）**：将汇编语言源程序翻译成机器语言目标程序
2. **解释程序（Interpreter）**：将源程序语句按执行顺序**逐条**翻译成机器指令并**立即执行**（如 PYTHON、BASIC）
3. **编译程序（Compiler）**：将高级语言源程序**整体**翻译成汇编语言或机器语言目标程序

> 🧠 **口诀**：汇编一对一，解释逐条跑，编译打包走

---

#### 考点 4：简述从源程序到可执行文件的转换过程

> 🔑 **锚点**：预 → 编 → 汇 → 链（四步走）

1. **预处理阶段**（#include、#define 等指令处理）
2. **编译阶段**（生成 .s 汇编程序）
3. **汇编阶段**（生成 .o 可重定位目标文件）
4. **链接阶段**（多个 .o + 库 → 可执行文件）

> 🧠 **口诀**：预编汇链四步走，源程序变可执行

---

#### 考点 5：简述计算机的用户分类

> 🔑 **锚点**：最终→管理员→应用→系统（由表及里）

1. **最终用户**
2. **系统管理员**
3. **应用程序员**
4. **系统程序员**

> 🧠 **口诀**：最终管理员，应用系统员，层层深入不迷乱

---

### 第二章 数据的表示与运算

#### 考点 6：简述定点数编码表示方法

> 🔑 **锚点**：原补反移四兄弟

1. **原码**：正数与二进制相同，负数符号位为 1
2. **补码**：正数同原码，负数为原码"各位取反，末位加 1"
3. **反码**：正数同原码，负数为原码"各位取反"（**末位不加 1**）
4. **移码**：补码基础上首位取反，常用于浮点数阶码

> 🧠 **口诀**：原码直接补码妙，反码中间移码跳

---

#### 考点 7：简述补码的突出优点

> 🔑 **锚点**：零唯一 + 模运算 + 多一负 + 免循环

1. 数 **0 的补码表示形式唯一**（原码有 +0 和 -0 两个）
2. 补码运算系统是**模运算系统**，可用**加法实现减法**运算，符号位和数值位一起参加运算
3. 比原码和反码**多表示一个最小负数**
4. 不需要通过**循环进位**来调整结果

> 🧠 **口诀**：零唯一来模运算，多表一负免循环，补码优点记心间

---

#### 考点 8：简述无符号数除法运算的判断操作

> 🔑 **锚点**：三种特殊情况先判断

1. 被除数为 0、除数不为 0，或 |被除数| < |除数| → **商为 0，余数为被除数**
2. 被除数不为 0、除数为 0 → 整数：**"除数为 0"异常**；浮点数：结果为**无穷大**
3. 被除数和除数都为 0 → 整数：**除法错异常**；浮点数：产生 **quiet NaN**

> 🧠 **口诀**：先看零除再看小，商零余被除，除零异常无穷大，双零quiet NaN

---

#### 考点 9：简述浮点数乘法的运算步骤

> 🔑 **锚点**：尾乘阶加 → 规格化 → 舍入 → 判溢出

1. **尾数相乘、阶相加**
2. **尾数规格化**（左规或右规）
3. **尾数舍入处理**
4. **阶码溢出判断**

> 🧠 **口诀**：尾乘阶加先运算，规格舍入再判断

---

### 第三章 指令系统与汇编

#### 考点 10：简述指令的类型

> 🔑 **锚点**：RR / RS / SI / SS

1. **RR 型**：两个操作数都来自寄存器
2. **RS 型**：两个操作数分别来自寄存器和存储单元
3. **SI 型**：两个操作数分别来自存储单元和立即数
4. **SS 型**：两个操作数都来自存储单元

> 🧠 **口诀**：RR最快SS慢，RS和SI中间站

---

#### 考点 11：简述与 CISC 相比、RISC 指令系统的主要特点

> 🔑 **锚点**：少指令 + 定长 + Load/Store + 多寄存器

1. **指令数目少**
2. **指令格式规整**，采用定长指令字方式
3. 只有 **Load/Store** 指令中的数据需要访存
4. 采用**大量通用寄存器**

> 🧠 **口诀**：少定LoadStore多寄存，RISC四宝记心间

---

#### 考点 12：简述 C 语言程序中的基本数据类型

> 🔑 **锚点**：指针序数带符号，浮点四类型

1. **指针或地址**
2. **序数、位串**
3. **带符号整数**
4. **浮点数**

> 🧠 **口诀**：指序带浮四兄弟，C语言里常相遇

---

#### 考点 13：简述 IA-32 指令的操作数类型

> 🔑 **锚点**：立即 → 寄存器 → 存储器（速度递减）

1. **立即数**：直接写在指令中，不需要访存
2. **寄存器操作数**：存在寄存器中
3. **存储器操作数**：存在主存中，需要访存

> 🧠 **口诀**：立即最快寄存次，存储最慢要访存

---

#### 考点 14：简述过程调用的执行步骤

> 🔑 **锚点**：传参 → 存址 → 保存 → 执行 → 恢复 → 返回

1. 调用者 P 将**入口参数**放到被调用者 Q 能访问到的地方
2. P 将**返回地址**存到特定地方，控制转移到 Q
3. Q **保存 P 的现场**，为自己的非静态局部变量分配空间
4. **执行 Q 的过程体**
5. Q **恢复 P 的现场**，释放局部变量空间
6. Q 取出**返回地址**，控制转移回 P

> 🧠 **口诀**：传参存址保现场，执行恢复再返回

---

#### 考点 15：简述 C 语言中循环结构

> 🔑 **锚点**：for / while / do-while 三兄弟

1. **for** 语句：知道循环次数时用
2. **while** 语句：条件满足就继续
3. **do-while** 语句：**至少执行一次**循环体

> 🧠 **口诀**：for计次数while条件，do-while至少跑一遍

---

#### 考点 16：简述与 IA-32 代码相比，x86-64 代码主要特点

> 🔑 **锚点**：寄存器更多 + 位数更长 + 传参用寄存器 + XMM 翻倍

1. 通用寄存器**个数更多**（从 8 个 → 16 个）
2. 通用寄存器**位数从 32 位扩展到 64 位**
3. 字长从 32 位变为 64 位，**逻辑地址从 32 位变为 64 位**
4. 整型入口参数 **6 个以内用通用寄存器**（RDI、RSI、RDX、RCX、R8、R9）而不是栈传递
5. XMM 寄存器从 8 个增加到 **16 个**，浮点操作基于 SSE 面向 XMM 寄存器的指令集

> 🧠 **口诀**：寄存翻倍位变长，六字以内寄存传，XMM十六更顺畅

---

#### 考点 17：简述 x86-64 的寄存器的使用约定

> 🔑 **锚点**：RSP栈顶 + RIP指令 + 六参寄存器 + 调用者/被调用者保存

1. 可不用 **RBP** 作栈帧底部，用 **RSP** 作基址寄存器访问栈帧信息，RBP 可作普通寄存器
2. 传送入口参数寄存器依次为：**RDI、RSI、RDX、RCX、R8、R9**；返回参数存放在 **RAX**
3. **调用者保存**：R10、R11；**被调用者保存**：RBX、RBP、R12、R13、R14、R15
4. **RSP** 指向栈顶元素
5. **RIP** 指向正在执行或即将执行的指令

> 🧠 **口诀**：RSP栈顶RIP指，六参RDI到R9，RAX返回值，R10R11调用者，其余被调者

---

### 第四章 处理器与 CPU

#### 考点 18：简述 CPU 执行指令的过程

> 🔑 **锚点**：取指 → 译码 → 取数 → 执行 → 存果 → 算下址

1. **取指令**：从 PC 所指单元取出指令送 IR，PC 自动增量
2. **指令译码**：对操作码译码生成控制信号
3. **计算源操作数地址并取操作数**：根据寻址方式确定源操作数地址
4. **执行数据操作**：在 ALU 中对源操作数运算
5. **计算目的操作数地址并存结果**
6. **计算下条指令地址**

> 🧠 **口诀**：取译取执存算下，六步走完一条令

---

#### 考点 19：简述 CPU 的基本功能和组成

> 🔑 **锚点**：PC + IR + ID + 启停 + 时序 + 控制 + 总线 + 中断

1. **程序计数器（PC）**：存放下一条指令地址
2. **指令寄存器（IR）**：存放现行指令
3. **指令译码器（ID）**：对操作码译码
4. **启停控制逻辑**：控制 CPU 启停
5. **时序信号产生部件**：产生同步时钟
6. **操作控制信号形成部件**：产生微命令
7. **总线控制逻辑**：管理总线访问
8. **中断机构**：处理异常情况和外部中断请求

> 🧠 **口诀**：PC指地址IR存指令，ID来译码启停控，时序控制总线断，八大部件组CPU

---

#### 考点 20：简述 CPU 对异常和中断的响应过程步骤

> 🔑 **锚点**：保护 → 关断 → 识别转处理

1. **保护断点和程序状态**：将 PC 和 PSW 压栈
2. **关中断**：防止响应过程中被其他中断打断
3. **识别异常和中断事件并转相应处理程序**

> 🧠 **口诀**：先保护再关断，识别事件转处理

---

#### 考点 21：简述指令的处理过程阶段

> 🔑 **锚点**：IF → ID → EX → WB（四阶段流水线）

1. **取指令并 PC 加 1（IF）**：根据 PC 从存储器取出指令
2. **译码并读寄存器（ID）**：对操作码译码，读取寄存器 rs 和 rt
3. **运算或读存储器（EX）**：ALU 运算或根据 addr 读存储器
4. **结果写回（WB）**：结果写入目的寄存器 rt 或主存单元 addr

> 🧠 **口诀**：IF取指ID译码，EX运算WB写回，四阶段流水线

---

### 第五章 编译与链接

#### 考点 22：简述四趟扫描处理

> 🔑 **锚点**：词法 → 语法 → 优化分配 → 生成

1. **第一趟**：词法分析（识别单词符号）
2. **第二趟**：语法分析（构建语法树）
3. **第三趟**：代码优化和存储分配
4. **第四趟**：生成代码

> 🧠 **口诀**：词法语法优化配，四趟扫描代码成

---

#### 考点 23：简述符号表中的符号类型（链接器视角）

> 🔑 **锚点**：全局定义 + 外部引用 + 本地自用

1. **Global Symbol**：在本模块定义并被其他模块引用（非 static 函数名、全局变量名）
2. **External Symbol**：由其他模块定义并被本模块引用（外部函数名、外部变量名）
3. **Local Symbol**：在本模块定义并在本模块引用（static 函数、static 变量）

> 🧠 **口诀**：全局定义供人用，外部引用别人功，本地自用不外出

---

#### 考点 24：简述通过 shell 命令行输入可执行文件名 a.out 进行程序加载的过程

> 🔑 **锚点**：提示符 → 解析 → fork → execve

1. shell 输出**命令行提示符**（如 unix>），接受用户输入
2. 用户输入"./a.out[enter]"后，shell **解析命令行**，构造 argv 和 argc
3. 调用 **fork** 函数创建子进程
4. 以 argc、argv、environ 为参数调用 **execve**，在子进程上下文中加载运行 a.out

> 🧠 **口诀**：提示符下敲命令，解析参数fork生，execve来加载

---

### 第六章 存储器层次结构

#### 考点 25：简述主存块和 cache 行之间的映射方式

> 🔑 **锚点**：直接固定 / 全相联任意 / 组相联固定组内任意

1. **直接映射**：每个主存块映射到 cache 的**固定行**
2. **全相联映射**：每个主存块映射到 cache 的**任意行**
3. **组相联映射**：每个主存块映射到 cache 的**固定组的任意行**

> 🧠 **口诀**：直接固定行，全相任意行，组相固定组内任意行

---

#### 考点 26：简述虚拟存储器的类型

> 🔑 **锚点**：段式 / 页式 / 段页式

1. **段式**虚拟存储器：按程序逻辑结构划分，段大小动态可变
2. **页式**虚拟存储器：按固定大小页划分（如 4KB、8KB）
3. **段页式**虚拟存储器：先逻辑分段，再每页分段内，结合两者优点

> 🧠 **口诀**：段页段页三类型，虚拟存储分得清

---

#### 考点 27：简述磁盘存储器的性能指标

> 🔑 **锚点**：密度容量速率时间

1. **记录密度**
2. **存储容量**
3. **数据传输率**
4. **平均存取时间** = 寻道时间 + 旋转等待时间 + 传输时间

> 🧠 **口诀**：密度容量速率时，磁盘性能四指标

---

#### 考点 28：简述 SSD 的三个限制

> 🔑 **锚点**：先擦后写 + 顺序写入 + 次数有限

1. 写某一页之前，必须**先擦除该页所在的整个区块**
2. 擦除后区块内的页必须**按顺序写入**
3. **擦除/编程次数有限**（约 10 万-100 万次）

> 🧠 **口诀**：先擦后写按顺序，次数有限要牢记

---

### 第七章 I/O 与系统

#### 考点 29：简述 I/O 的主要控制方式

> 🔑 **锚点**：程序直控 → 中断 → DMA（逐级解放 CPU）

1. **程序直接控制**（轮询）：CPU 不断查询设备状态
2. **中断控制**：设备就绪后发送中断请求通知 CPU
3. **DMA 控制**：DMA 控制器与主存直接传输，CPU 仅启动和结束

> 🧠 **口诀**：程序直控最原始，中断通知省CPU，DMA传输最彻底

---

#### 考点 30：简述中断系统的基本功能

> 🔑 **锚点**：记录 → 响应 → 选优 → 保护 → 屏蔽嵌套

1. **及时记录**各种中断请求（中断请求寄存器 IRR）
2. **自动响应**中断请求（CPU 开中断状态下，执行完指令后自动检测）
3. 多个中断请求时，**自动选择并响应优先级最高**的
4. **保护断点和现场**（断点由 CPU 保存，现场由中断服务程序保存）
5. 通过**中断屏蔽实现多重中断的嵌套执行**

> 🧠 **口诀**：记录响应选优先，保护断点和现场，屏蔽嵌套功能全

---

#### 考点 31：简述 I/O 接口的主要职能

> 🔑 **锚点**：缓冲 + 检测 + 控制定时 + 格式转换

1. **数据缓冲**：解决速度不匹配问题
2. **错误和就绪检测**：检测设备状态
3. **控制和定时**：实现设备与 CPU 的时序同步
4. **数据格式的转换**：串并转换、电平转换等

> 🧠 **口诀**：缓冲检测控定时，格式转换四职能

## 二、名词解释速查（单选 / 名词解释 / 填空常考）

> 以下概念来自原序知识点，与第一部分不重复，覆盖单选/名词解释高频考点。

| # | 名词 | 定义 |
| :-: | :--- | :--- |
| 1 | ALU 算术逻辑部件 | 能进行算术运算与逻辑运算的组合逻辑电路，核心是带标志加法器 |
| 2 | 指令集体系结构 ISA | 软件和硬件之间的接口，规定机器级程序的格式和行为 |
| 3 | 流水线 IF→ID→EX→WB | 指令执行拆成四阶段并行：取指 → 译码读寄存器 → 运算/访存 → 写回 |
| 4 | 主频 | CPU 主脉冲信号的时钟频率，是时钟周期的倒数 |
| 5 | 时钟周期 | CPU 主脉冲信号的宽度，计算机执行一条指令被分成若干步，每步需要一个时钟周期 |
| 6 | 字长 | CPU 一次能处理的二进制位数，通常指寄存器位数（8/16/32/64 位） |
| 7 | 机器数 | 数值数据在计算机内部的二进制编码表示（含符号位），包括原码、反码、补码、移码 |
| 8 | 定点数 | 小数点位置固定的数，分定点整数（纯整数）和定点小数（带小数） |
| 9 | 浮点数 | 格式 N = 尾数 × 基数^阶码，阶码范围决定数范围，尾数决定精度 |
| 10 | 规格化 | 尾数调整使有效数字最高位为 1（左规：尾数左移阶码减 1；右规：尾数右移阶码加 1） |
| 11 | 重定位 | 重新确定代码和数据的地址，并更新指令中被引用符号地址的操作 |
| 12 | 栈帧 | 过程调用时在栈中分配的一块存储区域，保存入口参数、返回地址、被保存寄存器、局部变量 |
| 13 | 系统调用 | 用户程序通过陷阱指令向操作系统内核请求服务的接口（如 I/O、进程管理） |
| 14 | 程序 vs 进程 | **程序**是静态的代码集合；**进程**是程序的一次运行过程（动态、有生命周期） |
| 15 | Cache | 基于程序访问局部性原理，CPU 内/附近的高速缓存，用 SRAM 实现 |
| 16 | 虚拟存储器 vs Cache | **相同**：都基于局部性，缓存提高速度。**不同**：虚拟存**扩展容量**（硬件+软件）；Cache **提高速度**（硬件） |
| 17 | 程序访问局部性 | 包含**时间局部性**（近期访问的数据再次访问概率高）和**空间局部性**（邻近地址访问概率高） |
| 18 | 大端方式 | 数据最高有效字节存放在**最低地址**，最低有效字节存放在最高地址 |
| 19 | 中断 vs 异常 | **中断**：外部设备引发（如 I/O 请求），与当前指令无关；**异常**：CPU 执行指令引发（如除数为 0、缺页），与指令相关 |
| 20 | RISC vs CISC | RISC 精简指令系统：指令少、格式规整、Load/Store 访存、多寄存器；CISC 复杂指令系统相反 |
| 21 | 总线 | 连接计算机各部件的公共传输介质，分地址线、数据线、控制线三组 |
| 22 | CPI | 每条指令的平均时钟周期数 = 总时钟周期数 / 总指令条数 |
| 23 | 直接寻址 vs 间接寻址 | **直接**：指令中地址码就是操作数地址；**间接**：地址码指向的单元中存放操作数的真实地址 |
| 24 | 链接器 | 将多个可重定位 .o 文件组合成可执行文件，完成**符号解析**和**重定位**两个任务 |
| 25 | 静态库 vs 动态库 | **静态库（.a）**：链接时拷贝进可执行文件，独立运行；**动态库**：运行时加载，共享、节省磁盘/内存 |
| 26 | 存储器层次结构 | 寄存器 → Cache → 主存 RAM → 外存（磁盘/SSD），速度递减、容量递增、价格递减 |
| 27 | 易失 vs 非易失存储器 | **易失**：断电丢失（RAM、Cache）；**非易失**：断电保留（ROM、磁盘、SSD、U 盘） |
| 28 | IEEE 754 浮点数标准 | 统一浮点数格式（单精度 32 位 / 双精度 64 位），定义规格化、特殊数（0、无穷大、NaN） |
| 29 | CPU 访存过程 | 地址线送地址 → 控制线送读写命令 → 数据线送/接收数据；**cache 缺失由硬件处理，缺页由软件处理** |
| 30 | 存储单位换算 | bit(位) < B(字节)=8bit < KB=1024B < MB=1024KB < GB=1024MB < TB=1024GB |

## 四、易错点清单（考场上防呆）

| # | 易错点 | 正确做法 |
| :-: | :--- | :--- |
| 1 | **考点 4 和考点 12 内容完全相同**（都是预→编→汇→链） | 合并记忆，避免重复背诵 |
| 2 | 补码优点中"**多表示一个最小负数**"容易漏掉 | 口诀里有"多一负"三字，默念 |
| 3 | 过程调用步骤中"保存现场"和"恢复现场"顺序不能颠倒 | 调用者保存者先 save 后 restore |
| 4 | x86-64 传参是"**6 个以内用寄存器**"，不是"所有参数都用寄存器" | 口诀"六字以内寄存传" |
| 5 | SSD 限制是"先擦除整个区块"，不是"只擦除那一页" | 口诀"先擦后写" |
| 6 | Cache 映射"组相联"是"固定组内任意行"，不是"任意组任意行" | 口诀"组相固定组内任意行" |
| 7 | 中断是**外部**事件，异常是**内部**指令引发的 | 别记反了 |
| 8 | 原码 +0 和 -0 表示不同；补码 0 **唯一** | 这点考选择填空题高频 |
| 9 | 静态库拷贝进可执行文件独立运行；动态库运行时加载共享 | 别记反 |
| 10 | 虚拟存储**扩展容量**（硬件+软件），Cache **提高速度**（硬件） | 两者对比考单选 |
