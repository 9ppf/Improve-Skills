# Cache 主存地址划分与总容量计算：完整笔记 + 答题模板

---

## 一、概念辨析（极易混淆，必须理清）

### 1. 三个名词对应关系
- **Tag = 标记位** ✅ 完全同一个东西。用来区分“虽然映射到了同一个组，但到底是不是我要的那个主存块”。
- **索引（Index） ≠ 整个 Cache** ❌ 索引是地址字段，作用是“指路”，告诉 CPU 去 Cache 的哪一组找数据。准确说：索引 = **Cache 的组号**。
- **块内地址 = 偏移（Offset）** ✅ 完全同一个东西。用来选中一个块里面的具体哪个字节。

### 2. 终极理解：把 Cache 想象成一个 Excel 表格
在 N 路组相联的 Cache 中：
- **行数 = 组数**（Set）。主存地址里的“组索引”就是用来选哪一行的。
- **列数 = 路数**（Way）。路数是硬件设计时固定的（如4路）。
- **总格子数（总行数 / Cache Line总数） = 组数 × 路数**。

**查找过程（对应地址划分）：**
1. 用“组索引”选中表格的某一行（某一组）。
2. 用“Tag”和这一行里的 N 个格子（N路）同时比较，判断是否命中。
3. 用“块内偏移”从命中的那个格子里取出具体的字节。

> 注意：直接映射就是只有 1 列的表格；全相联就是只有 1 行的表格（1个组，没有行号）。

### 3. 主存地址与 Cache 的关系
- **主存**：巨大的仓库，里面有很多块，每块有一个 Tag（身份证）。
- **Cache**：小仓库，里面有很多行，每行贴着一个 Tag（记录自己装的是哪块）。
- **主存地址**：CPU 发的纸条，上面写着 `Tag + 索引 + 偏移`。
  - 用**索引**去 Cache 找对应的组。
  - 用地址里的 **Tag** 去和组里每一行的 **Tag** 比较。
  - 匹配成功 → 命中；失败 → 未命中。

**关键：主存地址里的 Tag 只有一个，因为 CPU 一次只找一个块。Cache 里的 Tag 有很多个，因为每一行都要记录自己装的是哪个块。**

---

## 二、核心规律：主存地址分几部分？

主存地址的划分完全由**“组索引（Index）”是否存在**决定。

- **有索引（3部分）**：直接映射、N路组相联映射。
- **无索引（2部分）**：全相联映射。

**为什么全相联没有索引？**
全相联映射意味着主存中任何一块都可以放入 Cache 的任何一行，整个 Cache 只有 1 个组（组数 = 1）。组索引的作用是“选择第几组”，现在只有 1 组，不需要选，所以索引位数为 log2(1) = 0 位，字段自然消失。

**结论规律：**
1. 题目说 **“直接映射”** -> 肯定有组索引，地址分 **3部分** (Tag + 索引 + 偏移)。
2. 题目说 **“N路组相联”** -> 肯定有组索引（只要组数>1），地址分 **3部分** (Tag + 索引 + 偏移)。
3. 题目说 **“全相联映射”** -> 没有组索引，地址分 **2部分** (Tag + 偏移)。

## 三、万能解题流程（“切蛋糕”法）

拿到题目，按以下顺序依次计算：

### 第一步：算主存地址总位数
- **公式**：主存地址总位数 = log2(主存容量)
- **注意**：题目若给的是 MB/GB，先化成 2^n B，指数 n 就是总位数。

### 第二步：切最低位（块内偏移）
- **公式**：块内偏移位数 = log2(块大小)
- **位置**：地址最低位，A(n-1) ~ A0

### 第三步：算 Cache 总行数
- **公式**：总行数 = Cache 数据区容量 ÷ 块大小
- **注意**：如果题目给的是“Cache容量”，这里默认是“数据区容量”。

### 第四步：算组数，决定有没有“索引”
- **全相联**：组数 = 1（没有索引，跳到第六步）
- **直接映射**：组数 = 总行数（不需要除以路数，路数为1）
- **N路组相联**：组数 = 总行数 ÷ N路

### 第五步：切中间位（组索引）
- **公式**：组索引位数 = log2(组数)（全相联直接算 0）
- **位置**：紧挨在块内偏移的上面。

### 第六步：切最高位（Tag）
- **公式**：Tag位数 = 总位数 - 索引位数 - 偏移位数
- **位置**：地址最高位，剩下全部给 Tag。

### 第七步：写格式
- **有索引**：`[Tag] + [组索引] + [块内偏移]`
- **无索引**：`[Tag] + [块内偏移]`

## 四、计算方式辨析（用不用 log？）

求位数时，不是所有计算都要用 log，取决于已知什么、求什么：

### 1. 必须用 log2 的情况（已知总数求位数）
只要题目给的是“总数”（总容量、总块数、总组数），要算需要多少位二进制表示，就用 log2。
- 求主存地址总位数：log2(64MB) = log2(2^26) = 26 位
- 求块内偏移位数：log2(64B) = log2(2^6) = 6 位
- 求组索引位数：log2(16组) = log2(2^4) = 4 位

> 💡 **实战技巧**：题目通常是 2 的幂，根本不需要按计算器算 log，只要把数字化成 2^n，指数 n 就是位数。看到 64 想到 2^6，位数就是 6。

### 2. 绝对不用 log 的情况（求数量用除法）
题目给的是两个容量，或容量和块大小，要算里面有多少个“块”或“行”，用除法。
- 求 Cache 行数：4KB ÷ 64B = 64 行（或 2^12 ÷ 2^6 = 2^6 = 64 行）
- 求组数：64行 ÷ 4路 = 16 组

### 3. 绝对不用 log 的情况（求剩余字段用减法）
地址总位数固定，切掉偏移，切掉索引，剩下的就是 Tag。
- 求 Tag 位数：26 - 4 - 6 = 16 位

### 📝 口诀总结：
- **看“总数”求“位数”，用 log2**（实际就是找 2 的几次方）。
- **看“容量”求“数量”，用除法**。
- **看“总位”求“剩位”，用减法**。

## 五、Cache 总容量计算方法

Cache 总容量 = **数据区容量** + **行附加信息** + **LRU替换位**

### 1. 数据区容量（位）
- **公式**：数据区容量 × 8
- **注意**：单位是位（bit），不要漏乘 8。

### 2. 行附加信息（每行）
- **Tag**：前面算出的 Tag 位数
- **有效位（Valid）**：默认都有，**1 位**
- **脏位（Dirty）**：**写回策略**才有，**1 位**（写直达没有）
- **公式**：每行附加位 = Tag + 有效位 + 脏位
- **总行附加**：Cache 行数 × 每行附加位

### 3. LRU 替换位（按组算，不按行算）
- **直接映射**：不需要 LRU 位（0 位）
- **全相联**：1 组，LRU 位数 = log2(路数)
- **N路组相联**：LRU 位数 = 组数 × log2(路数)
- **注意**：4 路组相联，每组需要 log2(4) = 2 位。

### 4. 最终总容量公式
Cache总容量 = 数据区位数 + (行数 × 每行附加位) + LRU位数

## 六、避坑指南（易错点与口误纠正）

1. **绝对不要把“总行数”和“组数”搞混！**
   - 正确的公式是：**总行数 ÷ 路数 = 组数**。
   - 千万不要说成“组数 ÷ 路数 = 组数”，这是错的。比如 64行 ÷ 4路 = 16组。
2. **按字节编址**：默认 1B = 8 位，地址位数算出来后，容量算“位”时一定要乘 8。
3. **写回策略才有脏位**：题目若没提写策略，默认写回（有时默认写直达，看题目习惯）。
4. **LRU 位按组算**：4 路组相联每组 2 位，共有多少组就乘多少。
5. **Cache 数据区容量 ≠ Cache 总容量**：总容量必须加 Tag、有效位、脏位、LRU 位。
6. **索引是 Cache 的组号，不是主存的索引**。索引位数由 Cache 的组数决定。
7. **直接映射也有索引**！直接映射是 1 路组相联，组数 = 总行数，索引位数 = log2(总行数)。

### 模板A：4路组相联 第(1)问 主存地址划分

```
解：

(1) 主存地址划分

① 主存地址总位数：
   64MB = 2^26 B
   按字节编址，地址总位数 = 26 位

② 块内偏移位数：
   块大小 64B = 2^6 B
   偏移位数 = log2(64) = 6 位
   位置：A5 ~ A0

③ Cache总行数：
   行数 = Cache数据区容量 ÷ 块大小
        = 4KB ÷ 64B
        = 4096B ÷ 64B
        = 64 行

④ 组数：
   4路组相联，组数 = 总行数 ÷ 路数
                  = 64 ÷ 4
                  = 16 组

⑤ 组索引位数：
   组索引位数 = log2(16) = 4 位
   位置：A9 ~ A6

⑥ Tag位数：
   Tag位数 = 总位数 - 索引位数 - 偏移位数
           = 26 - 4 - 6
           = 16 位
   位置：A25 ~ A10

⑦ 主存地址格式：
   ┌──────────┬──────────┬──────────┐
   │   Tag    │  组索引  │ 块内偏移 │
   │  16 位   │   4 位   │   6 位   │
   └──────────┴──────────┴──────────┘
   位置：A25~A10 | A9~A6 | A5~A0

   各字段含义：
   - Tag：标识主存块，用于和Cache中的Tag比较
   - 组索引：选择Cache的16组中的某一组
   - 块内偏移：选择64B块内的某个字节
```

### 模板B：4路组相联 第(2)问 Cache总容量

```
(2) Cache总容量

① 数据区容量：
   4KB = 4096B = 4096 × 8 = 32768 位

② 每行附加信息：
   Tag：16 位
   有效位：1 位
   脏位：1 位（写回策略）
   每行附加 = 16 + 1 + 1 = 18 位

③ 所有行附加信息总计：
   64 行 × 18 位 = 1152 位

④ LRU替换位：
   4路组相联，每组需要 log2(4) = 2 位
   共16组：16 × 2 = 32 位

⑤ Cache总容量：
   32768 + 1152 + 32 = 33952 位
   = 4244 B

答：Cache总容量为 33952 位（或 4244 B）。
```

### 考试提速口诀

```
一看映射定几块：
  全相联 → 2块
  直接/组相联 → 3块

二算总位看主存：
  容量化2^n，n就是总位数

三算偏移看块大小：
  块大小化2^m，m就是偏移位数

四算行数看Cache：
  行数 = Cache容量 ÷ 块大小

五算组数看路数：
  组数 = 行数 ÷ 路数（直接映射路数=1，全相联组数=1）

六算索引取对数：
  索引位数 = log2(组数)

七算Tag用减法：
  Tag = 总位数 - 索引 - 偏移

八算容量三部分：
  数据区 + 行附加 + LRU位
```

## 八、例题速查

| 题目条件 | 主存地址部分数 | 地址格式 |
| :--- | :---: | :--- |
| 直接映射 | 3 部分 | Tag + 索引 + 偏移 |
| 4路组相联 | 3 部分 | Tag + 索引 + 偏移 |
| 全相联映射 | 2 部分 | Tag + 偏移 |

**示例：4路组相联，64MB主存，4KB Cache，64B块**
- 总位数：log2(64MB) = 26 位
- 偏移：log2(64B) = 6 位
- 行数：4KB / 64B = 64 行
- 组数：64 / 4 = 16 组
- 索引：log2(16) = 4 位
- Tag：26 - 4 - 6 = 16 位
- 地址格式：`Tag(16) | 索引(4) | 偏移(6)`

## 九、一句话总结

**索引选组，Tag 选行，偏移选字节。**
总行数 = Cache容量 ÷ 块大小 （箱子能装多少格子）
组数 = 总行数 ÷ 路数 （几个格子打成一包）
索引位数 = log2(组数) （给包编号需要几位）
Tag位数 = 总位数 - 索引位数 - 偏移位数 （剩下的全部给 Tag）
