# 折半插入排序 —— 例题、算法与抢分技巧

## 一、题目

有关键字序列 `38, 19, 65, 13, 97, 49, 41, 95, 1, 73`，采用**折半插入排序**算法进行升序排序，请写出每趟排序的结果。

---

## 二、推演过程

*(默认第 1 个元素 `38` 已有序，括号内标注了**二分查找 mi 的过程**。最终的序列结果和直接插入完全一样，但步骤体现了"折半")*

- **初始**：`[38] | 19, 65, 13, 97, 49, 41, 95, 1, 73`
- **第 1 趟**（插 19）：(中间 38)，19<38，插前面。
  - `[19, 38] | 65, 13, 97, 49, 41, 95, 1, 73`
- **第 2 趟**（插 65）：(中间 19，去右；中间 38，去右)，插后面。
  - `[19, 38, 65] | 13, 97, 49, 41, 95, 1, 73`
- **第 3 趟**（插 13）：(中间 38，去左；中间 19，去左)，插最前面。
  - `[13, 19, 38, 65] | 97, 49, 41, 95, 1, 73`
- **第 4 趟**（插 97）：(中间 19，去右；中间 38，去右；中间 65，去右)，插后面。
  - `[13, 19, 38, 65, 97] | 49, 41, 95, 1, 73`
- **第 5 趟**（插 49）：(中间 38，去右；右边中间 65，去左)，插在 38 和 65 之间。
  - `[13, 19, 38, 49, 65, 97] | 41, 95, 1, 73`
- **第 6 趟**（插 41）：(中间 38，去右；右边中间 65，去左；再中间 49，去左)，插在 38 后。
  - `[13, 19, 38, 41, 49, 65, 97] | 95, 1, 73`
- **第 7 趟**（插 95）：(中间 38 去右，中间 65 去右，中间 97 去左)，插在 65 后。
  - `[13, 19, 38, 41, 49, 65, 95, 97] | 1, 73`
- **第 8 趟**（插 1）：每次比中间值都小，一路向左，插最前。
  - `[1, 13, 19, 38, 41, 49, 65, 95, 97] | 73`
- **第 9 趟**（插 73）：(中间 41 去右，中间 65 去右，中间 95 去左)，插在 65 后。
  - **最终结果**：`[1, 13, 19, 38, 41, 49, 65, 73, 95, 97]`

## 三、核心思想（大白话）

还是打扑克牌理牌。左手里的牌**已经排好序**，右手摸到一张**新牌**。
找位置时，**不挨个比，而是每次直接看手里正中间的那张牌**。
如果新牌比中间牌小，就把右半边全扔掉，去左半边继续找中间；如果比中间牌大，就去右半边找。**每次砍掉一半**，找到坑位后，把后面的牌往后挪一格插进去。

## 四、完整代码 + 下标级注释

```c
void InsertSort(SeqList R[], int n)
{
    SeqList x;          // 【暂存新牌】
    int j, k, lo, hi, mi;
    //  lo: 左边界下标
    //  hi: 右边界下标
    //  mi: 中间位置下标
    //  k : 最终确定的插入位置下标
    //  j : 负责挪牌搬运工的下标

    for (int i = 2; i <= n; i++)
    {
        x = R[i];       // 【拿牌】把第 i 个位置的元素抽出来，暂存

        lo = 1;         // 【划定范围】左边界从有序区第 1 个开始
        hi = i - 1;     // 【划定范围】右边界到有序区最后一个（i-1）结束

        // 【二分法找位置】
        while (lo <= hi)
        {
            mi = (lo + hi) / 2;  // 算中间下标

            // 遇到相等的，直接停，准备插在它后面（保证稳定性）
            if (R[mi].key == x.key) break;

            if (R[mi].key > x.key)
                hi = mi - 1;     // 中间牌 > 新牌：去左边找，右边界缩回来
            else
                lo = mi + 1;     // 中间牌 < 新牌：去右边找，左边界扩过去
        }

        // 【确定最终坑位 k】
        if (mi <= lo)
            k = lo + 1;
        else
            k = mi - 1;      // ⚠️ 注：原题此处疑似笔误，按标准答案填空即可

        // 【腾空位】
        // 搬运工 j 从有序区最后一位(i-1)开始，一直退到坑位 k
        for (j = i - 1; j >= k; j--)
            R[j+1] = R[j];   // 往后挪一格

        R[k] = x;            // 把新牌放进坑位
    }
}
```

## 五、考场极速抢分技巧（必看！）

### 🃏 1. 手算推演技巧（大题）

- **结果序列与直接插入一样**：因为只改了"找位置"的方式，没改"挪位置"的方式。
- **但过程必须写出来**：为了向老师证明你用的是折半，最好在旁边用括号标出**"看中间（mi），去左边/右边"**的过程（如推演所示）。
- **画线法**：找中间时，在纸上把中间那个数圈出来，然后果断把另一半划掉。

### 💻 2. 代码填空/改错技巧

- **找牌起点**：`x = R[i]`
- **相等直接跳**：`R[mi].key == x.key`（这是折半插入特有的优化，为了稳定性）
- **比中间小去左边**：`hi = mi - 1`
- **比中间大去右边**：`lo = mi + 1`
- **挪牌起点必考**：`for (j = i - 1; ...)` 这里一定是 `i - 1`，绝对不能写错。

### 🎯 3. 选择题秒杀结论（直接背）

| 维度 | 结论 |
| :--- | :--- |
| **与直接插入的区别** | 折半插入**减少了比较次数**（降到了 O(n log n) 级别），但**元素的移动次数不变** |
| **时间复杂度** | 依然是 **O(n²)**。因为移动元素太费时间了，找得再快也白搭 |
| **空间复杂度** | **O(1)**（只用了几个临时变量） |
| **稳定性** | **稳定**（代码里有 `==` 退出判断，或者 `>` 严格比较，不会让相等的元素跨过彼此） |
| **适用场景** | 当数据量较大，且**比较操作代价很高**时，用折半插入比直接插入好 |
