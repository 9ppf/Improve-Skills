# 单链表（带头结点）插入操作 做题笔记

## 一、核心概念与前提条件
- **【知识点】定义**：单链表是一种链式存储的线性表，每个结点包含数据域和指向下一个结点的指针域。
- **【适用前提】**：题目明确指出为**“带头结点”**的单链表。这意味着链表中存在一个不存有效数据的“虚结点”（头结点），`head` 指针永远指向它。
- **【核心原则】**：
  - **原则1（head不可变）**：在带头结点的链表中，无论进行何种插入/删除操作，`head` 指针的值绝对不能改变。真正指向第一个数据结点的永远是 `head->next`。
  - **原则2（先连后断）**：在修改指针时，必须先让新结点连接后面的链表（防断链），再让前驱结点连接新结点。
- **【易混概念对比】**：
  - `p`：指针变量，存地址。
  - `p->next`：指针域，存下一个结点的地址。
  - `head`：头指针（指向头结点）。
  - `head->next`：首元结点（真正的第一个数据结点）。

## 二、通用做题步骤（画图四步法）
1. **【第一步：画初始状态（准备）】**：
   - 画出头指针 `head`、头结点、首元结点（原一号结点）以及新结点 `p`。
   - 标出初始的箭头指向关系：`head` -> 头结点 -> 首元结点；`p` 孤立。
2. **【第二步：画目标状态与核心处理】**：
   - 明确操作完成后的最终结构：`head` -> 头结点 -> **新结点 p** -> 首元结点。
   - 操作细节 A（连后面）：让新结点 `p` 指向原来的首元结点。代码：`p->next = head->next;`
   - 操作细节 B（连前面）：让头结点的 `next` 指向新结点 `p`。代码：`head->next = p;`
3. **【第三步：结束条件（验证）】**：
   - 顺着箭头走一遍：能否从 `head` -> 头结点 -> `p` -> 首元结点 -> 后续结点顺利走完，且没有死循环。

## 三、进阶考点与核心推导

### 1. 时间复杂度
- **概念解释**：带头结点的表头插入操作，不需要遍历链表寻找前驱结点（因为前驱永远是头结点）。
- **关系**：时间复杂度为 **O(1)**。这是单链表相较于顺序表在表头插入的巨大优势（顺序表为 O(n)）。

### 2. 头结点存在的意义
- **统一操作**：如果不带头结点，在空表插入和在表头插入需要单独判断并修改 `head` 指针（`head = p`）；在表中间插入则不需要。带头结点后，所有位置的插入/删除操作代码逻辑完全一致，减少了边界条件的判断。

## 四、易错点总结（排雷区）

| 易错点（错误做法） | 正确做法（避坑指南） |
| :--- | :--- |
| 写出 `head=p;` （以为 head 是指向第一个数据结点的） | 牢记题干“带头结点”，`head` 永远指向头结点，只能改 `head->next=p;` |
| 先执行 `head->next=p;`，再执行 `p->next=head->next;` | 会导致原链表后续结点地址丢失（断链），且 `p->next` 会指向自己。必须先连后断。 |
| 把 `p->next` 理解为“p 的指针”。 | `p` 是结点地址，`p->next` 是结点内部的指针域，修改它不会改变 `p` 的位置。 |
| 形成 `p->next = head;` （死环） | `p` 应该连接的是原一号结点（`head->next`），而不是连接头结点 `head`。 |

## 五、例题补充

### 例题 1：求正确的语句序列（原题）

**题目**：已知 `head` 为指向带头结点的单链表的头指针，指针变量 `p` 指向一个新结点，`next` 是结点的指针域，若要将 `p` 所指结点插入到单链表的表头，则正确的语句序列是（ ）。
A. `head->next=p; p->next=head;`
B. `p->next=head->next; head=p;`
C. `head=p; p->next=head->head;`
D. `p->next=head->next; head->next=p;`

**解题过程**：
| 步骤 | 头结点状态 | p 的 next 指向 | 操作/判断 |
| :--- | :--- | :--- | :--- |
| 初始 | `head` 指向头结点 | 未知（新结点） | 目标是插在 head 和原一号结点之间 |
| 执行 A | 指向 `p` | 指向 `head` | 原一号结点丢失（断链），且形成 `head` <-> `p` 死环，错误。 |
| 执行 B | 不变 | 指向原一号结点 | `head=p` 改变了头指针，使其变成了不带头结点的链表，错误。 |
| 执行 D | 不变 | 指向原一号结点 | `head->next=p` 完美接上表头，符合“先连后断”原则，正确。 |

**答案**：D
**解析/避坑提示**：看到“带头结点”，秒排选项 B、C，因为它们改变了 `head`；选项 A 违反“先连后断”原则。

---

### 例题 2：对比题型（不带头结点）

**题目**：若单链表**不带头结点**，`head` 指向第一个数据结点。将 `p` 插入表头的正确语句是？

**解析**：
- 因为不带头结点，`head` 直接指向首元结点。
- 插入时，需要让 `p` 的 `next` 指向原首元结点（`p->next = head;`），然后再将 `head` 移到 `p`（`head = p;`）。

**答案**：`p->next = head; head = p;`

## 六、一句话记忆

> **带头结点插表头，head绝对不能动；**  
> **先让新点连旧点，再让头点连新点。**
