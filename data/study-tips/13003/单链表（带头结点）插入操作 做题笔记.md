# 单链表核心操作与避坑笔记

## 💡 核心铁律
> **单链插入要防丢，先连后断是铁律。**
> **若有后驱 p 在手，先断后连也可以。**

---

## 一、核心概念辨析

- **头指针（head）**：永远指向头结点（带头结点）或首元结点（不带头结点）。
- **头结点**：不存有效数据，只为统一操作。
- **首元结点**：真正的第一个数据结点。带头结点时，首元结点是 `head->next`；不带头结点时，首元结点就是 `head`。
- **p 与 p->next**：`p` 是指针变量（存地址）；`p->next` 是结点内部的指针域（存下一个结点的地址）。

---

## 二、⭐ 单链表判空（极易混淆的送命题）

> ⚠️ **注意**：单链表是动态分配内存的，只要内存够，链表可以无限长，因此**链式存储没有"判满"**，只需掌握"判空"。

### 1. 带头结点的单链表（看 next）

- **代码**：`head->next == NULL`
- **原理**：`head` 永远指向头结点。头结点后面没有人（`next` 为空），说明表里没有数据。

```text
        head
         ↓
    [ 头结点 | next ] ---> NULL
```

### 2. 不带头结点的单链表（看 head）

- **代码**：`head == NULL`
- **原理**：`head` 直接就是第一个数据结点。连第一个结点都没有，说明表为空。

```text
        head
         ↓
       NULL
```

## 三、题型 1：表头插入

表头插入分为两种情况，代码完全不同。

### 1. 带头结点的表头插入（head 不变）

**题目**：将 `p` 插入带头结点的单链表表头。

**正确代码**：
```c
p->next = head->next;
head->next = p;
```

**解析**：`head` 永远指着头结点。先让新结点 `p` 连上原首元结点；再让头结点指向 `p`。

```text
     变量head             变量p
       ↓                     ↓
  [ 头结点 | next ]  ->  [ 数据p | next ]  ->  [ 原数据1 | next ] -> ...
```

### 2. 不带头结点的表头插入（head 改变！）

**题目**：将 `p` 插入不带头结点的单链表表头。

**正确代码**：
```c
p->next = head;
head = p;
```

**解析**：`head` 直接指向首元结点。必须先连后移。先让 `p` 指向原 `head`，再把 `head` 指针移到 `p` 上。

```text
     变量head
       ↓
  [ 数据p | next ]  ->  [ 原数据1 | next ] -> ...
```

💣 **避坑**：千万不能先写 `head = p;`，否则原链表丢失，且 `p->next = p` 会形成死环。

---

## 四、题型 2：已知前驱和后继（已知 q 和 p）

**题目**：已知 `q` 是 `p` 的前驱，在 `q` 和 `p` 之间插入 `s`。

**正确代码**：
```c
q->next = s;
s->next = p;    // 或反过来写也行
```

**解析**：手里有 `p` 指针，即使先断了 `q` 到 `p` 的线，也能找回来。

```text
     变量q                 变量s                 变量p
       ↓                     ↓                     ↓
  [ 数据q | next ]  ->  [ 数据s | next ]  ->  [ 数据p | next ] -> ...
```

---

## 五、题型 3：只知前驱（未知后继）

**题目**：已知单链表中 `q` 结点，在 `q` 后插入 `s`。

**正确代码**：
```c
s->next = q->next;    // 先连后
q->next = s;          // 再断前
```

**解析**：手里没有后继结点的指针，必须**先连后断**。如果先写了 `q->next = s;`，后面的整条链表将彻底丢失！

```text
     变量q                 变量s
       ↓                     ↓
  [ 数据q | next ]  ->  [ 数据s | next ]
                              |
                              ↓
                         [ 原q的后继 | next ] -> ...
```

---

## 六、易错点排雷

| 易错点（错误做法） | 正确做法（避坑指南） |
| :--- | :--- |
| 乱改 head：带头结点时写出 `head = p;` | `head` 永远指向头结点，只改 `head->next` |
| 断链：不带头结点插入先写了 `head = p;`；或未知后继插入先写了 `q->next = s;` | **先连后断**是铁律，除非手里有后继指针可以先断 |
| 死环：写出 `p->next = head`（且没先保存原 head） | 先连新的，再断旧的，就不会死环 |
| 判空搞混：题干说"带头结点"却选 `head == NULL` 作判空 | 带头看 `next == NULL`，不带头才看 `head == NULL` |
