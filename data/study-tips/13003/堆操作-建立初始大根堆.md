# 堆操作 —— 建立初始大根堆（最大堆）

## 一、题目

将数据序列 `70, 12, 30, 1, 5, 31, 44, 56, 61` 建成一个**最大堆**。

---

## 二、推演过程（图解建堆法）

建堆核心口诀：**从最后一个非叶子节点开始，从后往前，依次向下调整**。

数组长度 n = 9，最后一个非叶子节点的下标是 `n / 2 = 9 / 2 = 4`（向下取整）。

**初始状态**：`[70, 12, 30, 1, 5, 31, 44, 56, 61]`

先把它想象成一棵完全二叉树：

```text
             70(1)
           /       \
       12(2)       30(3)
      /    \       /    \
    1(4)   5(5) 31(6) 44(7)
   /   \
 56(8) 61(9)
```

| 步骤 | 调整节点（下标/值） | 操作 | 当前数组 |
| :--- | :--- | :--- | :--- |
| 第 1 步 | 节点 4，值 = 1 | 孩子 56、61，最大 61。1 < 61，交换。 | `70, 12, 30, 61, 5, 31, 44, 56, 1` |
| 第 2 步 | 节点 3，值 = 30 | 孩子 31、44，最大 44。30 < 44，交换。 | `70, 12, 44, 61, 5, 31, 30, 56, 1` |
| 第 3 步 | 节点 2，值 = 12 | 孩子 61、5，最大 61。12 < 61，交换。**连锁反应**：12 沉到节点 4，继续比 56、1，最大 56。12 < 56，再交换。 | `70, 61, 44, 56, 5, 31, 30, 12, 1` |
| 第 4 步 | 节点 1，值 = 70 | 孩子 61、44，最大 61。70 > 61，符合规则，**不交换**。 | 不变 |

🏁 **建堆完成**，最终结果：**`70, 61, 44, 56, 5, 31, 30, 12, 1`**

对应的大根堆树形结构（每个父节点都 ≥ 子节点）：

```text
           70(1)
         /       \
     61(2)       44(3)
    /    \       /    \
 56(4)  5(5) 31(6) 30(7)
 /
12(8)  1(9)
```

## 三、建堆通用步骤与考场口诀

### 🛠️ 通用操作步骤：

1. **画图**：在草稿纸上把数组按顺序画成一棵**完全二叉树**。
2. **找起点**：找到**最后一个非叶子节点**，下标 = `n / 2`（向下取整）。
3. **从后往前查**：从这个起点开始，依次向前（直到下标 1 的根节点），对每一个非叶子节点执行向下调整。
4. **向下调整**：对比该节点与其左右孩子，找出**最大值（建大堆）或最小值（建小堆）**。
5. **交换与连锁**：把最值换到父节点位置。**⚠️ 陷阱：如果发生交换，被换到下面的那个元素若还有孩子，必须继续往下比，直到它比孩子大（或小），或者落到叶子节点为止。**

### 💡 考场极简口诀（建议默写前默念三遍）：

> **建大堆，找 n/2。左、根、右挑最大，最大顶上去。换下来的接着往下比，直到到底为止。**

---

## 四、核心思想（大白话）

把这堆数字当成一个公司，每个上级必须比下级能力（数字）强。

建堆就像查腐败：**从最底层的包工头（最后一个非叶子节点）开始往上查**。

如果包工头发现自己的手下（左右孩子）比自己强，就把自己降级，让最强的手下坐自己的位置。降级后的包工头如果下面还有小弟，得继续往下比。这样一轮查完，董事长（根节点）绝对是全公司最强的。

## 五、完整代码 + 下标级注释

（数组下标从 1 开始，`R[0]` 通常作为暂存哨兵）

```c
// 核心调整函数：将以 k 为根的子树调整为大根堆
void HeapAdjust(SeqList R[], int k, int len)
{
    R[0] = R[k]; // R[0] 暂存根节点的值（哨兵）

    // 沿较大的子节点向下筛选 (2*k 是左孩子)
    for (int i = 2 * k; i <= len; i = i * 2)
    {
        // 如果右孩子存在，且右孩子 > 左孩子，i 指向右孩子
        if (i < len && R[i].key < R[i + 1].key)
            i++;

        // 根节点比大孩子还大，说明不用调了，跳出
        if (R[0].key >= R[i].key) break;
        else
        {
            R[k] = R[i]; // 把大孩子换上来
            k = i;       // 根节点换到下面去了，k 跟着移动，继续往下比
        }
    }
    R[k] = R[0]; // 把最开始暂存的根节点，放入最终的空位
}

// 建堆主函数
void BuildMaxHeap(SeqList R[], int n)
{
    // 从最后一个非叶子节点(n/2)倒着往前调
    for (int i = n / 2; i > 0; i--)
    {
        HeapAdjust(R, i, n);
    }
}
```

## 六、考场极速抢分技巧与答题规范（必看）

### ✍️ 1. 卷面答题规范与手算技巧

- **一定要画树形图**：在草稿纸上把数组画成完全二叉树，看着图做，绝不出错。
- **做标记**：每次向下调整时，把被比较的三个节点（根、左、右）圈出来，防止看错。
- **卷面格式**：如果题目要求写出"过程"，就像笔记里一样，写出每一步调整后的数组，并标明"调整节点 X"。如果只要求"最大堆"，写出最终序列即可。

### 🃏 2. 检查对错的秒杀技巧

- **公式验证**：写完最终序列后，对所有非叶子节点 i，必须满足 `R[i] >= R[2i]` 且 `R[i] >= R[2i+1]`。有违背就说明没调干净。
- **找最大值**：最大堆的第一个元素（数组第 1 个位置），必须是整个数组里的最大值。

### 🎯 3. 选择题秒杀结论（直接背）

| 维度 | 结论 |
| :--- | :--- |
| **升序排序建什么堆？** | 大根堆（为了每次把最大的放到末尾） |
| **降序排序建什么堆？** | 小根堆（为了每次把最小的放到末尾） |
| **建堆时间复杂度** | **O(n)**。虽然每次向下调整是 O(log n)，但整体建堆的数学推导结果就是 O(n)，**不要记错成 O(n log n)** |
| **稳定性** | **不稳定**（把末尾元素换到堆顶，会破坏相同元素的相对顺序） |
