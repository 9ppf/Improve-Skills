# 时间复杂度与复杂度常考点笔记

> **复习策略**：重基础结论、记前提条件、背秒杀口诀。专升本极少考复杂的代码推导，直接背结论即可拿分。

## 一、🌟 绝对必背：经典排序算法属性表（必考）

| 排序算法 | 平均时间复杂度 | 最坏时间复杂度 | 最好时间复杂度 | 空间复杂度 | 稳定性 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **直接插入排序** | O(n²) | O(n²) | **O(n)** | O(1) | ✅ **稳定** |
| **冒泡排序** | O(n²) | O(n²) | **O(n)** | O(1) | ✅ **稳定** |
| **简单选择排序** | O(n²) | O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| **希尔排序** | O(n^1.3) | O(n²) | 无定论 | O(1) | ❌ 不稳定 |
| **快速排序** | **O(nlogn)** | **O(n²)** | O(nlogn) | O(logn) | ❌ 不稳定 |
| **堆排序** | **O(nlogn)** | O(nlogn) | O(nlogn) | O(1) | ❌ 不稳定 |
| **归并排序** | **O(nlogn)** | O(nlogn) | O(nlogn) | **O(n)** | ✅ **稳定** |
| **基数排序** | O(d(n+r)) | O(d(n+r)) | O(d(n+r)) | O(n+r) | ✅ **稳定** |

### 💡 考场秒杀口诀：

1. **平均 O(nlogn) 的算法**："**快、归、堆**"（快速、归并、堆排序）。
2. **不稳定的算法**："**快、些、选、堆**"（快速、**希尔**、选择、堆排序）。
   > *除这四个外，其他常考算法（冒泡、插入、归并、基数）全是稳定的。*
3. **空间复杂度特殊点**：归并排序需要 **O(n)**，快速排序需要 **O(logn)**，其余基本为 O(1)。
4. **最坏情况特殊点**：快速排序最坏是 **O(n²)**（当数组本身有序时发生）。

## 二、🔍 查找算法的复杂度

1. **顺序查找**：无序/有序，平均时间复杂度均为 **O(n)**。
2. **折半查找（二分查找）**：
   - 时间复杂度：**O(log₂n)**。
   - ⚠️ **前提大坑**：必须是**顺序存储（数组）** + **有序**。如果是"链表"，则不能用折半查找！
3. **哈希表（散列表）**：
   - **平均**时间复杂度：**O(1)**。
   - **最坏**时间复杂度：**O(n)**（发生极端冲突时）。

---

## 三、📦 基础数据结构操作复杂度

1. **顺序表（数组）**：
   - 按位置查找（随机访问）：**O(1)**。
   - 插入 / 删除：**O(n)**（因为要移动后续元素）。
2. **单链表**：
   - 查找第 i 个元素：**O(n)**。
   - 已知节点 p 之后插入/删除：**O(1)**。
3. **栈和队列**：入栈/出栈、入队/出队，统统都是 **O(1)**。
4. **二叉树**：前序、中序、后序遍历，求树深，时间复杂度均为 **O(n)**（每个节点访问一次）。

## 四、💻 简单代码段复杂度分析（选择题常客）

看代码算复杂度，主要看**循环层数**和**循环变量的变化步长**：

1. **单层循环**：循环 n 次，复杂度为 **O(n)**。

```c
for(int i=0; i<n; i++) { ... }
```

2. **简单的双层循环**：一般就是 **O(n²)**。

```c
for(int i=0; i<n; i++)
  for(int j=0; j<n; j++) { ... }
```

3. ⚠️ **循环变量成倍增长**：看到 `i *= 2` 或 `i = i * 2`，答案一定是 **O(log₂n)**。

```c
for(int i=1; i<=n; i=i*2) { ... } // O(log₂n)
```

4. **常数级 O(1)**：没有循环，或者循环次数是固定的（比如固定循环 100 次）。

## 五、🕸️ 图的基础复杂度（记结论即可）

假设顶点数为 n，边数为 e：

- **邻接矩阵存储图**：
  - 空间复杂度：O(n²)。
  - 遍历（DFS/BFS）时间复杂度：O(n²)。
- **邻接表存储图**：
  - 空间复杂度：O(n+e)。
  - 遍历（DFS/BFS）时间复杂度：O(n+e)。

## 🛑 专升本避坑指南

- **看题眼**：题目问的是"平均"还是"最坏"？如果没有特别说明，默认指最坏情况。
- **建堆的时间复杂度**：将无序数组建成堆的时间复杂度是 **O(n)**。（注意：不是 O(nlogn)，这是常考易错点）。
- **O(1) 的含义**：不是指代码只有一行，而是指执行次数是常数（固定数字），与数据规模 n 无关。
