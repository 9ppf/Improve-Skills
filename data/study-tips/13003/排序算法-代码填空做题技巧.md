# 🎯 数据结构算法代码填空：通用套路与秒杀技巧

> **使用方法**：先看「四看一猜」法审题，再按「填空眼」特征定位算法类型，最后用「防坑检查法」复查三遍。所有代码示例中 **`____`** 就是考研填空题大概率会被挖掉的位置。

遇到代码挖空题，不要慌。先按照「四看一猜」法审题，再对照各算法的「填空眼」找特征，最后用「防坑指南」复查。

---

## 一、通用解题方法论（「四看一猜」法）

不管什么算法，拿到填空题先看这四个地方，再代入验证一次。

### 👀 1. 看题干（抓核心词）
* **找关键词**：题干里写了"返回…位置"、"删除…结点"、"升序…排序"
* **作用**：这决定了函数最终要输出什么，也决定了最后一个空（通常在 `return` 那里）填什么

### 👀 2. 看变量（找「工具人」）
* 快速扫一眼开头定义的变量
* `temp` 一般是遍历指针，`count` 是计步器，`flag` 是标志位，`i/j/k` 是下标指针——看名字就能猜出它们是干嘛的

### 👀 3. 看 `if` 语句（防坑守卫）
* **规律**：`if` 往往用来处理「异常情况」或「边界条件」
* **答题**：看到 `if (指针 == NULL)`，后面多半跟着 `return 0;` 或 `return -1;` 报错；两个边界条件通常用 `||`（或）连接

### 👀 4. 看 `while` 循环（找漏掉的拼图）
* **看循环条件**：决定什么时候继续走
* **看循环体**：最关键的空！通常缺两样：
  1. **移动指针**：`temp = temp->next;`（不移动必死循环）
  2. **计数/标记**：找位置必然有 `count++;` 或 `i++;`

### 🧪 5. 代入极简数据验证（一猜）
填完空之后，**画一个只有 1 个结点/空链表/长度为 1 的数组**，在脑子里跑一遍：
- 会不会死循环？
- 会不会对 `NULL` 取 `->next`？
- 算出来的结果对不对？

## 二、各算法「填空眼」秒杀技巧

看到这些特征，直接联想对应代码。

### 🔵 插入类排序（直接插入、折半插入、希尔排序）
**核心动作**：拿牌 → 找位置 → 腾空位 → 插入

#### 1. 直接插入排序（边找边挪）
* **【拿牌暂存】**（必考）：
```c
x = R[i]; // 把当前要插入的元素抽出来
```
* **【边找边挪条件】**（必考，防越界）：
```c
while ( j >= 1 && R[j].key > ____ ) // ⚠️ j>=1 不能漏！
```
* **【挪牌动作】**（必考）：
```c
R[j+1] = ____; // 把前面的元素往后挪一格
```
* **【插入回填】**：
```c
R[j+1] = x; // 跳出循环后，x 填回 j+1 位置
```

#### 2. 折半插入排序（二分找位置）
* **【初始化边界】**：
```c
lo = 1; hi = i - 1;
```
* **【折半循环条件】**：
```c
while ( lo <= hi )
```
* **【缩小区间方向】**：
```c
if (R[mi].key > x.key) hi = ____; // 大了去左边
else lo = ____; // 小了去右边
```
* **【挪牌起点】**（必考）：
```c
for (j = ____; j >= k; j--) // 起点一定是 i-1，不能写错！
```

#### 3. 希尔排序（分组插入）
* **【核心特征】**：直接插入里的 `1` 全换成增量 `d`
* **【挪牌跨度 & 指针跳转】**（必考）：
```c
R[j+d] = ____; // 往后挪 d 格
j = ____; // 往前跳 d 格
```
* **【外层循环控制增量】**：
```c
for (d = n/2; d >= 1; ____) // 每次 d 折半
```

### 🟢 交换类排序（冒泡、快速排序）
**核心动作**：两两比较，反序则交换

#### 1. 冒泡排序
* **【内层循环边界】**（必考）：
```c
for (j = 1; j <= ____; j++) // 每趟沉底一个最大数，所以到 n-i
```
* **【比较条件】**：
```c
if ( R[j].key ____ R[j+1].key ) // 升序是 >，降序是 <
```
* **【优化标志位】**：
```c
if (flag == 0) ____; // 整趟没交换，已有序，直接退出
```

#### 2. 快速排序（挖坑填数）
* **【暂存基准（挖坑）】**：
```c
pivot = R[____]; // 通常是 R[low]，也有 R[high] 或随机
```
* **【右找小填左坑】**（必考）：
```c
while (low < high && R[high].key ____ pivot.key) high--;
R[low] = R[high];
```
* **【左找大填右坑】**（必考）：
```c
while (low < high && R[low].key ____ pivot.key) low++;
R[high] = R[low];
```
* **【基准归位】**：
```c
R[low] = ____; // 循环结束，两指针相遇，基准填回
```
* **【递归调用】**（必考，分左右）：
```c
QuickSort(R, low, ____); // 左半区
QuickSort(R, ____, high); // 右半区
```

### 🟡 选择类排序（简单选择、堆排序）
**核心动作**：找最大/最小，放到指定位置

#### 1. 简单选择排序
* **【记录极值下标】**（必考）：
```c
k = ____; // 假设当前位置 i 就是最小
if ( R[j].key ____ R[k].key ) k = j; // 发现更小的，更新 k
```
* **【一趟一换】**：
```c
if ( ____ ) { // 最小值不在 i 位置才交换
    temp = R[i]; R[i] = R[k]; R[k] = temp;
}
```

#### 2. 堆排序（向下调整 HeapAdjust）
* **【找左孩子】**（必考）：
```c
i = ____; // 左孩子 = 2*k
```
* **【找最大孩子】**（必考，⚠️ 别漏 `i < len` 判断）：
```c
if ( i < len && R[i].key ____ R[i+1].key ) i++; // i 指向左右孩子中较大的
```
* **【父子比较退出条件】**：
```c
if ( R[0].key ____ R[i].key ) break; // 根比大孩子还大，不用调了
```
* **【孩子上位 + 指针下移】**：
```c
R[k] = ____; // 大孩子换上来
k = ____; // 根节点换到下面去，继续往下比
```
* **【建堆起点】**（必考）：
```c
for (i = ____; i > 0; i--) // 从最后一个非叶子节点 n/2 往前调
```

### 🔴 链表与查找类
#### 1. 单链表找指定结点位置
* **【无效判断（双条件）】**（必考）：
```c
if ( *head == NULL || ____ ) return 0; // 用 || 连接
```
* **【循环遍历条件】**：
```c
while (temp != curr && ____) // 既要没找到目标，又要没到末尾
```
* **【移动指针 + 计数】**（必考）：
```c
temp = ____; // 不移动必死循环
count++;
```
* **【返回位置】**：
```c
return ____; // 位置从 1 开始计
```

#### 2. 二分查找（折半查找）
* **【循环条件】**（必考，⚠️ 不是 `low < high`！）：
```c
while ( ____ ) // 必须是 low <= high
```
* **【计算中间位置】**：
```c
mid = ____; // (low + high) / 2
```
* **【缩范围方向】**：
```c
if (arr[mid] > key) high = ____; // 大了往左
else low = ____; // 小了往右
```

## 三、终极防坑检查法（填空写完必看）

| # | 坑点 | 检查方法 | 后果 |
|:---:|------|----------|------|
| 1 | **防越界** | 数组下标做减法（如 `j--`）时，前面有没有 `j >= 1` 守卫？ | 死循环 / 内存越界崩溃 |
| 2 | **防死循环** | 二分/快排里的边界更新能不能跨过彼此？（必须是 `+1` / `-1`，不能是 `= mi` 或 `= low`） | 永远在中间跳不出去 |
| 3 | **防漏分号** | 空后面有分号的，你填空里千万别带分号 | 编译错误 |
| 4 | **防指针不动** | 链表/遍历类循环里，有没有 `temp = temp->next;`？ | 卡在第一个结点永远不动 |
| 5 | **防交换方向** | 冒泡/快排的比较符号：升序是 `>`，降序是 `<`，别写反 | 排序方向完全错 |
| 6 | **防堆调整漏哨兵** | 堆排序里 `R[0] = R[k];` 这句有没有？（哨兵暂存根节点） | 调整逻辑乱套 |
| 7 | **防返回值语义** | 返回的是"位置"还是"状态码"？位置从 1 开始计，状态码 0/-1 表示失败 | 答案语义错 |
