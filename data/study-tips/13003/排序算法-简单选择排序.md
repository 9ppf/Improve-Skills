# 简单选择排序 —— 例题、算法与抢分技巧

## 一、题目

有关键字序列：`38, 19, 65, 13, 97, 49, 41, 95, 1, 73`，采用**简单选择排序**算法进行升序排序，请写出每趟排序的结果。

---

## 二、推演过程

*(核心规则：每一趟从剩下的无序区里挑出一个**最小的数**，和当前无序区的**第一个位置**交换)*

**初始状态**：`38, 19, 65, 13, 97, 49, 41, 95, 1, 73`

| 趟数 | 找到的最小值 | 交换位置 | 结果序列 | 归位 |
| :--- | :--- | :--- | :--- | :--- |
| 第 1 趟 | 1 | 1 ↔ 38 | `1, 19, 65, 13, 97, 49, 41, 95, 38, 73` | 1 |
| 第 2 趟 | 13 | 13 ↔ 19 | `1, 13, 65, 19, 97, 49, 41, 95, 38, 73` | 13 |
| 第 3 趟 | 19 | 19 ↔ 65 | `1, 13, 19, 65, 97, 49, 41, 95, 38, 73` | 19 |
| 第 4 趟 | 38 | 38 ↔ 65 | `1, 13, 19, 38, 97, 49, 41, 95, 65, 73` | 38 |
| 第 5 趟 | 41 | 41 ↔ 97 | `1, 13, 19, 38, 41, 49, 97, 95, 65, 73` | 41 |
| 第 6 趟 | 49 | **不交换**（49 已在第 6 位） | `1, 13, 19, 38, 41, 49, 97, 95, 65, 73` | 49 |
| 第 7 趟 | 65 | 65 ↔ 97 | `1, 13, 19, 38, 41, 49, 65, 95, 97, 73` | 65 |
| 第 8 趟 | 73 | 73 ↔ 95 | `1, 13, 19, 38, 41, 49, 65, 73, 97, 95` | 73 |
| 第 9 趟 | 95 | 95 ↔ 97 | **最终结果**：`1, 13, 19, 38, 41, 49, 65, 73, 95, 97` | 全部 |

## 三、核心思想（大白话）

就像打擂台选老大。第一趟，让所有人比一遍，把全场最矮的拎出来，站到第一个位置。

第二趟，剩下的人再比一遍，把第二矮的拎出来，站到第二个位置。

以此类推。它和冒泡排序的区别是：**冒泡是相邻两两比较，每次比较都可能交换；选择排序是只记下标，每趟比完只交换一次。**

## 四、完整代码 + 下标级注释

```c
void SelectSort(SeqList R[], int n)
{
    int i, j, k;
    SeqList temp;

    // i 控制趟数，从第 1 个位置一直到第 n-1 个位置
    for (i = 1; i < n; i++)
    {
        k = i; // 假设当前位置 i 的元素就是最小的，用 k 记录它的下标

        // j 从当前位置的下一个位置开始，扫描到末尾找真正的最小值
        for (j = i + 1; j <= n; j++)
        {
            if (R[j].key < R[k].key)
            {
                k = j; // 发现更小的，记录下更小元素的下标
            }
        }

        // 内层循环结束，如果发现真正的最小值不在 i 的位置，就交换
        if (k != i)
        {
            temp = R[i];
            R[i] = R[k];
            R[k] = temp;
        }
    }
}
```

## 五、考场极速抢分技巧与答题规范（必看）

### ✍️ 1. 卷面答题规范与手算技巧

- **画竖线法**：在卷面上作答时，在已排好的部分和未排好的部分中间画一条竖线 `|`。比如第一趟后：`1 | 19, 65, 13, ...`。让老师一眼看出你已经把 1 归位了。
- **做标记**：在草稿纸上，每一趟找最小值时，可以把扫到的最小值打个勾，防止看到后面忘了前面。
- **特别留意不交换的情况**：如果最小值刚好就在当前起点位置（比如本题第 6 趟的 49），直接照抄，千万别乱换。

### 🃏 2. 检查对错的秒杀技巧

- **看前缀**：每一趟结束后，数组最前面的 `i` 个数必须是从小到大排好的，并且绝对是整个数组中最小的 `i` 个数。
- **看交换次数**：每趟最多只发生一次交换。所以如果你手算时发现某一趟里，数字像冒泡一样换来换去，那说明你用错算法了。

### 🎯 3. 选择题秒杀结论（直接背）

| 维度 | 结论 |
| :--- | :--- |
| **稳定性** | **不稳定**（因为在交换的时候，可能会把前面相等的元素跨越过去，改变相对顺序） |
| **时间复杂度** | **O(n²)**。注意：无论原数组是有序、逆序还是乱序，比较次数永远都是 **n(n−1)/2** 次。**它不像冒泡或插入那样有最好情况** |
| **空间复杂度** | **O(1)**（只需要一个临时变量 temp 用作交换） |
| **移动次数** | **极少**。相比于冒泡排序的疯狂交换，选择排序每趟最多只交换 1 次，总移动次数最多 **3(n−1)** 次。如果元素的数据结构特别庞大（比如很大的结构体），选择排序就比冒泡、插入都要好 |
