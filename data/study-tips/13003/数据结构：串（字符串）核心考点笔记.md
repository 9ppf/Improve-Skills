# 串（字符串）核心考点笔记

> **适用场景**：自考/统考数据结构选择题、考研复习
> **核心标签**：#数据结构 #串 #模式匹配 #子串计算

---

## 一、概念辨析：串 = 字符串

在数据结构中，**“串”（String）** 就是 **“字符串”** 的学术简称。

- **本质**：一种特殊的线性表，其数据元素被限定为单个字符。
- **编程语言对应**：C 语言中的字符数组（以 `\0` 结尾），Java/Python 中的 `String` 对象。

---

## 二、核心概念：主串与子串

- **主串（目标串）**：被查找的原始字符串。例如：`p = "abcdef"`
- **子串（模式串）**：主串中的一部分。例如：`q = "bcd"`

### ⚠ 绝对易错点：子串的“连续性”

**子串必须是主串中连续的一段字符。**

- 假设主串 `p = "abcdef"`
- ✅ `"bcd"` 是子串（连续）
- ❌ `"bdf"` **不是**子串（跳过了 'c'，不连续，这叫“子序列”）

### 特殊子串

1. **空串（`""`）**：长度为 0 的串，是**任何串**的子串。
2. **自身**：一个串本身，也是它自己的子串。
3. **真子串**：不包含自身的子串（但通常包含空串）。

---

## 三、必考计算题：子串数目的求解

> 💡 **真题回顾**：若串 `S = "software"`，其子串的数目是？
> **答案**：37（包含空串）。

### 1. 核心秒杀公式（强烈建议背诵）

假设字符串的长度为 n：

- **非空子串**的数目 = **n(n+1)/2**
- **总子串**（包含空串）的数目 = **n(n+1)/2 + 1**
- **真子串**（不含自身）的数目 = **n(n+1)/2**（如果题目只问非空真子串，则是 **n(n+1)/2 − 1**）

### 2. 公式推导（按长度分类累加法）

以 `S = "software"` 为例，长度 n = 8：

- 长度为 1 的子串：8 个
- 长度为 2 的子串：7 个
- …
- 长度为 8 的子串：1 个（它自己）
- **非空子串总数** = 8 + 7 + 6 + … + 1 = 36 个
- **总子串总数** = 36 + 1（空串）= **37** 个

### 3. 考场避坑指南

- 问：“其**非空**子串的数目” → 选 **36**。
- 问：“其**子串**的数目” → 默认包含空串，选 **37**。
- 问：“其**真子串**的数目” → 扣除自身，选 **36**。

## 四、串的基本运算（选择题高频考点）

| 运算名称 | 定义说明 | 编程语言对应方法（参考） |
| --- | --- | --- |
| **模式匹配（Pattern Matching）** | **求子串在主串中首次出现的位置**（也叫串定位） | C：`strstr()`；Java：`indexOf()`；Python：`find()` / `index()` |
| **联接（Concat）** | 将两个串首尾相连，组成新串 | `"abc" + "def"` → `"abcdef"` |
| **求子串（SubString）** | 从主串中截取指定位置和长度的连续字符 | Python 切片：`p[1:4]`；Java：`substring()` |
| **求串长（Length）** | 计算串中字符的个数（不含 `\0`） | `len("abc")` → 3 |

> 💡 **真题解析回顾**：“求 q 在 p 中首次出现的位置的运算” → 选 **A. 模式匹配**。
>
> 常考算法：**BF 算法**（暴力破解，时间复杂度 O(m×n)）、**KMP 算法**（利用 `next` 数组，时间复杂度 O(m+n)，必考大题/选择题）。

---

## 五、备考小贴士

1. **区分“子串”与“子序列”**：看到“子串”二字，脑子里立刻弹出“**连续**”的警报。
2. **空串 vs 空格串**：
   - 空串：`""`，长度为 0。
   - 空格串：`"   "`，长度大于 0（全是空格字符）。
3. 遇到模式匹配的代码题或求 `next` 数组的题，重点复习 **KMP 算法** 的手动推导过程。
4. **公式必背**：长度为 n 的串，子串总数是 **n(n+1)/2 + 1**。
