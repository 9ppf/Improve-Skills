# 数据结构核心考点背诵笔记（知识点 + 锚点 + 内容）

> **使用方法**：先看"锚点"回忆，想不起来再看"内容"。带 ✦ 的知识点是计算/过程类，可能升级为解答大题。
>
> **题型规律**：概念、公式、复杂度、识别类 → 填空/单选；过程、画图、算序列类 → 解答大题。

---

## 一、数据结构基础（必考）

| 知识点 | 锚点 | 内容 |
|--------|------|------|
| 数据结构 | 元素 + 关系 | 相互之间存在一种或多种特定关系的数据元素的集合 |
| 逻辑结构 | 抽象关系 | 数据元素间的抽象关系：线性、树形、图形、集合 |
| 存储结构 | 内存表示 | 数据在计算机中的表示：顺序、链式、索引、散列 |
| 算法 | 有限指令序列 | 对特定问题求解步骤的描述，是指令的有限序列 |
| 算法特性 | 有确可 + 入出 | 有穷性、确定性、可行性、输入、输出 |
| 时间复杂度 | T(n) = O(f(n)) | 估算算法执行时间 |
| 复杂度排序 | 小到大 | O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(2ⁿ) |
| 空间复杂度 | 占多少内存 | 估算算法所需存储空间 |

> 研究内容三件套口诀：**「逻存运」**——先想关系（逻辑）→ 再放内存（存储）→ 最后定义用法（运算）。

---

## 二、线性表（核心）

| 知识点 | 锚点 | 内容 |
|--------|------|------|
| 顺序表特点 ✦ | 物理也相邻 | 逻辑相邻物理也相邻；随机存取（下标访问 O(1)） |
| 顺序表缺点 | 查快改慢 | 插入删除需移动大量元素 O(n)；静态分配容量固定 |
| 链表特点 | 物理不一定相邻 | 逻辑相邻物理不一定相邻；顺序存取（从头遍历 O(n)） |
| 链表优点 | 改指针即可 | 插入删除 O(1) 仅改指针；动态分配无容量限制 |
| 链表缺点 | 慢 + 费空间 | 存取慢需遍历；额外空间存指针 |
| 单链表 | 一个指针 | 结点 = 数据域 + 后继指针 |
| 双链表 | 两个指针 | 结点 = 数据域 + 前驱指针 + 后继指针（可反向遍历） |
| 循环链表 | 尾指头成环 | 尾结点指针指向头结点；**空表判断 head->next == head** |
| 逆置 | 链表基本操作 | 创建、插入、删除、查找、遍历、**逆置** |

**顺序表 vs 链表（选择题高频）**：

| 特性 | 顺序表 | 链表 |
|------|--------|------|
| 存取 | 随机存取 O(1) | 顺序存取 O(n) |
| 插入/删除 | 移动元素 O(n) | 改指针 O(1) |
| 空间 | 静态分配，可能浪费 | 动态分配，无浪费 |
| 适用 | 频繁查找少增删 | 频繁增删少查找 |

> 不宜用链表实现的排序：**快速排序**；不宜链式存储的结构：**数组**（要随机访问）。

## 三、栈和队列（重点）

| 知识点 | 锚点 | 内容 |
|--------|------|------|
| 栈定义 | 只动栈顶 | 仅在表尾（栈顶）插入和删除的线性表 |
| 栈特点 | LIFO | 后进先出 |
| 栈的存储 | 顺序栈 / 链栈 | 数组实现 / 链表实现 |
| 栈的应用 ✦ | 函数调用家族 | 函数调用、**后缀（逆波兰）表达式求值**、括号匹配、递归、迷宫求解 |
| 后缀求值结构 | 操作数栈 | 扫描到操作数入栈，遇到运算符弹两个算完再压回 |
| 队列定义 | 尾进头出 | 仅在表尾（队尾）插入、表头（队头）删除的线性表 |
| 队列特点 | FIFO | 先进先出 |
| 循环队列判空 | 相等即空 | front == rear |
| 循环队列判满 ✦ | 牺牲一格 | (rear + 1) % MaxSize == front |
| 队列应用 | 排队场景 | 缓冲区、打印队列、**广度优先搜索（BFS）** |

> 不宜用栈求解的问题：**BFS**（要用队列）；栈的空间分配大小 = **最大递归/操作深度**。

## 四、串、数组和广义表（基础）

| 知识点 | 锚点 | 内容 |
|--------|------|------|
| 串定义 | 字符序列 | 零个或多个字符组成的有限序列 |
| 朴素模式匹配 | 一个一个比 | O(n×m) |
| KMP 算法 | next 数组不回溯 | O(n+m)，利用部分匹配表避免主串指针回溯 |
| 数组存储 ✦ | C 语言行优先 | 行优先 / 列优先；地址 = 基址 + 偏移元素个数 × 元素大小 |
| 对称矩阵压缩 ✦ | 只存一半 | n(n+1)/2 个元素；上三角元素换位后套行优先公式 |
| 稀疏矩阵 | 三元组表 | 三元组表、十字链表 |
| 广义表表头 | 第一个元素 | 可能是原子也可能是子表 |
| 广义表表尾 | 除头都算 | **永远是表**（即使只有一个元素也要加括号） |
| 广义表深度 ✦ | 最大括号层数 | 原子深度为 0，空表深度为 1 |

## 五、树与二叉树（重中之重）

| 知识点 | 锚点 | 内容 |
|--------|------|------|
| 树的度 | 结点度最大值 | 所有结点度的最大值 |
| 树的深度 | 到最远叶子 | 根结点到最远叶子结点的层数 |
| 二叉树定义 | 最多两子树 | 每个结点最多两棵子树，且有左右之分 |
| 性质 1 | 每层上限 | 第 i 层最多 2^(i-1) 个结点 |
| 性质 2 | 整树上限 | 深度为 k 的二叉树最多 2^k − 1 个结点 |
| 性质 3 | 叶子公式 | **n₀ = n₂ + 1**（叶子数 = 度为 2 结点数 + 1） |
| 性质 4 | 完全二叉树深度 | ⌊log₂n⌋ + 1 |
| 满二叉树 | 层层都满 | 深度 k 有 2^k − 1 个结点 |
| 完全二叉树 | 最后一层靠左 | 除最后一层外全满，最后一层从左往右排 |
| 二叉树存储 | 数组 / 二叉链表 | 顺序存储适合完全二叉树；**二叉链表最常用** |
| 先序遍历 | 根左右 | 根 → 左 → 右 |
| 中序遍历 | 左根右 | 左 → 根 → 右 |
| 后序遍历 | 左右根 | 左 → 右 → 根 |
| 层序遍历 | 用队列 | 按层从上到下、从左到右 |
| 遍历还原 ✦ | 必须有中序 | 先/后序 + 中序可唯一确定二叉树；**先 + 后不行** |
| 线索二叉树 | 空指针利用 | 用空指针存前驱/后继，方便遍历 |
| BST | 左 < 根 < 右 | 查找 O(logn)，最坏退化成链表 O(n) |
| AVL | 高度差 ≤ 1 | 平衡二叉树，查找/插入/删除均 O(logn) |
| 哈夫曼树 | WPL 最小 | 最优二叉树；构造：每次选两个最小权值结点合并 |
| 哈夫曼结点数 ✦ | 2n − 1 | n 个叶子的哈夫曼树共 2n − 1 个结点（无度为 1 的结点） |
| 哈夫曼编码 | 前缀码 | 数据压缩用，任一编码不是另一编码的前缀，无歧义 |

## 六、图（重点）

| 知识点 | 锚点 | 内容 |
|--------|------|------|
| 邻接矩阵 | 二维数组 | A[i][j] 存边/权；**无向图矩阵对称，有向图不一定** |
| 邻接矩阵适用 | 稠密图 | 直观易查边，稀疏图浪费空间 |
| 邻接表 | 数组 + 链表 | 每个顶点挂一条邻接点链表；适合稀疏图 |
| 无向图邻接表 | 2e 个结点 | 边表结点总数 = 2e（每条边存两次） |
| DFS | 栈 / 递归 | 一路到底再回溯 |
| BFS | 队列 | 逐层遍历，先近后远 |
| 遍历时间复杂度 | 看存储结构 | 邻接矩阵 O(n²)；邻接表 O(n+e) |
| Prim 算法 | 选顶点 | 适合**稠密图**，O(n²) |
| Kruskal 算法 | 选边 | 适合**稀疏图**，O(eloge) |
| Dijkstra | 单源最短路 | 一个点到其余各点，要求**非负权**，O(n²) |
| Floyd | 所有点对 | 所有顶点对最短路径，O(n³) |
| 拓扑排序 | DAG | 有向无环图按先后排序顶点，判断工程可行性 |
| 关键路径 | AOE 网最长路径 | 决定工程最短工期 |
| 路径长度 | 带权图看权 | 带权图中路径长度 = 路径上**权值之和**（非边数） |

## 七、查找（Search）

| 知识点 | 锚点 | 内容 |
|--------|------|------|
| 顺序查找 | 无要求 | 逐个比较，O(n)，对表无要求 |
| 二分查找前提 ✦ | 有序 + 顺序存储 | 无序不能直接二分（先排序） |
| 二分查找思想 ✦ | 取中缩半 | 比较中间元素缩小范围；mid = (low+high) // 2；O(logn) |
| 二分查找长度 | 等于层数 | 判定树中关键字所在层数（根为第 1 层） |
| 查找长度 ≤ k 的个数 | 前 k 层满 | 2^k − 1（n 足够大时） |
| BST 查找 | 平均 logn | 平均 O(logn)，最坏（有序插入退化）O(n) |
| B 树 | 多路平衡 | 多路平衡查找树，用于数据库、文件系统 |
| 散列函数 | 除留余数 | H(key) = key % p |
| 冲突处理 | 两大家族 | 开放定址法（线性探测、二次探测）；链地址法（拉链） |
| 散列查找 | O(1) | 平均查找时间 O(1)，效率最高 |
| 线性探测问题 | 堆积 | 非同义词争夺同一地址，链地址法无堆积问题 |

## 八、排序（重中之重）

**八大排序必背表**：

| 算法 | 基本思想 | 时间复杂度 | 空间 | 稳定性 |
|------|---------|-----------|------|--------|
| 直接插入 | 逐个插入有序区 | 最好 O(n)，平均/最坏 O(n²) | O(1) | 稳定 |
| 希尔 | 分组插入，缩小增量 | O(n^1.3) ~ O(n²) | O(1) | 不稳定 |
| 冒泡 | 相邻比较，大的下沉 | 最好 O(n)，平均/最坏 O(n²) | O(1) | 稳定 |
| 快速排序 ✦ | 选基准，分治递归 | 最好/平均 O(nlogn)，最坏 O(n²) | O(logn)~O(n) | 不稳定 |
| 简单选择 ✦ | 选最小放有序区 | 始终 O(n²) | O(1) | 不稳定 |
| 堆排序 ✦ | 建堆、选堆顶、调整 | 始终 O(nlogn) | O(1) | 不稳定 |
| 归并 | 分治，两两归并 | 始终 O(nlogn) | O(n) | 稳定 |
| 基数 | 按位分配收集 | O(d(n+r)) | O(n+r) | 稳定 |

| 知识点 | 锚点 | 内容 |
|--------|------|------|
| 内部排序 | 全程内存 | 数据全部在内存中排序 |
| 外部排序 | 外存 + 归并 | 数据在外存（磁盘），常用归并排序 |
| 稳定的算法 | **插冒归基** | 直接插入、冒泡、归并、基数 |
| 不稳定的算法 | **希快选堆** | 希尔、快速、简单选择、堆 |
| 基本有序 | 插入 / 冒泡 | 数据基本有序时用 |
| 大量无序 | 快 / 堆 / 归 | 数据量大且无序时用 |
| 内存有限 | 堆排序 | 空间 O(1) |
| 要求稳定 | 归并 / 基数 | 稳定算法里效率高的 |
| 每趟选最终位置 | 交换类 | 快排、冒泡、选择、堆每趟至少一个元素到位 |
| 比较次数与初序无关 | 选择排序 | 简单选择排序始终比较 n(n-1)/2 次 |
| 快排最坏情况 | 已有序 | 退化为 O(n²)，优化：随机选基准 |
| 堆排序时间拆分 | 建堆 + 调整 | 建堆 O(n)，每次调整 O(logn)，总 O(nlogn) |

## 九、高频考点速记清单

> 考前 10 分钟过一遍的浓缩版：

1. **复杂度**：O(1) < O(logn) < O(n) < O(nlogn) < O(n²)
2. **线性表**：顺序表随机存取、链表增删快
3. **栈 LIFO、队列 FIFO**；循环队列判满 (rear+1)%MaxSize == front
4. **二叉树**：n₀ = n₂ + 1；遍历先/中/后/层序
5. **哈夫曼**：WPL 最小；结点总数 2n−1；编码是前缀码
6. **图**：矩阵（稠密）、邻接表（稀疏）；DFS 栈、BFS 队列
7. **MST**：Prim 稠密、Kruskal 稀疏；最短路径：Dijkstra、Floyd
8. **查找**：二分要有序 O(logn)、散列 O(1)
9. **排序**：快/堆/归 O(nlogn)；插/冒/选 O(n²)；稳定 = 插冒归基

## 十、易错点提醒

| 易错点 | 正确认识 |
|--------|---------|
| 链表插删指针顺序 | 先连后断，防止断链 |
| 遍历还原二叉树 | 先/后 + 中序可以；**先 + 后序不行** |
| 邻接矩阵对称性 | 无向图一定对称，有向图不一定 |
| 快排最坏情况 | 原表有序时退化 O(n²)，随机选基准优化 |
| 堆排序时间 | 建堆 O(n) + 调整 O(logn)，总 O(nlogn) |
| 散列冲突 | 链地址法优于开放定址，无堆积问题 |
| 稳定性归属 | 稳定性只与**算法本身**有关，与数据无关 |

## 一句话总记忆

> **基础记"逻存运"，线性记"查顺增链"，栈队记"后进先进"，树记"n₀=n₂+1 和 2n−1"，图记"矩阵稠密表稀疏、DFS 栈 BFS 队"，查找记"二分有序散列 O(1)"，排序记"快堆归 nlogn、插冒归基稳"。**
