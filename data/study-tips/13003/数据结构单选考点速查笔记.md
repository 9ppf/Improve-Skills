# 数据结构单选考点速查笔记（真题规律总结）

> **使用方法**：先看"锚点"反应考点，再看"考法与秒杀要点"确认解法。这是从 63 道历年单选题里反向提炼的规律，考场上遇到同款直接套。
>
> **题型分布**：全部为单选题；概念辨析类靠记忆锚点，计算类靠公式，过程类靠模拟。

---

## 一、数据结构基本概念与算法分析（6 题）

| 知识点 | 锚点 | 考法与秒杀要点 |
|--------|------|---------------|
| 数据结构研究的基本内容 | 逻存运 | 选项含"**逻辑结构 + 存储结构 + 操作**"三件套的直接选（答案 A 款） |
| 抽象数据类型 ADT | 定义+操作封装 | 抓两个特征：**封装数据定义和数据操作**、**与具体实现无关**；"C 语言提供""与实现相关"都是坑 |
| 线性与非线性区分 | 树图非线性 | 不属于线性结构的选**二叉树**；线性 = 线性表/双链表/栈/队列/循环队列/串 |
| 评价算法的指标 | 时间复杂度 | 选**时间复杂度**；执行时间、代码长度、编程语言都是干扰项 |
| 线性表 n 的取值 | 非负整数 | n 是**非负整数**（n=0 是空表）；"任意正整数"漏了 0，是坑 |
| 数据项与数据元素 | 基本vs最小 | **数据元素是数据的基本单位**，数据项是最小单位；"数据项包含数据元素"是反向坑 |

## 二、线性表（8 题）

| 知识点 | 锚点 | 考法与秒杀要点 |
|--------|------|---------------|
| 顺序表地址计算 ✦ | 起始+间隔×n，末单元减 1 | LOC(i) = 首址 + (i−1)×L；问"**占用的最后一个单元**"要再 + (L−1)。例：200 起、L=8，第 5 个元素首址 232，末单元 239 |
| 带头结点表头插入 | 先连后断 | 正确顺序：`p->next=head->next; head->next=p;`；先改 head->next 再用 p->next 的必断链（坑选项 A） |
| 循环链表空链判断 | 指回头不是 NULL | 带头结点循环链表空 = **head->next == head**；普通单链表空才是 head->next == NULL |
| p、q 之间插入 s | 先连后断 | `s->next=p->next; p->next=s;`——和表头插入同一原则，**先连新的，再断旧的** |
| 仅尾指针循环链表插删 | 尾指针万能 | 尾插 O(1)；删头也 O(1)（rear->next 就是头），答案 **O(1) 和 O(1)** |
| 等概率插入平均移动 | 一半 | 长度 n 的顺序表等概率插入平均移动 **n/2** 次（删除是 (n−1)/2） |
| 不宜链表实现的排序 | 快排要随机访问 | **快速排序**（基准选取和划分需要随机访问）；插入/归并/基数都能在链表上做 |
| 不宜链式存储的结构 | 数组要随机访问 | **数组**（按下标直接访问）；无向图、二叉树、链表都可以链式存 |

## 三、栈与队列（7 题）

| 知识点 | 锚点 | 考法与秒杀要点 |
|--------|------|---------------|
| 出栈序列合法性 | 后面比它小的要降序 | 判定法：出栈序列中每个元素**后面比它小的元素必须呈降序**。例 5,4,1,3,2：4 后面比它小的 1,3,2 不是降序 → 不可能 |
| 顺序栈栈底地址 ✦ | 向上长：底=顶−(n−1)×L | top=top+1 是向上增长 → 栈底 = 栈顶地址 − (n−1)×L。例：栈顶 100、n=10、L=4 → 100−36=64。栈顶指针向下增长则反过来 |
| 循环队列逆向推导 ✦ | 出队减、入队加，逆向倒推 | 逆向：原 rear = 现 rear − 入队次数，原 front = 现 front − 出队次数（**都要 mod MaxSize**）。例：现 rear=2, front=4，出队 2 入队 1 → 原 rear=1, front=2 |
| 栈的应用 | 后缀表达式 | 计算**后缀表达式**的值用栈；BFS 用队列、希尔排序用数组、散列查找用表 |
| 后缀求值用几个栈 | 只有一个操作数栈 | **一个保存操作数及运算结果的栈**；两个栈是中缀转后缀的配置，别混 |
| 不宜用栈求解 | BFS 用队列 | **图的广度优先搜索**（用队列）；回文判断、括号匹配、数制转换都用栈 |
| 栈空间分配大小 ✦ | 模拟找最大深度 | 按入出序列逐步模拟，记录**栈内同时存在的最大元素个数**。例 f..a 入、d,e,a,b,c,f 出 → 最大深度 4 |

## 四、数组与矩阵（3 题）

| 知识点 | 锚点 | 考法与秒杀要点 |
|--------|------|---------------|
| 二维数组行优先地址 ✦ | 前面元素个数 × L | 偏移 = 该元素**前面**的元素个数。0 起下标：偏移 = (i×列数 + j) × L + 基址。例：100 起、L=6、4 列，M[2][2] → (2×4+2)×6=60 → 160 |
| 对称矩阵压缩个数 | 含对角线 n(n+1)/2 | 存上三角（含对角线）共 **n(n+1)/2** 个；n(n−1)/2 不含对角线，是坑 |
| 上三角压缩地址 ✦ | 整行累加 + 行内偏移 | 先算前面几行元素总数（第 1 行 n 个、第 2 行 n−1 个…），再加行内偏移，最后 ×L+基址。例：6 阶 a34 → 6+5+1=12 个在前 → 10+12×2=34 |

## 五、广义表（4 题）

| 知识点 | 锚点 | 考法与秒杀要点 |
|--------|------|---------------|
| 广义表的表尾 | 剩下的整体加层括号 | 表尾 = 去掉第一个元素后**剩下的部分再套一层外括号**（永远是表）。例：LS=(A,B,(g,h)) 的表尾是 (B,(g,h)) |
| 广义表的表头 | 第一个元素原样取 | 表头 = 第一个元素**原样取出**，不加不删（可能是原子也可能是子表） |
| head/tail 嵌套运算 | 剥洋葱写中间结果 | 从外往里逐层剥：head 取第一个、tail 去掉第一个；**每步写出中间结果**再继续，别心算跳步 |
| 广义表的深度 | 最大括号嵌套层数 | 数括号嵌套层数（含最外层）；原子深度 0，空表深度 1 |

## 六、树与二叉树（12 题）

| 知识点 | 锚点 | 考法与秒杀要点 |
|--------|------|---------------|
| 完全二叉树某层有叶求最多结点 ✦ | 上面全满 + 分支×2 | 例：第 4 层 5 个叶 → 1~3 层满（7 个），第 4 层 8−5=3 个分支，第 5 层最多 3×2=6 → 共 21。公式：**上面层全满 + 该层分支数 × 2** |
| 全部 k 叶同层且分支都有两孩 | 满二叉树 | 这是满二叉树，结点数 = **2k − 1** |
| 分支结点数求叶结点最少 ✦ | n0=n2+1，n1∈{0,1} | 完全二叉树 n1 只能是 0 或 1；n1=1 时 n2=分支数−1，n0 最小 = **分支数**。例 7 个分支 → 叶最少 7 |
| 二叉树性质找错误 | n0>n2 恒成立，n0 与 n1 无关 | 错误项通常是"**叶结点多于度 1 结点**"——n0 与 n1 没有必然大小关系（单支树可相等）；"二叉树可为空""可存数组"都对 |
| 前序+中序 → 后序 ✦ | 前序定根、中序分左右 | 递归还原再写后序；速查：**根一定在后序最后**。例 ABCD/ACDB → 后序 DCBA |
| 后序中根前面的结点 | 左右根 | 后序 = 左 → 右 → 根，根前面是**左右子树的全部结点** |
| BST 层数与关键字大小 | 层深不代表值大 | 选**不确定**；左子树深处的关键字照样比根小 |
| BST 插入后高度最小 | 根取中间、左右均衡 | 找"根是中间值、插入后左右子树规模均衡"的序列；逐个模拟排除最快。例 6,4,1,8,10,5 |
| BST 插入后高度最高 | 接近有序致链化 | 找模拟后"一条链插到底"的序列（近似有序但带交替偏移）。例 10,6,8,9,12,11,13 |
| 哈夫曼树的概念 | WPL 最小 | 哈夫曼树 = **带权路径长度 WPL 最小**的二叉树；"权值之和最小""唯一""高度最低"都是坑（两最小权相等时不唯一） |
| 哈夫曼结点总数 | 2n−1 | n 个叶子（字符）的哈夫曼树共 **2n−1** 个结点（无度 1 结点） |
| 树转等价二叉树 | 树后序 = 二叉树中序 | 树 T 的后序遍历 = 对应二叉树 T1 的**中序遍历**（孩子兄弟法转换） |

## 七、图（6 题）

| 知识点 | 锚点 | 考法与秒杀要点 |
|--------|------|---------------|
| 邻接表无向图指针个数 | n + 2e | 顶点表 n 个头指针 + 每条边存两次（2e 个边结点各 1 个指针）= **n + 2e** |
| DFS 与 BFS 生成树关系 | 都 n−1 条边，可能相同 | 选"**可能相同**"；一定相同/一定不同都不对，边数都是 n−1 相等 |
| 拓扑序列存在 | DAG | 存在拓扑序列 ⇔ 是**有向无环图**；拓扑序列不一定唯一 |
| 带权图单源最短路 | Dijkstra | 一个顶点到其余各点 → **迪杰斯特拉**；Prim/Kruskal 是最小生成树，哈夫曼不是图算法 |
| 带权图路径长度 | 权值之和 | 路径长度 = **路径上边的权值之和**（无权图才是边数） |
| 出入度均 2 求最少顶点 | 从 3 开始试 | 顶点可以互相贡献度：3 个顶点两两间双向各取 2 进 2 出即可 → 最少 **3** 个 |

## 八、查找（7 题）

| 知识点 | 锚点 | 考法与秒杀要点 |
|--------|------|---------------|
| 二分查找比较序列 ✦ | 标索引，mid=(low+high)//2 | 先标 0~n−1 索引，逐次算 mid 记录 arr[mid]，**每步写 low/high** 防错 |
| 二分查找比较次数 ✦ | 数层数 | 同上模拟，数比较了几次。例 9 元素查 82：62→82，共 2 次 |
| 判定树的结构性质 | 只保证是二叉树 | 判定树**只是一棵二叉树**；不一定满、不一定完全、叶子不一定同层 |
| 长度 ≤ k 的关键字个数 | 2^k − 1 | 查找长度 ≤ k 的个数 = 判定树前 k 层节点总数 = **2^k − 1**（n 足够大时前 k 层满，n≥100 保 k=4） |
| 线性探查法探查次数 ✦ | 从 H(key) 起逐个 +1 | 从散列地址开始逐个往后数，**冲突继续、到空（或找到）停**，数经过的地址数。例 H(23)=5，5→6→7 空 = 3 次 |
| 散列查找最好复杂度 | O(1) | 最好 **O(1)**（散列函数一步定位） |
| m 阶 B 树性质 | 关键字范围 ⌈m/2⌉−1 ≤ n ≤ m−1 | 正确项：非根结点关键字数满足该范围。坑：非终端至多 **m** 棵子树（不是 m+1）；根至少 **1** 个关键字（2 棵子树）；所有叶在同一层 |

## 九、排序（10 题）

| 知识点 | 锚点 | 考法与秒杀要点 |
|--------|------|---------------|
| 趟次结果识别排序 ✦ | 特征指纹对照表 | **直接插入**：前缀有序但元素未最终定位；**归并**：等长块内有序；**快排**：基准归位左右分块；**冒泡/选择**：出现一个最终位置元素（冒泡大数沉底、选择小数置顶） |
| 第 1 趟识别 | 前缀有序 = 插入 | 例 8,9,10,4,…前三个有序且后面乱 → 直接插入排序 |
| 第 2 趟识别（含快速） | 两趟前缀有序 = 插入 | 插入第 k 趟后**前 k+1 个元素有序**；冒泡/选择/归并两趟都达不到前缀有序时选插入 |
| 每趟选最终位置且不稳定 | 快排/选择/堆里挑 | 每趟归位一个元素：冒泡(稳)、快排(不稳)、选择(不稳)、堆(不稳)；不稳定且每趟归位 → **快速排序**（选项里出现谁选谁） |
| 不稳定的排序 | 希快选堆 | 选项中**直接选择排序**不稳定；归并/插入/基数稳定 |
| 比较次数与初序无关 | 直接选择 | **直接选择排序**始终比较 n(n−1)/2 次；插排/冒泡的比较次数都跟初序有关 |
| 建初始堆 ✦ | 升序大顶堆、降序小顶堆 | **降序排序建小顶堆**（每次取最小放后面）；从最后一个非叶结点 ⌊n/2⌋−1 起自后往前调整。例 35,58,24,13,44,19,10 → 小顶堆 10,13,19,58,44,35,24 |
| 内排序的定义 | 全程内存 | 内排序：待排序数据保存在**内存储器**中 |
| 最坏复杂度非 O(n²) | 堆排序 O(nlogn) | 插入/冒泡/快排最坏都 O(n²)，**堆排序**始终 O(nlogn) |
| 希尔排序两趟结果 ✦ | 按增量分组各自插入 | 别整趟重排！按增量 d 分成 d 组，**每组内部做插入排序**，逐组处理。增量序列 5,3 就做两轮 |

## 十、考场策略总结

1. **概念题（约 20 分）**：靠锚点直接反应，注意"基本/最小""线性/非线性""稳定/不稳定"三组反义坑
2. **计算题（约 15 分）**：地址计算先写偏移公式再代入；栈/队列逆向推导注意 **mod**；二分模拟每步写 low/high
3. **模拟题（约 15 分）**：BST 插入、堆调整、希尔分组、二分查找——动手画，别心算
4. **识别题（约 10 分）**：排序趟次指纹对照 + 排序性质组合（稳定性 × 归位性 × 比较次数固定性）
5. **送分记忆题（约 10 分）**：2n−1、n(n+1)/2、2^k−1、n/2、n+2e、O(1)、DAG——背就完事
