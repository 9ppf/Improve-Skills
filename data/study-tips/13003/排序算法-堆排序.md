# 堆排序（升序排序）—— 例题、算法与抢分技巧

## 一、题目

对于数据序列：`70, 12, 30, 1, 5, 31, 44, 56, 61`，采用**堆排序**算法进行升序排序，请写出每趟排序的结果。

---

## 二、推演过程

*(堆排序升序需要建**大根堆**。先把数组看作完全二叉树，构建初始堆，然后把堆顶（最大值）和末尾元素交换，再重新调整堆)*

- **初始序列**：`70, 12, 30, 1, 5, 31, 44, 56, 61`
- **初始建堆（大根堆）**：从最后一个非叶子节点（n/2=4，即数字 1）开始向前调整。
  - 调整后的大根堆：**`70, 61, 44, 56, 5, 31, 30, 12, 1`**
  - *(注意：建初始堆的过程，很多教材算作第 0 趟或第一步，建议写上)*

### 🎯 第 1 趟（最大值 70 归位）

- 堆顶 `70` 与末尾 `1` 交换。末尾切掉 70，剩下的重新调整为大根堆。
- **结果**：`61, 56, 44, 12, 5, 31, 30, 1, 70`

### 🎯 第 2 趟（次大值 61 归位）

- 堆顶 `61` 与末尾 `1` 交换。末尾切掉 61，剩下的重新调整。
- **结果**：`56, 12, 44, 1, 5, 31, 30, 61, 70`

### 🎯 第 3 趟（56 归位）

- 堆顶 `56` 与末尾 `30` 交换，重新调整。
- **结果**：`44, 12, 30, 1, 5, 31, 56, 61, 70`

### 🎯 第 4 趟（44 归位）

- 堆顶 `44` 与末尾 `31` 交换，重新调整。
- **结果**：`31, 12, 30, 1, 5, 44, 56, 61, 70`

### 🎯 第 5 趟（31 归位）

- 堆顶 `31` 与末尾 `5` 交换，重新调整。
- **结果**：`30, 12, 5, 1, 31, 44, 56, 61, 70`

### 🎯 第 6 趟（30 归位）

- 堆顶 `30` 与末尾 `1` 交换，重新调整。
- **结果**：`12, 1, 5, 30, 31, 44, 56, 61, 70`

### 🎯 第 7 趟（12 归位）

- 堆顶 `12` 与末尾 `5` 交换，重新调整。
- **结果**：`5, 1, 12, 30, 31, 44, 56, 61, 70`

### 🎯 第 8 趟（全部有序）

- 最后两个元素 `5` 和 `1` 交换。
- **最终结果**：`1, 5, 12, 30, 31, 44, 56, 61, 70`

## 三、核心思想（大白话）

把数组当成一个"金字塔"（完全二叉树）。**升序排序要建"大根堆"**（每个父节点都比孩子大）。

建好后，金字塔的塔尖（也就是数组第一个元素 `70`）绝对是全场最大的。

把塔尖摘下来，和金字塔最底层最右边的一个小弟交换位置。这样，最大的数就沉到了数组最末尾（排好序了）。

此时塔尖换了个小弟上去，可能不满足"大根堆"的规矩了，就让这个新塔尖往下沉（向下调整），把真正的大哥顶上来。

重复"摘塔尖 -> 换末尾 -> 沉塔尖"的动作，直到全部排好。

## 四、完整代码 + 下标级注释

*(实际考试中极少要求默写堆排序的完整代码，但常考填空，主要关注 `HeapAdjust` 向下调整函数)*

```c
// 核心调整函数：将以 k 为根的子树调整为大根堆
void HeapAdjust(SeqList R[], int k, int len)
{
    R[0] = R[k]; // R[0] 暂存根节点的值（哨兵）
    for (int i = 2 * k; i <= len; i = i * 2) // 沿较大的子节点向下筛选
    {
        if (i < len && R[i].key < R[i + 1].key)
            i++; // i 指向左右孩子中较大的一个

        if (R[0].key >= R[i].key) break; // 根节点比大孩子还大，说明不用调了
        else
        {
            R[k] = R[i]; // 把大孩子换上来
            k = i;       // 根节点换到下面去了，继续往下比
        }
    }
    R[k] = R[0]; // 把最开始暂存的根节点，放入最终的空位
}

// 堆排序主函数
void HeapSort(SeqList R[], int n)
{
    // 1. 初始建大根堆：从最后一个非叶子节点(n/2)倒着往前调
    for (int i = n / 2; i > 0; i--)
    {
        HeapAdjust(R, i, n);
    }

    // 2. 排序：每次把堆顶（最大值）和当前末尾交换，再调整
    for (int i = n; i > 1; i--)
    {
        SeqList temp = R[1];
        R[1] = R[i];       // 堆顶和末尾交换
        R[i] = temp;

        HeapAdjust(R, 1, i - 1); // 剩下的元素重新调整为大根堆
    }
}
```

## 五、考场极速抢分技巧与答题规范（必看）

### ✍️ 1. 卷面答题规范与手算技巧

- **建堆过程算不算一趟？** 严格来说，初始建大根堆（把无序数组变成大根堆）是**准备工作，不算"一趟排序"**。第一趟排序必须是从"堆顶与末尾交换，并重新调整后"开始算。
- **一定要画树形图（草稿纸）**：在草稿纸上把数组画成完全二叉树。找 `n/2` 的节点往下调整。
- **卷面答题**：直接写出每一趟调整后的序列，可以用竖线 `|` 隔开已排好序的部分，例如：`61, 56, 44, 12, 5, 31, 30, 1 | 70`。

### 🃏 2. 检查对错的秒杀技巧

- **看末尾**：第 1 趟做完，数组最后一个数必定是全场最大值（70）；第 2 趟做完，倒数第二个数必定是次大值（61）……依次类推。如果发现末尾不是当前剩余元素的最大值，绝对算错了。
- **检查剩余部分**：除了已经归位的末尾元素，前面的剩余部分一定是一个大根堆（即每个父节点都大于等于它的左右子节点）。利用这一点可以快速验证你的调整对不对。

### 🎯 3. 选择题秒杀结论（直接背）

| 维度 | 结论 |
| :--- | :--- |
| **稳定性** | **不稳定**（把末尾元素换到堆顶，会破坏相同元素的相对顺序） |
| **时间复杂度** | 建堆时间 **O(n)**，每次调整 **O(log n)**，共 **n−1** 次调整，总时间复杂度 **O(n log n)**。**最好、最坏、平均都是这个值** |
| **空间复杂度** | **O(1)**（原地排序，只需要常数个辅助变量） |
| **适用场景** | 数据量大，且需要找前 **K** 个最大/最小值的场景（比如海量数据求 Top K） |
