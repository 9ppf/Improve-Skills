## 第一章 数据结构基础（真题约 6 题）

### 1. 数据结构
> 🔑 锚点：元素 + 关系 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空
> 🧠 口诀：**「逻存运」**——先想关系（逻辑）→ 再放内存（存储）→ 最后定义用法（运算）

**内容**：相互之间存在一种或多种特定关系的数据元素的集合。

**相关真题考点**：
- [单选] 数据结构研究的基本内容 → 选项含"**逻辑结构 + 存储结构 + 操作**"三件套的直接选

### 2. 数据元素与数据项
> 🔑 锚点：基本 vs 最小 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**元素是基本，数据项最小**

**内容**：数据元素是数据的**基本单位**；数据项是数据的**最小单位**（数据元素由数据项组成）。

**相关真题考点**：
- [单选] 直接考单位归属 → 选"数据元素是基本单位"；⚠ 陷阱："数据项包含数据元素"是反向坑

### 3. 逻辑结构
> 🔑 锚点：抽象关系 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**线树图集四种关系**

**内容**：数据元素间的抽象关系，分为**线性、树形、图形、集合**四类。

**相关真题考点**：
- [单选] 线性与非线性区分 → 不属于线性结构的选**二叉树**；线性 = 线性表/双链表/栈/队列/循环队列/串

### 4. 存储结构
> 🔑 锚点：内存表示 ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**顺链索引散列四种存法**

**内容**：数据在计算机中的表示：**顺序、链式、索引、散列**。

**相关真题考点**：暂无真题（常作为三件套选项的一部分出现）

### 5. 抽象数据类型（ADT）
> 🔑 锚点：定义 + 操作封装 ｜ ⭐ ★★★★☆ ｜ 📝 单选
> 🧠 口诀：**封装定义和操作，与实现无关**

**内容**：ADT = 数据定义 + 数据操作的封装，只描述"做什么"，不描述"怎么做"。

**相关真题考点**：
- [单选] 抓两个特征：**封装数据定义和数据操作**、**与具体实现无关**；⚠ 陷阱："C 语言提供""与实现相关"都是坑

### 6. 算法
> 🔑 锚点：有限指令序列 ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**求解步骤的有限序列**

**内容**：对特定问题求解步骤的描述，是指令的有限序列。

**相关真题考点**：暂无真题

### 7. 算法的特性
> 🔑 锚点：有确可 + 入出 ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**有穷确定可行，有入有出**

**内容**：有穷性、确定性、可行性、输入、输出（五特性）。

**相关真题考点**：暂无真题

### 8. 时间复杂度
> 🔑 锚点：T(n) = O(f(n)) ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**评价算法看时间，不看代码不看机**

**内容**：估算算法执行时间随规模增长的趋势。

**相关真题考点**：
- [单选] 评价算法的指标 → 选**时间复杂度**；⚠ 陷阱：执行时间、代码长度、编程语言都是干扰项

### 9. 复杂度排序
> 🔑 锚点：小到大 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**1、log、n、nlog、n²、2ⁿ 一路飙升**

**内容**：O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(2ⁿ)

**相关真题考点**：暂无真题（常作为复杂度比较题的判据）

### 10. 空间复杂度
> 🔑 锚点：占多少内存 ｜ ⭐ ★★☆☆☆ ｜ 📝 填空
> 🧠 口诀：**时间看快慢，空间看占用**

**内容**：估算算法所需存储空间。

**相关真题考点**：暂无真题

## 第二章 线性表（真题约 8 题）

### 1. 线性表的定义
> 🔑 锚点：n 非负整数 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**n 从 0 起算，0 是空表**

**内容**：n 个数据元素的有限序列，n 是**非负整数**（n=0 是空表）。

**相关真题考点**：
- [单选] n 的取值 → 选"非负整数"；⚠ 陷阱："任意正整数"漏了 0

### 2. 顺序表的特点 ✦
> 🔑 锚点：物理也相邻 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空/计算
> 🧠 口诀：**逻辑相邻物理也相邻，下标访问 O(1)**

**内容**：逻辑相邻物理也相邻；随机存取（下标访问 O(1)）。地址公式：**LOC(i) = 首址 + (i−1)×L**。

**相关真题考点**：
- [单选] 顺序表地址计算 ✦ → 代入 LOC(i) = 首址 + (i−1)×L；问"**占用的最后一个单元**"要再 + (L−1)。例：200 起、L=8，第 5 个元素首址 232，末单元 239

### 3. 顺序表的缺点
> 🔑 锚点：查快改慢 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**插删挪一半，容量定死了**

**内容**：插入删除需移动大量元素 O(n)；静态分配容量固定。

**相关真题考点**：
- [单选] 等概率插入平均移动次数 → **n/2** 次（删除是 (n−1)/2）

### 4. 链表的特点
> 🔑 锚点：物理不一定相邻 ｜ ⭐ ★★★☆☆ ｜ 📝 单选/填空
> 🧠 口诀：**逻辑相邻物理随意，从头遍历 O(n)**

**内容**：逻辑相邻物理不一定相邻；顺序存取（从头遍历 O(n)）。

**相关真题考点**：暂无真题（常作为顺序表对比选项出现）

### 5. 链表的优点（插入操作）
> 🔑 锚点：改指针即可 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空
> 🧠 口诀：**先连后断——先连新的，再断旧的**

**内容**：插入删除 O(1) 仅改指针；动态分配无容量限制。

**相关真题考点**：
- [单选] 带头结点表头插入 → 正确顺序 `p->next=head->next; head->next=p;`；⚠ 陷阱：先改 head->next 再用 p->next 的必断链
- [单选] p、q 之间插入 s → `s->next=p->next; p->next=s;`——同一原则，**先连新的，再断旧的**

### 6. 链表的缺点
> 🔑 锚点：慢 + 费空间 ｜ ⭐ ★★☆☆☆ ｜ 📝 填空
> 🧠 口诀：**存取靠遍历，指针占空间**

**内容**：存取慢需遍历；额外空间存指针。

**相关真题考点**：暂无真题

### 7. 单链表
> 🔑 锚点：一个指针 ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**数据域 + 一个后继指针**

**内容**：结点 = 数据域 + 后继指针。

**相关真题考点**：暂无真题

### 8. 双链表
> 🔑 锚点：两个指针 ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**前驱后继双指针，正反都能走**

**内容**：结点 = 数据域 + 前驱指针 + 后继指针（可反向遍历）。

**相关真题考点**：暂无真题

### 9. 循环链表
> 🔑 锚点：尾指头成环 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空
> 🧠 口诀：**判空指回头，不是 NULL**

**内容**：尾结点指针指向头结点；带头结点循环链表**空表判断 `head->next == head`**（普通单链表空才是 head->next == NULL）。

**相关真题考点**：
- [单选] 循环链表空链判断 → 选 `head->next == head`；⚠ 陷阱：别选 == NULL
- [单选] 仅尾指针循环链表插删 → 尾插 O(1)；删头也 O(1)（rear->next 就是头），答案 **O(1) 和 O(1)**

### 10. 链表的基本操作
> 🔑 锚点：逆置是常客 ｜ ⭐ ★★★☆☆ ｜ 📝 解答题
> 🧠 口诀：**增删查改遍历逆置**

**内容**：创建、插入、删除、查找、遍历、**逆置**。

**相关真题考点**：暂无真题（逆置常考解答大题）

**顺序表 vs 链表（选择题高频）**：

| 特性 | 顺序表 | 链表 |
|------|--------|------|
| 存取 | 随机存取 O(1) | 顺序存取 O(n) |
| 插入/删除 | 移动元素 O(n) | 改指针 O(1) |
| 空间 | 静态分配，可能浪费 | 动态分配，无浪费 |
| 适用 | 频繁查找少增删 | 频繁增删少查找 |

**相关真题考点**：
- [单选] 不宜用链表实现的排序 → **快速排序**（基准选取和划分需要随机访问）；插入/归并/基数都能在链表上做
- [单选] 不宜链式存储的结构 → **数组**（按下标直接访问）；无向图、二叉树、链表都可以链式存

## 第三章 栈和队列（真题约 7 题）

### 1. 栈的定义
> 🔑 锚点：只动栈顶 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空
> 🧠 口诀：**后面比它小的必须降序**

**内容**：仅在表尾（栈顶）插入和删除的线性表。

**相关真题考点**：
- [单选] 出栈序列合法性 → 判定法：出栈序列中每个元素**后面比它小的元素必须呈降序**。例 5,4,1,3,2：4 后面比它小的 1,3,2 不是降序 → 不可能

### 2. 栈的特点
> 🔑 锚点：LIFO ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**后进先出，像叠盘子**

**内容**：后进先出（Last In First Out）。

**相关真题考点**：暂无真题（融入出栈序列题考查）

### 3. 栈的存储 ✦
> 🔑 锚点：顺序栈 / 链栈 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**向上长：底 = 顶 −(n−1)×L**

**内容**：数组实现（顺序栈）/ 链表实现（链栈）。

**相关真题考点**：
- [单选] 顺序栈栈底地址 ✦ → top=top+1 是向上增长 → 栈底 = 栈顶地址 − (n−1)×L。例：栈顶 100、n=10、L=4 → 100−36=64。⚠ 栈顶指针向下增长则反过来

### 4. 栈的应用 ✦
> 🔑 锚点：函数调用家族 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空
> 🧠 口诀：**调用递归括号匹配，后缀求值迷宫求解**

**内容**：函数调用、**后缀（逆波兰）表达式求值**、括号匹配、递归、迷宫求解。

**相关真题考点**：
- [单选] 栈的应用 → 计算**后缀表达式**的值用栈；⚠ 陷阱：BFS 用队列、希尔排序用数组、散列查找用表

### 5. 后缀表达式求值 ✦
> 🔑 锚点：操作数栈 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**求值一个栈，转换才两个**

**内容**：扫描到操作数入栈，遇到运算符弹两个算完再压回。

**相关真题考点**：
- [单选] 后缀求值用几个栈 → **一个保存操作数及运算结果的栈**；⚠ 陷阱：两个栈是中缀转后缀的配置，别混
- [单选] 栈空间分配大小 ✦ → 按入出序列逐步模拟，记录**栈内同时存在的最大元素个数**。例 f..a 入、d,e,a,b,c,f 出 → 最大深度 4

### 6. 队列的定义
> 🔑 锚点：尾进头出 ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**队尾进、队头出**

**内容**：仅在表尾（队尾）插入、表头（队头）删除的线性表。

**相关真题考点**：暂无真题

### 7. 队列的特点
> 🔑 锚点：FIFO ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**先进先出，像排队买票**

**内容**：先进先出（First In First Out）。

**相关真题考点**：暂无真题（FIFO 常作为队列题的判断依据）

### 8. 循环队列 ✦
> 🔑 锚点：判空相等、判满牺牲一格 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**出队减、入队加，逆向倒推别忘 mod**

**内容**：判空 `front == rear`；判满 `(rear + 1) % MaxSize == front`（牺牲一个存储单元）。

**相关真题考点**：
- [单选] 循环队列逆向推导 ✦ → 原 rear = 现 rear − 入队次数，原 front = 现 front − 出队次数（**都要 mod MaxSize**）。例：现 rear=2, front=4，出队 2 入队 1 → 原 rear=1, front=2

### 9. 队列的应用
> 🔑 锚点：排队场景 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**缓冲打印 BFS**

**内容**：缓冲区、打印队列、**广度优先搜索（BFS）**。

**相关真题考点**：
- [单选] 不宜用栈求解 → **图的广度优先搜索**（用队列）；回文判断、括号匹配、数制转换都用栈

## 第四章 串、数组和广义表（真题约 7 题）

### 1. 串的定义
> 🔑 锚点：字符序列 ｜ ⭐ ★★☆☆☆ ｜ 📝 填空
> 🧠 口诀：**零个或多个字符的有限序列**

**内容**：零个或多个字符组成的有限序列。

**相关真题考点**：暂无真题

### 2. 朴素模式匹配
> 🔑 锚点：一个一个比 ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**主串回退慢慢比，O(n×m)**

**内容**：主串指针每轮回退，逐个字符比较，复杂度 O(n×m)。

**相关真题考点**：暂无真题

### 3. KMP 算法
> 🔑 锚点：next 数组不回溯 ｜ ⭐ ★★★☆☆ ｜ 📝 填空/解答
> 🧠 口诀：**利用部分匹配表，主串指针不回溯，O(n+m)**

**内容**：O(n+m)，利用部分匹配表（next 数组）避免主串指针回溯。

**相关真题考点**：暂无真题

### 4. 数组的存储 ✦
> 🔑 锚点：C 语言行优先 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**前面元素个数 × L + 基址**

**内容**：行优先 / 列优先；地址 = 基址 + 偏移元素个数 × 元素大小。

**相关真题考点**：
- [单选] 二维数组行优先地址 ✦ → 偏移 = 该元素**前面**的元素个数。0 起下标：偏移 = (i×列数 + j) × L + 基址。例：100 起、L=6、4 列，M[2][2] → (2×4+2)×6=60 → 160

### 5. 对称矩阵压缩 ✦
> 🔑 锚点：只存一半 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**含对角线 n(n+1)/2，整行累加 + 行内偏移**

**内容**：存上三角（含对角线）共 **n(n+1)/2** 个元素；上三角元素换位后套行优先公式。

**相关真题考点**：
- [单选] 对称矩阵压缩个数 → **n(n+1)/2**；⚠ 陷阱：n(n−1)/2 不含对角线，是坑
- [单选] 上三角压缩地址 ✦ → 先算前面几行元素总数（第 1 行 n 个、第 2 行 n−1 个…），再加行内偏移，最后 ×L+基址。例：6 阶 a34 → 6+5+1=12 个在前 → 10+12×2=34

### 6. 稀疏矩阵
> 🔑 锚点：三元组表 ｜ ⭐ ★★☆☆☆ ｜ 📝 填空
> 🧠 口诀：**三元组、十字链表**

**内容**：压缩存储方式：三元组表、十字链表。

**相关真题考点**：暂无真题

### 7. 广义表的表头
> 🔑 锚点：第一个元素 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**第一个元素原样取，不加不删**

**内容**：表头 = 第一个元素**原样取出**（可能是原子也可能是子表）。

**相关真题考点**：
- [单选] 求表头 → 第一个元素原样取，可能是原子也可能是子表

### 8. 广义表的表尾
> 🔑 锚点：除头都算 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空
> 🧠 口诀：**剩下的整体再套一层括号，永远是表**

**内容**：表尾 = 去掉第一个元素后**剩下的部分再套一层外括号**，**永远是表**（即使只有一个元素也要加括号）。

**相关真题考点**：
- [单选] 求表尾 → 例：LS=(A,B,(g,h)) 的表尾是 (B,(g,h))；⚠ 陷阱：表尾不是原子，必须带括号

### 9. head/tail 嵌套运算
> 🔑 锚点：剥洋葱 ｜ ⭐ ★★★★☆ ｜ 📝 单选
> 🧠 口诀：**每步写出中间结果，别心算跳步**

**内容**：从外往里逐层剥：head 取第一个、tail 去掉第一个。

**相关真题考点**：

### 6. 性质 3：叶子公式 ✦
> 🔑 锚点：n₀ = n₂ + 1 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空/计算
> 🧠 口诀：**叶子永远比双分支多一个**

**内容**：**n₀ = n₂ + 1**（叶子数 = 度为 2 结点数 + 1）。

**相关真题考点**：
- [单选] 分支结点数求叶结点最少 ✦ → 完全二叉树 n1 只能是 0 或 1；n1=1 时 n2=分支数−1，n0 最小 = **分支数**。例 7 个分支 → 叶最少 7
- [单选] 二叉树性质找错误 → 错误项通常是"**叶结点多于度 1 结点**"——n0 与 n1 没有必然大小关系（单支树可相等）；"二叉树可为空""可存数组"都对

### 7. 性质 4：完全二叉树深度

> 🧠 口诀：**k 叶同层 + 分支都俩孩 = 满，共 2k−1**

**内容**：深度 k 有 2^k − 1 个结点，每层都满。

**相关真题考点**：
- [单选] 全部 k 个叶结点同层且分支结点都有两个孩子 → 是满二叉树，结点数 = **2k − 1**

### 9. 完全二叉树 ✦
> 🔑 锚点：最后一层靠左 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**上面全满 + 分支×2**

**内容**：除最后一层外全满，最后一层从左往右排。

**相关真题考点**：
- [单选] 某层有叶求最多结点 ✦ → 例：第 4 层 5 个叶 → 1~3 层满（7 个），第 4 层 8−5=3 个分支，第 5 层最多 3×2=6 → 共 21。公式：**上面层全满 + 该层分支数 × 2**

### 2. 二分查找的前提 ✦
> 🔑 锚点：有序 + 顺序存储 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**无序先排序，链表不能二分**

**相关真题考点**：暂无真题（常作判断题考点）

### 3. 二分查找的思想 ✦
> 🔑 锚点：取中缩半 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**标索引，mid=(low+high)//2，每步写 low/high**

**内容**：比较中间元素缩小范围；mid = (low+high) // 2；O(logn)。

**相关真题考点**：
- [单选] 二分查找比较序列 ✦ → 先标 0~n−1 索引，逐次算 mid 记录 arr[mid]，**每步写 low/high** 防错

### 4. 二分查找的长度与判定树 ✦
> 🔑 锚点：等于层数 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**比较次数数层数，前 k 层共 2^k−1**

**内容**：判定树中关键字所在层数即查找长度（根为第 1 层）；判定树**只是一棵二叉树**，不一定满、不一定完全、叶子不一定同层。

**相关真题考点**：
- [单选] 二分查找比较次数 ✦ → 模拟数比较了几次。例 9 元素查 82：62→82，共 2 次
- [单选] 判定树的结构性质 → **只保证是二叉树**；⚠ 陷阱：不一定满、不一定完全、叶子不一定同层
- [单选] 长度 ≤ k 的关键字个数 → 判定树前 k 层节点总数 = **2^k − 1**（n 足够大时前 k 层满，n≥100 保 k=4）

### 5. BST 查找
> 🔑 锚点：平均 logn ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**平均对数级，有序插入退化成链**

**内容**：平均 O(logn)，最坏（有序插入退化）O(n)。

**相关真题考点**：暂无真题

### 6. B 树
> 🔑 锚点：多路平衡 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空
> 🧠 口诀：**关键字 ⌈m/2⌉−1 到 m−1，子树至多 m 棵**

**内容**：多路平衡查找树，用于数据库、文件系统；所有叶在同一层。

**相关真题考点**：
- [单选] m 阶 B 树性质 → 正确项：非根结点关键字数满足 **⌈m/2⌉−1 ≤ n ≤ m−1**。⚠ 陷阱：非终端至多 **m** 棵子树（不是 m+1）；根至少 **1** 个关键字（2 棵子树）；所有叶在同一层

### 7. 散列函数
> 🔑 锚点：除留余数 ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**H(key) = key % p**

**内容**：常用除留余数法 H(key) = key % p。

**相关真题考点**：暂无真题

### 8. 冲突处理
> 🔑 锚点：两大家族 ｜ ⭐ ★★★☆☆ ｜ 📝 填空
> 🧠 口诀：**开放定址 vs 拉链**

**内容**：开放定址法（线性探测、二次探测）；链地址法（拉链）。

**相关真题考点**：暂无真题

### 9. 散列查找
> 🔑 锚点：O(1) ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**散列函数一步定位，最好 O(1)**

**内容**：平均查找时间 O(1)，效率最高。

**相关真题考点**：
- [单选] 散列查找最好复杂度 → **O(1)**（散列函数一步定位）

### 10. 线性探测 ✦
> 🔑 锚点：堆积 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算

## 第八章 排序（真题约 10 题，重中之重）

**八大排序必背表**：

| 算法 | 基本思想 | 时间复杂度 | 空间 | 稳定性 |
|------|---------|-----------|------|--------|
| 直接插入 | 逐个插入有序区 | 最好 O(n)，平均/最坏 O(n²) | O(1) | 稳定 |
| 希尔 | 分组插入，缩小增量 | O(n^1.3) ~ O(n²) | O(1) | 不稳定 |
| 冒泡 | 相邻比较，大的下沉 | 最好 O(n)，平均/最坏 O(n²) | O(1) | 稳定 |
| 快速排序 ✦ | 选基准，分治递归 | 最好/平均 O(nlogn)，最坏 O(n²) | O(logn)~O(n) | 不稳定 |
| 简单选择 ✦ | 选最小放有序区 | 始终 O(n²) | O(1) | 不稳定 |
| 堆排序 ✦ | 建堆、选堆顶、调整 | 始终 O(nlogn) | O(1) | 不稳定 |
| 归并 | 分治，两两归并 | 始终 O(nlogn) | O(n) | 稳定 |
| 基数 | 按位分配收集 | O(d(n+r)) | O(n+r) | 稳定 |

### 1. 内部排序
> 🔑 锚点：全程内存 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**数据全在内存里排序**

**内容**：待排序数据保存在**内存储器**中。

**相关真题考点**：
- [单选] 内排序的定义 → 待排序数据保存在**内存储器**中

### 2. 外部排序
> 🔑 锚点：外存 + 归并 ｜ ⭐ ★★☆☆☆ ｜ 📝 填空
> 🧠 口诀：**数据在外存，常用归并**

**内容**：数据在外存（磁盘），常用归并排序。

**相关真题考点**：暂无真题

### 3. 稳定与不稳定
> 🔑 锚点：插冒归基稳，希快选堆不稳 ｜ ⭐ ★★★★★ ｜ 📝 单选/填空
> 🧠 口诀：**「插冒归基」稳，「希快选堆」不稳**

**内容**：稳定 = 直接插入、冒泡、归并、基数；不稳定 = 希尔、快速、简单选择、堆。**稳定性只与算法本身有关，与数据无关**。

**相关真题考点**：
- [单选] 不稳定的排序 → 选项中**直接选择排序**不稳定；归并/插入/基数稳定

### 4. 每趟选最终位置
> 🔑 锚点：交换类 ｜ ⭐ ★★★★☆ ｜ 📝 单选
> 🧠 口诀：**快冒选堆每趟归位一个**

**内容**：快排、冒泡、选择、堆每趟至少一个元素到位。

**相关真题考点**：
- [单选] 每趟选最终位置且不稳定 → 每趟归位一个元素：冒泡(稳)、快排(不稳)、选择(不稳)、堆(不稳)；不稳定且每趟归位 → **快速排序**（选项里出现谁选谁）

### 5. 比较次数与初序无关
> 🔑 锚点：选择排序 ｜ ⭐ ★★★★★ ｜ 📝 单选
> 🧠 口诀：**简单选择雷打不动 n(n−1)/2 次**

**内容**：简单选择排序始终比较 n(n−1)/2 次，与初始顺序无关。

**相关真题考点**：
- [单选] 比较次数与初序无关 → **直接选择排序**；⚠ 陷阱：插排/冒泡的比较次数都跟初序有关

### 6. 快排的最坏情况
> 🔑 锚点：已有序 ｜ ⭐ ★★★★☆ ｜ 📝 单选/填空
> 🧠 口诀：**原表有序退化 O(n²)，随机选基准优化**

**内容**：原表有序时退化为 O(n²)；优化：随机选基准。

**相关真题考点**：暂无真题（常作性质判断出现）

### 7. 堆排序 ✦
> 🔑 锚点：建堆 + 调整 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**升序大顶堆、降序小顶堆；建堆 O(n)、调整 O(logn)**

**内容**：建堆 O(n)，每次调整 O(logn)，总 O(nlogn)；从最后一个非叶结点 ⌊n/2⌋−1 起自后往前调整。

**相关真题考点**：
- [单选] 建初始堆 ✦ → **降序排序建小顶堆**（每次取最小放后面）。例 35,58,24,13,44,19,10 → 小顶堆 10,13,19,58,44,35,24
- [单选] 最坏复杂度非 O(n²) → 插入/冒泡/快排最坏都 O(n²)，**堆排序**始终 O(nlogn)

### 8. 希尔排序 ✦
> 🔑 锚点：分组插入 ｜ ⭐ ★★★★★ ｜ 📝 单选/计算
> 🧠 口诀：**按增量分组，组内插入，别整趟重排**

**内容**：按增量 d 分成 d 组，**每组内部做插入排序**，逐组处理，增量逐渐缩小。

**相关真题考点**：
- [单选] 希尔排序两趟结果 ✦ → 别整趟重排！按增量 d 分成 d 组组内插入，增量序列 5,3 就做两轮

### 9. 排序趟次识别 ✦
> 🔑 锚点：特征指纹 ｜ ⭐ ★★★★★ ｜ 📝 单选
> 🧠 口诀：**插入看前缀、归并看等长块、快排看基准归位、冒泡选择看最终位**

**内容**：**直接插入**：前缀有序但元素未最终定位；**归并**：等长块内有序；**快排**：基准归位左右分块；**冒泡/选择**：出现一个最终位置元素（冒泡大数沉底、选择小数置顶）。

**相关真题考点**：
- [单选] 第 1 趟识别 → 例 8,9,10,4,…前三个有序且后面乱 → 直接插入排序
- [单选] 第 2 趟识别（含快速）→ 插入第 k 趟后**前 k+1 个元素有序**；冒泡/选择/归并两趟都达不到前缀有序时选插入

### 10. 排序选型
> 🔑 锚点：看场景 ｜ ⭐ ★★★☆☆ ｜ 📝 单选/填空
> 🧠 口诀：**基本有序插冒，大量无序快堆归，内存有限堆，要求稳定归并基数**

**内容**：数据基本有序时用插入/冒泡；数据量大且无序用快/堆/归；内存有限（空间 O(1)）用堆排序；要求稳定用归并/基数。

**相关真题考点**：暂无真题

## 第九章 高频考点速记清单

> 考前 10 分钟过一遍的浓缩版：

1. **复杂度**：O(1) < O(logn) < O(n) < O(nlogn) < O(n²)
2. **线性表**：顺序表随机存取、链表增删快
3. **栈 LIFO、队列 FIFO**；循环队列判满 (rear+1)%MaxSize == front
4. **二叉树**：n₀ = n₂ + 1；遍历先/中/后/层序
5. **哈夫曼**：WPL 最小；结点总数 2n−1；编码是前缀码
6. **图**：矩阵（稠密）、邻接表（稀疏）；DFS 栈、BFS 队列
7. **MST**：Prim 稠密、Kruskal 稀疏；最短路径：Dijkstra、Floyd
8. **查找**：二分要有序 O(logn)、散列 O(1)
9. **排序**：快/堆/归 O(nlogn)；插/冒/选 O(n²)；稳定 = 插冒归基

**送分公式速记**（背就完事）：

| 公式 | 含义 |
|------|------|
| 2n−1 | n 个叶子的哈夫曼树结点总数 |
| n(n+1)/2 | 对称矩阵压缩（含对角线）元素个数 |
| 2^k − 1 | 二分判定树前 k 层结点总数 / 深度 k 二叉树最多结点数 |
| n/2 | 顺序表等概率插入平均移动次数 |
| n + 2e | 无向图邻接表指针总数 |
| O(1) | 散列查找最好复杂度 / 栈顶操作 / 循环链表尾插删头 |
| DAG | 拓扑序列存在的充要条件 |

## 第十章 易错点提醒

| 易错点 | 正确认识 |
|--------|---------|
| 数据元素 vs 数据项 | 数据元素是**基本**单位，数据项是**最小**单位 |
| 线性表 n 的取值 | n 是**非负整数**（含 0），"任意正整数"是坑 |
| 链表插删指针顺序 | **先连后断**，防止断链 |
| 循环链表判空 | `head->next == head`，不是 == NULL |
| 循环队列逆向推导 | 出队减、入队加，**都要 mod MaxSize** |
| 栈底地址计算 | 先看增长方向：向上长 底=顶−(n−1)×L |
| 遍历还原二叉树 | 先/后 + 中序可以；**先 + 后序不行** |
| 对称矩阵压缩 | **n(n+1)/2 含对角线**；n(n−1)/2 不含，是坑 |
| 广义表表尾 | **永远是表**（再套一层括号），不是原子 |
| 广义表深度 | 原子 0、空表 1、其余数括号含最外层 |
| 二叉树性质 | n₀ 与 n₁ 无必然大小关系（单支树可相等） |
| BST 层数与值 | 层深不代表值大，选"不确定" |
| 判定树 | **只是一棵二叉树**，不一定满/完全/叶同层 |
| m 阶 B 树 | 非终端至多 **m** 棵子树（不是 m+1）；根至少 1 个关键字 |
| 邻接矩阵对称性 | 无向图一定对称，有向图不一定 |
| 后缀表达式求值 | **一个**操作数栈；两个栈是中缀转后缀 |
| 希尔排序 | 按增量分组**组内插入**，别整趟重排 |
| 快排最坏情况 | 原表有序时退化 O(n²)，随机选基准优化 |
| 堆排序时间 | 建堆 O(n) + 调整 O(logn)，总 O(nlogn) |
| 散列冲突 | 链地址法优于开放定址，无堆积问题 |
| 稳定性归属 | 稳定性只与**算法本身**有关，与数据无关 |
| 哈夫曼树 | WPL 最小但**不唯一**（两最小权相等时）；无度 1 结点 |
| 三组反义坑 | "基本/最小""线性/非线性""稳定/不稳定" |

## 第十一章 考场策略总结

1. **概念题（约 20 分）**：靠锚点直接反应，注意"基本/最小""线性/非线性""稳定/不稳定"三组反义坑
2. **计算题（约 15 分）**：地址计算先写偏移公式再代入；栈/队列逆向推导注意 **mod**；二分模拟每步写 low/high
3. **模拟题（约 15 分）**：BST 插入、堆调整、希尔分组、二分查找——动手画，别心算
4. **识别题（约 10 分）**：排序趟次指纹对照 + 排序性质组合（稳定性 × 归位性 × 比较次数固定性）
5. **送分记忆题（约 10 分）**：2n−1、n(n+1)/2、2^k−1、n/2、n+2e、O(1)、DAG——背就完事
