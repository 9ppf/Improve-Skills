## 题型一：图的遍历与生成树（DFS 与 BFS）

### 1. 核心概念与前提条件
- **生成树定义**：对含 n 个顶点的连通图，其生成树是包含全部 n 个顶点、且边最少的连通子图。
- **边数恒定（铁律）**：无论深度优先生成树（T1）还是广度优先生成树（T2），都恰好包含 **n-1 条边**。
- **高度关系（铁律）**：BFS 生成树的高度（层数） **≤** DFS 生成树的高度。
- **唯一性特例（铁律）**：当且仅当**图 G 本身就是一棵树（无环连通图）**时，T1 与 T2 一定相同。
- **一般情况**：对于有环的图，因遍历策略不同，T1 与 T2 通常不同，但也可能相同。

### 2. 通用做题步骤
1. **抓死概念**：题干出现"生成树"，立刻默念：**n 个顶点 → n-1 条边**，先把"边数"一类的绝对化选项秒掉。
2. **判断图是否含环**：若图本身无环（链 / 树形），则 T1 = T2；若图有环，再看遍历策略差异。
3. **找极端特例**：遇到"一定相同 / 一定不同"这类绝对化字眼，立刻在脑中画图测试（直线 vs 正方形 / 三角形），用特例推翻绝对结论。
4. **得出结论**：能找到"相同"和"不同"两种情况 → 只能选"可能相同"。

### 3. 进阶考点与核心推导
- **高度差异的由来**：BFS 一层一层向外铺，天然更"矮"；DFS 一条道走到黑再回溯，容易更"高"。所以 BFS 高度 ≤ DFS 高度是结构性结论，不是巧合。
- **相同与不同的边界**：相同只发生在"环不影响遍历顺序"的情形（如本身就是树）；只要有环且环上节点的访问顺序随策略变化，T1 与 T2 就不同。但"有环"仅是"通常不同"，不保证"一定不同"。

### 4. 易错点总结（排雷区）

| 易错点（错误做法） | 正确做法（避坑指南） |
| :--- | :--- |
| 看到"生成树"就以为 T1、T2 边数可能不同 | 生成树边数恒为 n-1，T1 与 T2 边数一定相等 |
| 想当然认为 T1 与 T2 一定相同（选项 A） | 仅当图本身是树（无环）时才一定相同 |
| 想当然认为 T1 与 T2 一定不相同（选项 C） | 有环也可能相同，不能选"一定不" |
| 用"三角形有环就不同"反推"有环必不同" | 有环仅"通常不同"，逻辑上只能选"可能相同" |

### 5. 例题补充

#### 例题 1：判断 DFS / BFS 生成树的关系（经典选择题）
**题目**：关于图 G 的深度优先生成树 T1 与广度优先生成树 T2，下列叙述中正确的是（ ）。
A. T1 与 T2 一定相同
B. T1 与 T2 可能相同
C. T1 与 T2 一定不相同
D. T1 与 T2 中所含边数不相等

**解题过程（用排除法）**：
- **秒杀 D**：T1、T2 都是生成树，边数都必定是 n-1，不可能不相等。
- **判断 A 和 C（找特例）**：
  - 若图 G 退化为一条链或一棵树（无环），无论 DFS 还是 BFS 只能保留全部原边，此时 T1 = T2 → A 在这种情况成立，C 不成立。
  - 若图 G 是三角形（有环），DFS 可能生成深度 3 的树，BFS 生成深度 2 的树，此时 T1 ≠ T2 → C 在这种情况成立，A 不成立。
- **结论**：既然既有相同、也有不同的情况，逻辑上只能选"可能相同"。

**答案**：B
**解析/避坑提示**：本题核心是"绝对化字眼要用特例推翻"。"一定相同 / 一定不同 / 边数不等"都是绝对化表述，逐一用特例（树 vs 三角）检验即可，不必算具体遍历。

## 题型二：邻接矩阵与顶点的度

### 一、度的核心性质（握手定理推论）

1. **有向图**：所有顶点的**出度之和 = 入度之和 = 边的总数**。
   - *解释：每条有向边必定贡献 1 个出度和 1 个入度。*
2. **无向图**：所有顶点的**度数之和 = 2 × 边的总数**。
   - *解释：无向图中一条边连接两个顶点，为两端各贡献 1 个度。*

### 二、如何用矩阵判断有向图和无向图

#### 1. 无向图的邻接矩阵（必定对称）

特点：矩阵沿主对角线对称（即 A[i][j] = A[j][i]）。

```text
    [ A  B  C ]
A   [ 0  1  1 ]
B   [ 1  0  1 ]  <-- A[0][1]=1，B[1][0]=1，对称
C   [ 1  1  0 ]
```

行和 = 列和 = 该顶点的度。

#### 2. 有向图的邻接矩阵（通常不对称）

特点：矩阵通常不对称。如果 A[i][j] = 1 但 A[j][i] = 0，说明只有从 i 指向 j 的单向边。

```text
    [ A  B  C ]
A   [ 0  1  1 ]
B   [ 0  0  1 ]  <-- A[0][1]=1，但 B[1][0]=0，不对称
C   [ 0  0  0 ]
```

行和 = 出度，列和 = 入度，总度 = 行和 + 列和。

### 三、矩阵特性总结表

| 对比维度 | 无向图矩阵 | 有向图矩阵 |
| :--- | :--- | :--- |
| 对称性 | 必定对称（A[i][j] = A[j][i]） | 通常不对称 |
| 顶点度数 | 度 = 行和 = 列和 | 度 = 出度（行和）+ 入度（列和） |
| 元素含义 | A[i][j]=1 表示 i 和 j 互通 | A[i][j]=1 表示 i 指向 j |
| 度数之和 | 所有度数之和 = 2 × 边数 | 所有出度之和 = 所有入度之和 = 边数 |

### 四、例题补充

#### 例题 1：无向图求度
**题目**：已知无向图的邻接矩阵如下，求各顶点的度。
```text
[ 0  1  1 ]
A = [ 1  0  1 ]
[ 1  1  0 ]
```
**解析**：
- 矩阵对称 → 无向图。
- 顶点 1（第 1 行）：0 + 1 + 1 = 2
- 顶点 2（第 2 行）：1 + 0 + 1 = 2
- 顶点 3（第 3 行）：1 + 1 + 0 = 2

**答案**：2, 2, 2

---

#### 例题 2：有向图求度（易错题）
**题目**：已知有向图的邻接矩阵如下，求各顶点的度（注意陷阱选项 2,2,1,1 只是出度）。
```text
[ 0  1  0  1 ]
A = [ 0  0  1  1 ]
[ 0  1  0  0 ]
[ 1  0  0  0 ]
```
**解析**：
- 矩阵不对称 → 有向图，度 = 出度（行和）+ 入度（列和）。
- 顶点 1：出度（第 1 行和 2）+ 入度（第 1 列和 1）= 3
- 顶点 2：出度（第 2 行和 2）+ 入度（第 2 列和 2）= 4
- 顶点 3：出度（第 3 行和 1）+ 入度（第 3 列和 1）= 2
- 顶点 4：出度（第 4 行和 1）+ 入度（第 4 列和 2）= 3

**答案**：3, 4, 2, 3
**解析/避坑提示**：若只算行和会得到 2,2,1,1，这正是命题人埋的干扰项。有向图问"度"必须出度、入度相加。

---

### 五、一句话记忆

> **矩阵对称是无向，不对称必有向。**
> **无向图看一行，有向图看两行。**
> **行是出，列是入，相加才是真度数。**
> **无向度和等于边数两倍，有向出度入度各自等于边数。**

## 题型三：拓扑排序

### 1. 核心概念与前提条件
- **适用前提**：拓扑排序**只适用于有向无环图（DAG）**。
- **存在性（充要条件）**：图 G 存在拓扑序列 ⟺ G 是有向无环图（DAG）。
- **唯一性**：拓扑序列**不一定唯一**；若排序过程中同时存在多个入度为 0 的顶点，它们的先后可任意，序列即不唯一。
- **无向图**：无向图没有拓扑排序的概念。

### 2. 通用做题步骤
1. **抓死前提**：题干出现"拓扑排序"，立刻默念：**有向无环图（DAG）**。
2. **反例法**：遇到"唯一"等绝对化字眼，立刻画"V"字形（A→B, A→C）或菱形图，找多个入度为 0 的顶点打破唯一性。
3. **排除法**：无向图直接排除；单纯说"有向图"的选项要警惕（可能含环，未必能拓扑排序）。

### 3. 进阶考点与核心推导
- **唯一性的判断**：拓扑序列是否唯一，取决于每一步"入度为 0 的顶点"是否唯一。只要某一时刻出现 ≥2 个入度 0 顶点，序列就不唯一。
- **有向图 ≠ DAG**：有向图如果存在环，则不存在拓扑序列。所以"是有向图"只是必要不充分条件，表述不如"有向无环图"准确。

### 4. 易错点总结（排雷区）

| 易错点（错误做法） | 正确做法（避坑指南） |
| :--- | :--- |
| 认为"有向图"就能拓扑排序（选项 A） | 有向图若有环则不能拓扑排序，A 必要不充分 |
| 认为拓扑序列唯一（选项 B） | 多个入度 0 顶点并存时序列不唯一，用 V 形图反例 |
| 认为无向图也有拓扑排序（选项 C） | 无向图根本没有拓扑排序概念，直接排除 |
| 漏掉 DAG 是充要条件 | 存在拓扑序列 ⟺ 有向无环图，选表述最准确的 D |

### 5. 例题补充

#### 例题 1：拓扑排序的存在条件（经典选择题）
**题目**：设图 G 存在拓扑序列，则下列结论中正确的是（ ）。
A. 图 G 是一个有向图
B. 图 G 的拓扑序列唯一
C. 图 G 是一个无向图
D. 图 G 是一个有向无环图

**解题过程（排除法）**：
- **秒杀 A**：有向图若有环则不存在拓扑序列，A 必要不充分，表述不够准确。
- **秒杀 B**：反例——画 V 字形有向图（A→B, A→C），拓扑序列可为 A,B,C 或 A,C,B，不唯一。
- **秒杀 C**：无向图没有拓扑排序概念。
- **选 D**：有向无环图（DAG）是拓扑排序存在的充要条件，表述最准确。

**答案**：D
**解析/避坑提示**：本题四个选项步步设坑。记住"存在拓扑序列 ⟺ DAG"这一充要条件，优先选把前提说全的那个。

### 6. 一句话记忆

> **拓扑必须 DAG，有向无环是前提。**
> **有向不一定行（可能有环），无向绝对不行。**
> **序列唯一看入度，多个入度 0 必不唯一。**

## 题型四：最短路径与最小生成树算法

### 1. 核心概念与前提条件
- **迪杰斯特拉（Dijkstra）**：求**单源最短路径**（一个顶点到其余各顶点）；适用带权图且**权值 > 0**。
- **弗洛伊德（Floyd）**：求**多源最短路径**（任意两顶点之间）；适用带权图，**权值可正可负**。
- **普里姆（Prim）**：求**最小生成树（MST）**；连通带权图，贪心选点，适合**稠密图**。
- **克鲁斯卡尔（Kruskal）**：求**最小生成树（MST）**；连通带权图，选边 + 并查集，适合**稀疏图**。
- **哈夫曼（Huffman）**：构造**哈夫曼树（最优二叉树）**；带权叶子节点，用于**编码 / 压缩**，目标是带权路径长度最短。

### 2. 通用做题步骤
1. **抓死关键词**：
   - "单源 / 一个顶点到其余" → 迪杰斯特拉（Dijkstra）
   - "多源 / 任意两顶点" → 弗洛伊德（Floyd）
   - "最小生成树 / 连通所有点且总权值最小" → 普里姆（Prim）或克鲁斯卡尔（Kruskal）
   - "编码 / 压缩" → 哈夫曼（Huffman）
2. **看权值**：出现负权边时，迪杰斯特拉会失效，不能选；题目给"权值 > 0"正是在提示 Dijkstra 可用。
3. **区分"最短路径"与"最小生成树"**：前者求两点/多点的路径长度，后者求连通全图的最小总权值，二者目标不同，算法不可混用。

### 3. 进阶考点与核心推导

**核心算法对比表（必背）**

| 算法名称 | 核心用途 | 适用条件 | 关键词 |
| :--- | :--- | :--- | :--- |
| 迪杰斯特拉 Dijkstra | 单源最短路径 | 带权图，权值 > 0 | 单源、最短路径、权值非负 |
| 弗洛伊德 Floyd | 多源最短路径 | 带权图，权值可正可负 | 多源、最短路径、三重循环 |
| 普里姆 Prim | 最小生成树 MST | 连通带权图 | 选点、贪心、稠密图 |
| 克鲁斯卡尔 Kruskal | 最小生成树 MST | 连通带权图 | 选边、并查集、稀疏图 |
| 哈夫曼 Huffman | 构造哈夫曼树 | 带权叶子节点 | 编码、压缩、带权路径长度最短 |

- **Dijkstra 的负权限制**：Dijkstra 基于"已确定最短距离的顶点不会再被更新"的贪心假设，负权边会破坏该假设，故要求权值非负；负权场景需改用其他算法（如 Bellman-Ford）。

### 4. 易错点总结（排雷区）

| 易错点（错误做法） | 正确做法（避坑指南） |
| :--- | :--- |
| 把 Prim / Kruskal（最小生成树）当最短路径算法 | 最小生成树目标是"连通全图总权值最小"，不是两点间最短路径 |
| 把哈夫曼当图论最短路径算法 | 哈夫曼用于构造最优二叉树 / 数据压缩，与图最短路径无关 |
| 忽略"权值 > 0"条件直接选 Dijkstra | 题目给正权正是在提示 Dijkstra；出现负权则不能选 |
| 混淆"单源"与"多源" | 单源→Dijkstra，多源→Floyd |

### 5. 例题补充

#### 例题 1：按场景选算法（经典选择题）
**题目**：要在带权图（权值 > 0）中求从某一顶点到其余各顶点的最短路径，应采用的算法是（ ）。
A. 哈夫曼算法
B. 普里姆算法
C. 克鲁斯卡尔算法
D. 迪杰斯特拉算法

**解题过程（排除法）**：
- **秒杀 A**：哈夫曼用于构造哈夫曼树（数据压缩），不属于图最短路径算法。
- **秒杀 B、C**：Prim 与 Kruskal 都是求最小生成树的，目标是连通所有顶点且总权值最小，不是求两点间最短路径。
- **选 D**：Dijkstra 专解单源最短路径，且题目要求权值非负（>0），完全吻合。

**答案**：D
**解析/避坑提示**：本题考"关键词匹配"。题干"某一顶点到其余各顶点"= 单源，直接锁定 Dijkstra；"权值 > 0"进一步确认其适用前提。

## 综合记忆指南（考前速览）

- **遍历生成树**：边数恒为 n-1；高度 BFS ≤ DFS；是树才一定同，有环可能同可能不同。
- **邻接矩阵**：无向对称，有向不对称；无向行列相等，有向行是出、列是入，相加才是度。
- **拓扑排序**：必须是有向无环图（DAG）；序列可能不唯一；无向图绝对不行。
- **算法选择**：单源最短路径选迪杰斯特拉（Dijkstra）；多源最短路径选弗洛伊德（Floyd）；最小生成树选普里姆（Prim）或克鲁斯卡尔（Kruskal）；编码压缩选哈夫曼（Huffman）。
