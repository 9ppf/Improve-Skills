# 基数排序（LSD 最低位优先）—— 例题、算法与抢分技巧

## 一、题目

对于数据序列：`31, 5, 44, 55, 61, 30, 60, 20, 1, 4, 29`，采用**基数排序**算法进行升序排序，请写出每趟排序的结果。

---

## 二、推演过程

*(基数排序不比较大小，而是"按位分配、按位收集"。准备 0~9 十个桶。从最低位（个位）开始，依次分配到桶里，再按桶的顺序收集回来。然后排十位)*

**初始序列**：`31, 5, 44, 55, 61, 30, 60, 20, 1, 4, 29`

*(最大数是 61，两位数，所以只需排个位和十位两趟)*

### 🎯 第 1 趟：按"个位"分配与收集

**分配（入桶）**：

| 桶号 | 数字 |
| :--- | :--- |
| 0 号桶 | 30, 60, 20 |
| 1 号桶 | 31, 61, 1 |
| 2~3 号桶 | 无 |
| 4 号桶 | 44, 4 |
| 5 号桶 | 5, 55 |
| 9 号桶 | 29 |

**收集（出桶）**：按 0 到 9 号桶的顺序，把数字拿出来。**注意：每个桶内部是先进先出**。

> **第 1 趟结果**：`30, 60, 20, 31, 61, 1, 44, 4, 5, 55, 29`

### 🎯 第 2 趟：按"十位"分配与收集

**分配（入桶）**：*(没有十位的看作 0)*

| 桶号 | 数字 |
| :--- | :--- |
| 0 号桶 | 1, 4, 5 *(上一趟排好序的结果)* |
| 2 号桶 | 20, 29 |
| 3 号桶 | 30, 31 |
| 4 号桶 | 44 |
| 5 号桶 | 55 |
| 6 号桶 | 60, 61 |

**收集（出桶）**：按 0 到 9 号桶顺序收集。

> **最终结果**：`1, 4, 5, 20, 29, 30, 31, 44, 55, 60, 61`

---

## 三、核心思想（大白话）

想象有 10 个标着 0~9 的排队通道。

**第一趟看个位**：个位是几，就排到几号通道里去。排完后，按 0~9 号的顺序，把所有通道里的人连成一个大长队。此时，个位数字已经从小到大排好了。

**第二趟看十位**：在这个新队伍的基础上，十位是几，就重新去几号通道排队。再次按 0~9 号顺序收拢。此时，十位数字也排好了。

因为前面已经保证了个位有序，所以当十位排好时，整个数字就彻底有序了。

## 四、完整代码（伪代码理解即可）

*(考研极少考基数排序的代码，多为手算题，了解核心循环即可)*

```c
void RadixSort(int A[], int n)
{
    int max = 找到数组最大值;
    int d = 计算最大值的位数; // 决定要循环几趟

    // 从个位(exp=1)开始，依次处理十位(exp=10)，百位(exp=100)...
    for (int exp = 1; max / exp > 0; exp *= 10)
    {
        初始化 10 个桶(队列);

        // 1. 分配
        for (int i = 0; i < n; i++)
        {
            int digit = (A[i] / exp) % 10; // 取出当前位的数字
            把 A[i] 放进 digit 号桶;
        }

        // 2. 收集
        int k = 0;
        for (int i = 0; i <= 9; i++)
        {
            while (桶 i 不为空)
            {
                A[k++] = 桶 i 的队头元素出队;
            }
        }
    }
}
```

## 五、考场极速抢分技巧与答题规范（必看）

### ✍️ 1. 卷面答题规范与手算技巧

- **画出 10 个桶**：在草稿纸上竖向写下 0, 1, 2... 9，然后用手指标记，依次把数字放进对应的桶里。每个桶里面也是从左到右写（先进先出）。
- **收集千万别乱**：收集时，必须严格按照 `0号桶的所有数 -> 1号桶的所有数 -> 2号桶的所有数...` 的顺序抄下来，千万不要竖着拿（比如先拿每个桶的第一个，再拿第二个，那就全错了）。
- **卷面格式**：每一趟的结果直接写完整序列，最好在旁边标注一句：**（按个位分配收集）**，老师一看就知道你的思路。

### 🃏 2. 检查对错的秒杀技巧

- **看第一趟的末尾**：第一趟排完后，序列的最后几个数，其个位一定是最大的（比如 29 的个位是 9，它一定在末尾）。
- **看第 n 趟的末尾**：最后一趟排完后，数组必须完全有序。
- **注意隐含陷阱**：如果有负数怎么办？教材里的标准基数排序是**不处理负数**的（除非将正负数分开排）。如果有负数，通常题目会直接用绝对值或者另外说明。考研题中如果混有负数，需谨慎。

### 🎯 3. 选择题秒杀结论（直接背）

| 维度 | 结论 |
| :--- | :--- |
| **稳定性** | **稳定**（因为分配和收集的过程是"先进先出"的，相同大小的数不会改变相对顺序） |
| **时间复杂度** | **O(d(n+r))**。其中 `n` 是元素个数，`d` 是关键字的位数（比如两位数 d=2），`r` 是基数（如果是十进制数字，r=10）。当 d 很小的时候，时间复杂度接近 **O(n)**，这是它最大的优势 |
| **空间复杂度** | **O(n+r)**（需要开辟 r 个桶（队列）来存放元素，以及收集时的辅助空间） |
| **适用场景** | 数据量极大，但是数据的位数很少（比如全是几百、几千的整数，或者全是一样位数的字符串） |
