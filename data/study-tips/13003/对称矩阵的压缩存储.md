# 对称矩阵的压缩存储 做题笔记

## 一、核心概念与前提条件
- **对称矩阵定义**：n阶方阵中，满足 `aij = aji` 的矩阵。
- **适用前提**：通常只存储**下三角**元素到一维数组 `sa` 中。必须明确一维数组 `sa` 的下标起点（0或1）。
- **核心原则/公式**：
  - 存下三角，按行优先（0-based）：`k = i(i+1)/2 + j` (当 i≥j)
  - 存下三角，按行优先（1-based）：`k = i(i+1)/2 + j + 1` (当 i≥j)
  - 遇到上三角（i<j）时，利用对称性换位成 aji 代入下三角公式。

## 二、通用做题步骤
1. **第一步：判断区域**
   - 判断目标元素是否在下三角（`i >= j`）。如果是，直接进入第二步。
   - 如果是上三角（`i < j`），先将 `i` 和 `j` 互换。
2. **第二步：求前序行元素总数**
   - 计算从第0行到第 `i-1` 行的元素总和，套用等差数列求和：`i(i+1)/2`。
3. **第三步：加本行列偏移并调整起点**
   - 加上本行前面的元素个数（即列下标 `j`）。
   - 看一维数组 `sa` 是否从1开始，是则整体加1。

## 三、进阶考点与核心推导
### 1. 为什么是 i(i+1)/2？
- 下三角第0行1个，第1行2个……第i-1行i个。求和公式 `(首项+末项)*项数/2`，即 `(1+i)*i/2`。

## 四、易错点总结（排雷区）

| 易错点（错误做法） | 正确做法（避坑指南） |
| :--- | :--- |
| 遇到 i<j 时直接代公式 | 必须先互换 i 和 j，即算 `aji` 的位置 |
| 错用二维数组公式 i*n+j | 压缩存储每行长度递增，必须用等差求和 |
| 没注意数组从0还是从1开始 | 看选项是否有 +1，0-based不加，1-based加1 |
| 搞错本行偏移是 i 还是 j | 求 `aij` 前面有几个元素是 `j`，互换后求 `aji` 前面是 `i` |
