# 直接插入排序 —— 例题、算法与抢分技巧

## 一、题目

有关键字序列 `38, 19, 65, 13, 97, 49, 41, 95, 1, 73`，采用**直接插入排序**算法进行升序排序，请写出每趟排序的结果。

---

## 二、推演过程

*(默认第 1 个元素 `38` 已有序，用 `|` 隔开左边的"有序区"和右边的"无序区")*

- **初始状态**：`[38] | 19, 65, 13, 97, 49, 41, 95, 1, 73`
- **第 1 趟**（插 19）：19 < 38，从后往前比 1 次，插在 38 前。
  - `[19, 38] | 65, 13, 97, 49, 41, 95, 1, 73`
- **第 2 趟**（插 65）：65 > 38，比 1 次，直接放后面。
  - `[19, 38, 65] | 13, 97, 49, 41, 95, 1, 73`
- **第 3 趟**（插 13）：13 < 65，再比 38，再比 19，比 3 次，插最前面。
  - `[13, 19, 38, 65] | 97, 49, 41, 95, 1, 73`
- **第 4 趟**（插 97）：97 > 65，比 1 次，直接放后面。
  - `[13, 19, 38, 65, 97] | 49, 41, 95, 1, 73`
- **第 5 趟**（插 49）：49 < 97，比 65，比 38（比 49 小），停，插在 38 后。
  - `[13, 19, 38, 49, 65, 97] | 41, 95, 1, 73`
- **第 6 趟**（插 41）：41 < 97... 一直往前比到 38，插在 38 后。
  - `[13, 19, 38, 41, 49, 65, 97] | 95, 1, 73`
- **第 7 趟**（插 95）：95 < 97，95 > 65，插在 65 后。
  - `[13, 19, 38, 41, 49, 65, 95, 97] | 1, 73`
- **第 8 趟**（插 1）：比谁都小，插最前。
  - `[1, 13, 19, 38, 41, 49, 65, 95, 97] | 73`
- **第 9 趟**（插 73）：73 < 97，73 < 95，73 > 65，插在 65 后。
  - **最终结果**：`[1, 13, 19, 38, 41, 49, 65, 73, 95, 97]`

---

## 三、核心思想（大白话）

就像打扑克牌理牌。左手里的牌**已经排好序**，右手摸到一张**新牌**。
找位置时，**从左手最右边（最大的牌）开始，挨个往左比**。
如果比它大，就把那张牌往右挪一格；一直比到比它小（或者没牌了），就把新牌插进空出来的位置。

## 四、完整代码 + 下标级注释

> **核心下标说明**：`i` 是当前要摸的新牌位置；`j` 是找位置和挪牌的临时下标。

```c
void InsertSort(SeqList R[], int n)
{
    SeqList x;          // 【暂存新牌】用来装当前要插入的那个元素
    int j;              // 【搬运工下标】负责从后往前找位置，并把牌往后挪

    // 默认第1个元素 R[1] 已经排好序，从第2个元素（i=2）开始往后遍历插入
    for (int i = 2; i <= n; i++)
    {
        x = R[i];       // 【拿牌】把第 i 个位置的元素抽出来，暂存在 x 中

        j = i - 1;      // 【开始找位置】j 从有序区的最后一个位置开始，一直往左走

        // 【核心循环：边找位置边挪牌】
        // 只要 j 还没越界(>=1)，并且 j 位置的牌比手里的新牌大
        while (j >= 1 && R[j].key > x.key)
        {
            R[j+1] = R[j];  // 就把 j 位置的牌往后挪一格（给新牌腾地方）
            j--;            // j 继续往左走，看下一张牌
        }

        // 【插入】
        // 循环结束时，j 停下的位置，要么是 0（新牌最小），要么是 R[j] <= x.key
        // 所以新牌应该放在 j 的右边，即 j+1 的位置
        R[j+1] = x;
    }
}
```

## 五、考场极速抢分技巧（必看！）

### 🃏 1. 手算推演技巧（大题）

- **画竖线法**：答题时一定要在有序区和无序区之间画一条竖线 `|`，老师阅卷一眼就能看懂。
- **只盯边界**：拿新牌 `x` 出来，只和有序区最右边的牌比。如果比边界大，直接放右边（1次就结束，比如插 65、97）；如果比边界小，才需要继续往左比。
- **不重不漏**：写每一趟结果时，千万别把后面的无序区抄错了。没参与排序的数字，照抄原位即可。

### 💻 2. 代码填空/改错技巧

- **防越界条件**：`while` 循环里的 `j >= 1` 绝对不能丢！如果不写，当新牌是全场最小的时候，`j` 会一直减到 0 甚至负数，导致数组越界崩溃。
- **比较符号**：一定是 `R[j].key > x.key`。如果写成 `>=` 就会破坏算法的稳定性（相同的牌会被挪动位置）。
- **插回位置**：跳出循环后，一定是插在 `j+1` 的位置，不是 `j`。因为此时 `j` 指向的是那个比新牌小的元素，或者 `j=0`。
- **哨兵优化（选择题常考）**：有时候代码里会写 `R[0] = R[i]; j = i - 1; while(R[0].key < R[j].key) ...`。这里的 `R[0]` 就是**哨兵**，它的作用是省去 `j >= 1` 的越界判断，提高一点运行速度。

### 🎯 3. 选择题秒杀结论（直接背）

| 维度 | 结论 |
| :--- | :--- |
| **最好情况** | 原数组已经升序。比较次数 **n−1**，移动次数 **0**。时间复杂度 **O(n)** |
| **最坏情况** | 原数组是逆序。比较和移动次数都达到最大。时间复杂度 **O(n²)** |
| **平均情况** | 时间复杂度 **O(n²)** |
| **空间复杂度** | **O(1)**（只需要一个临时变量 `x`） |
| **稳定性** | **稳定**（遇到相等的牌就停下来，不会跨越它们） |
| **适用场景** | 数据量较小，或者原数组**基本有序**（此时直接插入排序的效率极高） |
