# 循环队列的指针变化与逆向推导 做题笔记

## 一、核心概念与前提条件
- **循环队列定义**：使用固定大小的数组（长度为 `MaxSize`）首尾相连形成的逻辑环形结构，通过取模运算实现“循环”效果。
- **适用前提**：数组容量固定；需维护队头指针 `front`（指向队头元素）和队尾指针 `rear`（指向队尾元素的下一个位置）。
- **核心原则/公式**：
  - **正向入队**：`rear = (rear + 1) % MaxSize`
  - **正向出队**：`front = (front + 1) % MaxSize`
  - **逆向撤销入队**：`rear = (rear - 1 + MaxSize) % MaxSize`
  - **逆向撤销出队**：`front = (front - 1 + MaxSize) % MaxSize`
  - *对比*：入队只动 `rear`，出队只动 `front`，不要混淆。

## 二、通用做题步骤
1. **[第一步：明确已知条件与最终状态]**：记录数组大小 `MaxSize`，当前操作序列（如出队x次，入队y次），以及操作后的 `rear` 和 `front` 值。
2. **[第二步：逆向撤销操作（重点）]**：
   - **逆操作顺序**：与正向操作完全相反，先撤销最后一步操作（如入队），再撤销之前的操作（如出队）。
   - **指针回退**：将 `rear` 或 `front` 减去对应的操作步数。
   - **循环取模**：遇到减法时，必须使用公式 `(当前值 - 步数 + MaxSize) % MaxSize` 处理，防止指针出现负数。
3. **[第三步：正向验证]**：将倒推得出的初始状态，按照题目正向操作一遍，检查最终状态是否与题目给出的一致。

## 三、进阶考点与核心推导
### 1. 队列中元素个数计算
- **公式**：`元素个数 = (rear - front + MaxSize) % MaxSize`
- **说明**：无论 `rear` 在 `front` 前面还是后面，加上 `MaxSize` 再取模即可得到正确的元素数量（前提是不使用牺牲单元法，或者已知当前不是队满状态）。

### 2. 队空与队满的判断
- **无标志位/牺牲单元法**：`front == rear` 只能说明队空或队满。
  - **方案 A（牺牲一个存储单元）**：队空 `front == rear`；队满 `(rear + 1) % MaxSize == front`。
  - **方案 B（增设标志位）**：用 `tag` 标记最近一次操作是入队还是出队。入队导致 `front == rear` 为满；出队导致 `front == rear` 为空。

## 四、易错点总结（排雷区）

| 易错点（错误做法） | 正确做法（避坑指南） |
| :--- | :--- |
| 正向推导设未知数解方程 | **坚决使用逆向倒推法**，从最终状态回退，省时且不容易绕晕。 |
| 倒推时忘记加 `MaxSize` 取模，出现负数 | 只要是减法操作，必须写为 `(值 - 步数 + MaxSize) % MaxSize`。 |
| 弄反 `front` 和 `rear` 的移动方向 | 记住：**入队尾动（rear+1），出队头动（front+1）**。 |
| 把数组大小（MaxSize）当成队列元素个数 | 指针只是数组下标，元素个数需要通过 `(rear - front + MaxSize) % MaxSize` 计算。 |

## 五、例题补充

### 例题 1：已知操作后状态，求初始状态

**题目**：使用一个大小为6的数组保存循环队列Q。若从Q中出队两个元素，并入队一个元素，此时队尾rear和队头front的值分别为2和4。则在执行这三个操作之前rear和front的值分别是（  ）。
A. 0和3
B. 1和2
C. 2和5
D. 4和5

**解题过程**：
| 步骤 | 操作类型 | rear 值推导 | front 值推导 | 状态说明 | 操作/判断 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0 | 最终态 | 2 | 4 | 已知条件 | 初始 MaxSize = 6 |
| 1 | 撤销入队 | `(2 - 1 + 6) % 6 = 1` | 4 | 中间态 | 入队时rear+1，倒推时rear-1 |
| 2 | 撤销出队2个 | 1 | `(4 - 2 + 6) % 6 = 2` | 初始态 | 出队时front+1，倒推2次则front-2 |

**答案**：B. 1和2

**解析/避坑提示**：
- 本题是典型的“已知结果求初始”题型。千万不要设初始未知数正推，极其容易绕晕或漏掉取模。
- **正向验证**：初始 `front=2, rear=1`。出队2个，`front` 变为 `3`、`4`；入队1个，`rear` 变为 `(1+1)%6=2`。最终 `front=4, rear=2`，与题意完全吻合。

### 例题 2：求当前队列中的元素个数

**题目**：一个循环队列存放在大小为10的数组中，当前 `front = 6`，`rear = 2`。请问当前队列中有多少个元素？

**解析**：
- 分析：`front` 位于下标6，`rear` 位于下标2。此时 `rear` 在 `front` 前面，说明队列已经“绕了一圈”。
- 使用公式计算元素个数。
- 计算：`(rear - front + MaxSize) % MaxSize = (2 - 6 + 10) % 10 = 6 % 10 = 6`。
- 得出结论：当前队列中有6个元素。

**答案**：6个。
