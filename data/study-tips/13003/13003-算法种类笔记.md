## 📂 算法一：链表操作 —— 单链表首结点移至末尾（循环左移1位）

### 📌 原题重现

**阅读下列程序，并回答问题：**

```c
LinkList mynote(LinkList L) // L是不带头结点的单链表的头指针
{
    // 1. 边界判断：如果链表为空，或只有一个结点，则不需要移动
    if (L && L->next)
    {
        q = L;            // 2. 暂存首结点：q 指向原链表的第一个结点 (a1)
        L = L->next;      // 3. 移动头指针：L 指向原链表的第二个结点 (a2)，它将成为新头
        p = L;            // 4. 准备遍历：p 也从第二个结点 (a2) 开始
        S1: while (p->next) // 5. 找尾结点：如果 p 后面还有结点
                p = p->next;    //    就继续往后走，循环结束时，p 停在原尾结点 (an)
        S2: p->next = q;    // 6. 尾部接头部：把原尾结点 (an) 的 next 指向原首结点 (a1)
        q->next = NULL;     // 7. 断开旧链接：原首结点 (a1) 现在变成新尾结点了，它的 next 必须置空，防止成环
    }
    return L;               // 8. 返回新的头指针（此时指向原链表的第二个结点 a2）
}
```

**问题 (1)**：说明语句 S1 及 S2 的功能；
**问题 (2)**：设链表表示的线性表为 (a1, a2, ..., an)，写出算法执行后的返回值所表示的线性表。

### ✅ 标准答案

**(1) 语句 S1 及 S2 的功能：**

- **语句 S1 的功能**：遍历单链表，查找并定位原单链表的尾结点。循环结束后，指针 `p` 指向原链表的最后一个结点（即 `an`）。
- **语句 S2 的功能**：将原链表的首结点（`q` 指向的结点）链接到当前尾结点（`p` 指向的结点）的后面，并将原首结点的 `next` 域置为 `NULL`，使其成为新链表的尾结点。

**(2) 返回值所表示的线性表：**

`(a2, a3, ..., an, a1)`

### 💡 原题代码逻辑拆解（白话版）

- **保存老大哥**：`q = L` 就像用一只手死死拽住第一节车厢（a1）。
- **新车上位**：`L = L->next` 让第二节车厢（a2）变成新的车头。
- **巡道工找尾巴**：`p` 从新车头出发，`while` 循环一直往后跑，直到跑到最后一节车厢（an）。
- **首尾相连**：把最后一节车厢（an）的钩子挂到老大哥（a1）身上，然后把老大哥（a1）屁股后面的钩子剪断（`q->next = NULL`）。

### 一、 算法功能与核心思想

- **功能**：将单链表的第一个结点摘下，插入到链表的末尾。
- **效果**：原链表 `(a1, a2, ..., an)` ➡️ 操作后变为 `(a2, a3, ..., an, a1)`。
- **核心步骤**：
  1. **暂存**：保存第一个结点（指针 `q`）。
  2. **更新头指针**：让新头指针指向第二个结点（`L = L->next`）。
  3. **找尾**：遍历链表，找到最后一个结点（指针 `p`）。
  4. **拼接**：将尾结点的 `next` 指向原第一个结点（`p->next = q`），并将原第一个结点的 `next` 置空（`q->next = NULL`）。

💡 **为什么边界条件是 `if (L && L->next)`？**

- `L` 为真：防止链表为空（0个结点）。不带头结点的链表，`L == NULL` 即空表。
- `L->next` 为真：防止链表只有一个结点。如果只有一个结点（`a1 -> NULL`），把它移到末尾毫无意义，且找不到下一个结点了。
- 总结：该条件是为了保证链表至少包含两个结点。

### 二、 补充扩展：带头结点的单链表实现

如果链表是带头结点的，头结点（`L`）不存数据，不能被移动。代码逻辑会有细微调整：

```c
LinkList mynote_with_head(LinkList L) {
    // 前提：L 是头结点，L->next 才是第一个数据结点
    // 边界条件：至少有两个数据结点 (L->next 且 L->next->next)
    if (L->next && L->next->next) {
        q = L->next;          // q 指向第一个数据结点 (a1)
        L->next = q->next;    // 头结点跳过 a1，直接指向第二个数据结点 (a2)
        p = L->next;          // p 从 a2 开始遍历
        // S1: 找尾结点
        while (p->next) {
            p = p->next;
        }
        // S2: 拼接
        p->next = q;          // 尾结点指向 a1
        q->next = NULL;       // a1 置空，成为新尾结点
    }
    return L; // 带头结点的算法，头指针始终不变，返回 L 本身
}
```

### 三、 核心易混淆点辨析（重点！）

| 操作目的 | 不带头结点 (L 指向首元结点) | 带头结点 (L 指向头结点) |
| :--- | :--- | :--- |
| 判断链表为空 | `if (L == NULL)` | `if (L->next == NULL)` |
| 判断至少有两个结点 | `if (L != NULL && L->next != NULL)` | `if (L->next != NULL && L->next->next != NULL)` |
| 算法返回的指针 | 返回新的首元结点 (原 `L->next`) | 返回头结点 (L 保持不变) |

### 四、 复杂度分析与避坑指南

- **时间复杂度**：`O(n)`。需要遍历整个链表找到尾结点。
- **空间复杂度**：`O(1)`。只使用了 `p` 和 `q` 两个辅助指针，没有开辟新结点。

⚠️ **避坑指南（考试/写代码常错点）**

- **忘记置空 `q->next = NULL`**：这是最致命的错误！如果不置空，新链表的尾结点（a1）仍然指向原来的第二个结点（a2），会导致链表成环，后续遍历会死循环。
- **指针丢失**：必须先执行 `q = L` 保存首结点，再执行 `L = L->next` 移动头指针，否则原首结点就找不到了。
- **混淆返回值**：在不带头结点的实现中，`return L` 返回的是已经移动后的 `L`（即原链表的 `a2`）。

## 📂 算法二：字符串操作 —— 利用递归实现字符串逆序（翻转）

### 📌 原题重现

**阅读下列程序，并回答问题：**

```c
// 1. 辅助函数：截取子串
void substr(char *t, char *s, int pos, int len)
{
    while (len > 0 && *s)  // 只要还需截取长度大于0，且源串未到结尾
    {
        *t = *(s + pos - 1); // 核心：取源串偏移 pos-1 位置的字符，赋给目标串
        t++;                 // 目标指针后移，准备接收下一个字符
        s++;                 // 源指针后移
        len--;               // 截取长度减 1
    }
    *t = '\0';               // 截取完毕，给目标串末尾封口
}
// 2. 核心函数：递归翻转
char *func(char *s)
{
    char t[100];             // 局部数组，用于暂存每次剥离下来的首字符
    if (strlen(s) <= 1) return s; // 递归终止条件：长度<=1直接返回
    substr(t, s, 1, 1);      // 步骤A：把 s 的第1个字符摘出来，存入 t
    substr(s, s, 2, strlen(s) - 1); // 步骤B：把 s 从第2个字符开始的剩余部分，覆盖回 s（相当于掐头）
    func(s);                 // 步骤C：递归处理剩下的字符串 s
    return strcat(s, t);     // 步骤D：回溯时，把暂存的 t 拼接在 s 的末尾
}
// 3. 主函数
main()
{
    char str[100] = "String";
    printf("%s\n", func(str)); // 输出结果
}
```

**问题 (1)**：简述函数 substr 和 func 的功能；
**问题 (2)**：若执行 main 函数，程序的输出结果是什么？

### ✅ 标准答案

**(1) 函数功能：**

- **substr 函数的功能**：字符串截取。从源字符串 `s` 的第 `pos` 个位置开始，截取长度为 `len` 的子串，存入目标数组 `t` 中。
- **func 函数的功能**：利用递归算法，将传入的字符串进行逆序（翻转）。

**(2) 输出结果：**

`gnirtS`

### 💡 原题代码逻辑拆解（白话版）

- **substr 是一把剪刀**：`substr(t, s, 1, 1)` 剪下首字母存到 `t`；`substr(s, s, 2, strlen(s) - 1)` 把原字符串从第2个位置开始的剩余部分，直接覆盖写回 `s` 的开头（相当于砍掉首字母）。
- **func 是包工头**：每次拿到字符串，先把首字母摘下来存好，剩下的字符串"掐头"后，接着调用自己去处理。等递归到底层（只剩一个字符），开始往上回溯，把之前存好的首字母依次拼接到末尾，从而实现逆序。

### 一、 算法功能与核心思想

- **功能**：将输入的字符串进行逆序（首尾颠倒）。
- **核心思想（分治法/递归）**：
  - **拆解**：每次把字符串的"首字符"单独摘下来存好，剩下的字符串"掐头"后形成一个新的短字符串。
  - **递归**：拿着剩下的短字符串继续执行同样的操作，直到剩下最后 1 个字符（递归终止）。
  - **归并**：从最底层开始返回，把之前摘下来的首字符依次"拼接"到返回结果的末尾。

### 二、 辅助函数 substr 深度解析

**参数定义**：

- `t`：目标数组（存到哪里）
- `s`：源字符串（从哪里截）
- `pos`：起始位置（人类习惯从 1 开始数，代码内做了 `pos - 1` 转换）
- `len`：截取长度

**在本算法中的两种巧妙用法**：

- **切片（拿首字符）**：`substr(t, s, 1, 1);` 从 s 的第 1 个位置，截取 1 个字符，放到 t 里。
- **自我覆盖（掐头）**：`substr(s, s, 2, strlen(s) - 1);` 参数 `t` 和 `s` 传的是同一个地址！从 s 的第 2 个位置开始，截取剩下的所有字符，直接覆盖写回 s 的开头。这等于把原字符串的首字符删掉了，后面的字符整体前移。

### 三、 核心函数 func 的递归执行流程（以 "String" 为例）

- **第 1 层**：`s = "String"` 摘出 `t = "S"`。剩下 s 覆盖为 `"tring"`。调用 `func("tring")`（等待底层返回）。
- **第 2 层**：`s = "tring"` 摘出 `t = "t"`。剩下 s 覆盖为 `"ring"`。调用 `func("ring")`（等待底层返回）。
- …（层层深入，直到第 6 层）
- **第 6 层**：`s = "g"` 长度为 1，触发终止条件，直接返回 `"g"`。

**开始回溯（拼装）**：

- 第 5 层：`strcat("g", "n")` 返回 `"gn"`。
- 第 4 层：`strcat("gn", "i")` 返回 `"gni"`。
- 第 3 层：`strcat("gni", "r")` 返回 `"gnir"`。
- 第 2 层：`strcat("gnir", "t")` 返回 `"gnirt"`。
- 第 1 层：`strcat("gnirt", "S")` 返回 `"gnirtS"`。

### 四、 避坑指南（易错点）

- **substr 函数内部的指针递增**：由于 `while` 循环里每次执行了 `s++`，这意味着每次取字符时基准点都在变。因此 `*(s + pos - 1)` 中的 `pos - 1` 实际上是一个"相对偏移"。如果传入的 `pos` 很大（比如 `pos=5`），随着 `s++`，实际取到的字符会越界或跳跃。这段代码之所以能运行，是因为传入的 `pos` 只有 1 和 2，恰好配合了逻辑。
- **局部数组 `t` 的作用域**：`char t[100];` 定义在 `func` 内部，每一次递归调用都会在内存栈上开辟一个新的 `t` 数组，互不干扰。这就是为什么每一层都能安全存下自己那一层摘下来的首字母。
- **字符串结束符 `\0`**：`substr` 的最后一句 `*t = '\0';` 绝对不能漏。如果不加，`strcat` 拼接时找不到截断点，会导致输出乱码甚至程序崩溃。

## 📂 算法三：队列操作 —— 队列元素按条件分流（拆分）

### 📌 原题重现

阅读下列算法，并回答问题：（注：`InitQueue`、`EnQueue`、`DeQueue` 和 `QueueEmpty` 分别是队列初始化、入队、出队和判队空的操作）

```c
void func(Queue *Q, Queue *Q1, Queue *Q2)
{
    int e;
    InitQueue(Q1); // 初始化队列 Q1
    InitQueue(Q2); // 初始化队列 Q2
    // 当队列 Q 不为空时，不断循环
    while (!QueueEmpty(Q))
    {
        e = DeQueue(Q);   // 从队列 Q 中出队一个元素，赋值给 e
        if (e >= 0)
            EnQueue(Q1, e); // 如果 e 大于等于 0，将 e 入队到 Q1
        else
            EnQueue(Q2, e); // 如果 e 小于 0，将 e 入队到 Q2
    }
}
```

- **问题 (1)**：`Q`、`Q1` 和 `Q2` 都是队列结构，设队列 `Q = (2, 0, -8, 5, -3, -7, 6)`（其中 `2` 为队头元素），写出执行 `func(&Q, &Q1, &Q2)` 之后队列 `Q`、`Q1` 和 `Q2` 的状态；
- **问题 (2)**：简述算法 `func` 的功能。

### ✅ 标准答案

**(1) 执行后的状态**：

- `Q = ()`（队列变为空）
- `Q1 = (2, 0, 5, 6)`
- `Q2 = (-8, -3, -7)`

**(2) 算法功能**：

将队列 `Q` 中的所有元素依次出队，并根据元素的值进行分流：大于等于 `0` 的元素依次入队到 `Q1`，小于 `0` 的元素依次入队到 `Q2`。该操作保持了元素在原队列中的相对顺序。执行完毕后，原队列 `Q` 变为空队列。

### 💡 原题代码逻辑拆解（白话版）

这就好比过安检。`Q` 是排队的人群，`Q1` 和 `Q2` 是两条不同的通道。保安（`while` 循环）每次让队伍最前面的一个人出列（`DeQueue`），看一眼他带的行李（`e`）。如果没有违禁品（`e >= 0`），就让他去 `Q1` 通道重新排队；如果有违禁品（`e < 0`），就让他去 `Q2` 通道重新排队。直到原来的人群全部分流完毕，原队伍 `Q` 就空了。

### 一、 算法深度解析

**1. 为什么队列出队后，入队到新队列的顺序不变？**

因为队列的特性是"先进先出 (FIFO)"。题目中给出的 `Q` 是 `(2, 0, -8, 5, -3, -7, 6)`，`2` 是队头。循环时，一定是先出队 `2`，再出队 `0`，再出队 `-8`……对于 `Q1`，它是先收到 `2`，再收到 `0`，再收到 `5`，再收到 `6`。入队的顺序决定了出队的顺序，所以 `Q1` 的状态自然就是 `(2, 0, 5, 6)`，顺序并没有打乱。对于 `Q2` 同理。

**2. 代码执行步骤推演**

| 步骤 | 从 Q 出队的元素 e | 判断 e >= 0 | 操作 | Q1 状态 | Q2 状态 | Q 状态（出队后） |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 初始 | — | — | — | `()` | `()` | `(2, 0, -8, 5, -3, -7, 6)` |
| 1 | `2` | 是 | 入队 Q1 | `(2)` | `()` | `(0, -8, 5, -3, -7, 6)` |
| 2 | `0` | 是 | 入队 Q1 | `(2, 0)` | `()` | `(-8, 5, -3, -7, 6)` |
| 3 | `-8` | 否 | 入队 Q2 | `(2, 0)` | `(-8)` | `(5, -3, -7, 6)` |
| 4 | `5` | 是 | 入队 Q1 | `(2, 0, 5)` | `(-8)` | `(-3, -7, 6)` |
| 5 | `-3` | 否 | 入队 Q2 | `(2, 0, 5)` | `(-8, -3)` | `(-7, 6)` |
| 6 | `-7` | 否 | 入队 Q2 | `(2, 0, 5)` | `(-8, -3, -7)` | `(6)` |
| 7 | `6` | 是 | 入队 Q1 | `(2, 0, 5, 6)` | `(-8, -3, -7)` | `()`（空） |

### 二、 复杂度分析与避坑指南

- **时间复杂度**：`O(n)`。假设队列 `Q` 中有 `n` 个元素，`while` 循环需要执行 `n` 次，每次出队和入队的时间复杂度都是 `O(1)`。
- **空间复杂度**：`O(n)`。使用了两个额外的队列 `Q1` 和 `Q2`，它们总共存储了原队列中的所有 `n` 个元素。

⚠️ **避坑指南**：

- **注意队列的 FIFO 特性**：在写结果的时候，千万不要把顺序写反。很多同学可能会下意识地把 `Q1` 写成 `(6, 5, 0, 2)`（这是栈的特性），一定要牢记队列是先进先出，入队顺序即最终状态顺序。
- **别忘了判空**：`while (!QueueEmpty(Q))` 意味着只要 `Q` 里面还有元素就继续，最终 `Q` 一定会变成空队列。在回答 `Q` 的状态时，不要忘记写 `Q = ()`。

### ✅ 标准答案（填空补全）

- ② `R[mi].key == x.key`
- ③ `mi + 1`

### 💡 原题代码逻辑拆解（白话版）

折半插入排序，本质就是**打扑克牌**。左手里的牌**已经排好序**，右手摸到一张**新牌**。找位置的时候不用挨个比，直接看左手里**最中间**的那张牌。比它小就往左边找，比它大就往右边找。**每次砍掉一半的范围**。找到坑位后，把后面的牌统统往后挪一格，把新牌塞进去。

### 一、 完整代码 + 下标级注释（复习专用）

大前提：`lo`、`hi`、`mi`、`k`、`j` 全部代表数组的下标（第几个位置）。

```c
void InsertSort(SeqList R[], int n)
{
    SeqList x;          // 【暂存新牌】用来装当前要插入的那个元素
    // === 核心下标变量集合 ===
    int j, k, lo, hi, mi;
    //  lo: 左边界下标
    //  hi: 右边界下标
    //  mi: 中间位置下标
    //  k : 最终确定的插入位置下标
    //  j : 负责挪牌搬运工的下标
    // 默认第1个元素 R[1] 已经排好序，从第2个元素（i=2）开始往后遍历插入
    for (int i = 2; i <= n; i++)
    {
        x = R[i];       // 【拿牌】把第 i 个位置的元素抽出来，拿在手里（x）
        // 【1. 划定查找范围（都是下标）】
        lo = 1;         // 查找范围的左边界下标 = 1（有序区第一个元素）
        hi = i - 1;     // 查找范围的右边界下标 = i-1（有序区最后一个元素）
        // 【2. 二分法找位置（不断缩小下标范围）】
        while (lo <= hi) // 只要左下标还没超过右下标，说明范围里还有牌
        {
            mi = (lo + hi) / 2;  // 【算中间下标】左右下标相加除以2
            // 目标元素和中间元素的对比
            if (R[mi].key == x.key) break; // 相等，放中间，结束循环
            if (R[mi].key > x.key)
                hi = mi - 1;     // 中间牌 > 新牌：说明在左半边，把【右边界下标】缩到 mi 左边一格
            else
                lo = mi + 1;     // 中间牌 < 新牌：说明在右半边，把【左边界下标】扩到 mi 右边一格
        }
        // 【3. 确定最终要插在哪个下标（坑位 k）】
        if (mi <= lo)
            k = lo + 1;      // 算出来的插入坑位下标
        else
            k = mi - 1;      // ⚠️ 原题笔误，应付考试照填即可
        // 【4. 腾空位（往后挪数据）】
        // 搬运工 j 从有序区最后一个元素的下标(i-1)开始，一直向左退到坑位下标 k
        for (j = i - 1; j >= k; j--)
            R[j + 1] = R[j];   // 把下标 j 的数据，往后挪一格放到下标 j+1 的位置上
        // 【5. 插入】
        R[k] = x;            // 把手里暂存的新牌 x，放进空出来的下标 k 里
    }
}
```

### 二、 考场极速抢分口诀（必背）

**填空找位置三连**：

- 遇大往左缩：`hi = mi - 1;`
- 遇小往右扩：`lo = mi + 1;`
- 相等直接溜：`if (R[mi].key == x.key) break;`

**代码填空必背**：

- 拿牌：`x = R[i];`（填空 ①）
- 往后挪：`for (j = i - 1; j >= k; j--) R[j + 1] = R[j];`（填空 ⑥ 必考 `i - 1`）

**时间复杂度（常考选择题）**：

- **比较次数**：比普通插入排序少（因为用了二分砍半）。
- **移动次数**：和普通插入排序一模一样（找完位置，还得老老实实挪牌）。
- **总时间复杂度**：依然是 `O(n²)`（挪牌太费劲了）。
- **空间复杂度**：`O(1)`。
