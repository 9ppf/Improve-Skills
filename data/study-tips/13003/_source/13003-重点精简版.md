## 一、数据结构基础（必考）

### 1. 基本概念
- **数据结构**：相互之间存在一种或多种特定关系的数据元素的集合。
- **逻辑结构**：数据元素间的抽象关系（线性、树形、图形、集合）。
- **存储结构**：数据在计算机中的表示（顺序、链式、索引、散列）。
- **算法**：对特定问题求解步骤的描述，是指令的有限序列。
- **算法特性**：有穷性、确定性、可行性、输入、输出。

### 2. 算法评价
- **时间复杂度**：估算算法执行时间，记为 `T(n) = O(f(n))`。
- **常见复杂度（从优到劣）**：`O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(2ⁿ)`。
- **空间复杂度**：估算算法所需存储空间。

## 二、线性表（核心）

### 1. 顺序表（数组实现）
- **特点**：逻辑相邻，物理也相邻；随机存取（下标访问）。
- **优点**：存取速度快。
- **缺点**：插入、删除需移动大量元素，效率低（O(n)）；静态分配，容量固定。
- **基本操作**：插入、删除、查找、遍历。

### 2. 链表（指针实现）
- **特点**：逻辑相邻，物理不一定相邻；顺序存取（需从头遍历）。
- **优点**：插入、删除方便（O(1)，仅改指针）；动态分配，无容量限制。
- **缺点**：存取慢，需遍历；占用额外空间存指针。
- **分类**：
  - **单链表**：每个结点含数据域 + 后继指针。
  - **双链表**：每个结点含数据域 + 前驱指针 + 后继指针（方便反向遍历）。
  - **循环链表**：尾结点指针指向头结点，形成环。
- **基本操作**：创建、插入、删除、查找、遍历、逆置。

### 3. 顺序表 vs 链表

| 特性 | 顺序表 | 链表 |
| :--- | :--- | :--- |
| 存取 | 随机存取，O(1) | 顺序存取，O(n) |
| 插入 / 删除 | 需移动元素，O(n) | 改指针，O(1) |
| 空间 | 静态分配，可能浪费 | 动态分配，无浪费 |
| 适用 | 频繁查找，少增删 | 频繁增删，少查找 |

## 三、栈和队列（重点）

### 1. 栈（Stack）
- **定义**：限定仅在表尾（栈顶）进行插入和删除操作的线性表。
- **特点**：后进先出（LIFO）。
- **存储**：顺序栈（数组）、链栈（链表）。
- **基本操作**：入栈（push）、出栈（pop）、取栈顶（top）、判空。
- **应用**：函数调用、表达式求值（后缀 / 逆波兰）、括号匹配、递归实现、迷宫求解。

### 2. 队列（Queue）
- **定义**：限定仅在表尾（队尾）插入，在表头（队头）删除的线性表。
- **特点**：先进先出（FIFO）。
- **存储**：顺序队列（数组，需解决假溢出）、循环队列、链队列。

### 3. 循环队列
- **判空**：`front == rear`。
- **判满**：`(rear+1) % MaxSize == front`（牺牲一个单元）。
- **基本操作**：入队（enqueue）、出队（dequeue）、取队头、判空。
- **应用**：缓冲区、打印队列、广度优先搜索（BFS）。

## 四、串、数组和广义表（基础）

### 1. 串（String）
- **定义**：零个或多个字符组成的有限序列。
- **基本操作**：赋值、连接、求长度、比较、子串定位（模式匹配）。
- **模式匹配**：
  - 朴素算法：O(n*m)。
  - KMP 算法：O(n+m)，利用 **部分匹配表（next 数组）** 避免回溯，效率高。

### 2. 数组
- **定义**：按一定格式排列的相同类型数据元素的集合。
- **存储**：行优先（C 语言）、列优先。
- **矩阵压缩**：对称矩阵、三角矩阵、稀疏矩阵（三元组表、十字链表）。

## 五、树与二叉树（重中之重）

### 1. 树的基本概念
- 结点、度、叶子、双亲、孩子、兄弟、层次、深度、高度。
- **树的度**：所有结点度的最大值。
- **树的深度**：根结点到最远叶子结点的层数。

### 2. 二叉树（Binary Tree）
- **定义**：每个结点最多有两棵子树（左、右），子树有左右之分。
- **性质（必考）**：
  - 第 i 层最多有 `2^(i-1)` 个结点。
  - 深度为 k 的二叉树最多有 `2^k - 1` 个结点。
  - 叶子结点数 `n₀ = 度为 2 的结点数 n₂ + 1`。
  - 具有 n 个结点的完全二叉树深度为 `⌊log₂n⌋ + 1`。
- **特殊二叉树**：
  - **满二叉树**：每层都满，深度 k 有 `2^k - 1` 个结点。
  - **完全二叉树**：除最后一层外，其余层满；最后一层结点靠左排列。
- **存储**：
  - 顺序存储：适合完全二叉树（数组）。
  - 链式存储：二叉链表（数据域 + 左指针 + 右指针），最常用。

### 3. 二叉树遍历（核心）
- **先序遍历**：根 → 左 → 右。
- **中序遍历**：左 → 根 → 右。
- **后序遍历**：左 → 右 → 根。
- **层序遍历**：按层次从上到下、从左到右（用队列实现）。
- **考点**：已知两种遍历序列（含中序），可唯一确定二叉树。

### 4. 二叉树应用
- **线索二叉树**：利用空指针存前驱 / 后继，方便遍历。
- **二叉排序树（BST）**：左子树值 < 根值 < 右子树值，查找效率 O(logn)。
- **哈夫曼树（最优二叉树）**：
  - 带权路径长度（WPL）最小。
  - 构造：每次选两个最小权值结点合并。
  - 应用：哈夫曼编码（数据压缩，前缀码，无歧义）。

## 六、图（重点）

### 1. 图的基本概念
- 顶点、边、有向图（弧）、无向图、网（带权图）、度、入度、出度、路径、环、连通图、强连通图、生成树。

### 2. 图的存储
- **邻接矩阵**：二维数组，`A[i][j]` 表示 i 到 j 的边 / 权。
  - 优点：直观，易查边。
  - 缺点：空间浪费（稀疏图）。
- **邻接表**：数组 + 链表，每个顶点对应一个链表，存邻接点。
  - 优点：省空间（适合稀疏图）。
  - 缺点：查边麻烦。

### 3. 图的遍历
- **深度优先搜索（DFS）**：
  - 思想：一路到底，再回溯。
  - 实现：递归 / 栈。
  - 时间：邻接矩阵 O(n²)，邻接表 O(n+e)。
- **广度优先搜索（BFS）**：
  - 思想：逐层遍历，先近后远。
  - 实现：队列。
  - 时间：同 DFS。

### 4. 图的应用
- **最小生成树（MST）**：
  - 普里姆（Prim）算法：选顶点，适合稠密图，O(n²)。
  - 克鲁斯卡尔（Kruskal）算法：选边，适合稀疏图，O(eloge)。
- **最短路径**：
  - 迪杰斯特拉（Dijkstra）：单源最短路径，非负权，O(n²)。
  - 弗洛伊德（Floyd）：所有顶点对最短路径，O(n³)。
- **拓扑排序**：有向无环图（DAG），按先后顺序排列顶点，判断工程可行性。
- **关键路径**：AOE 网，求最长路径，决定工程最短工期。

## 七、查找（Search）

### 1. 静态查找（无增删）
- **顺序查找**：逐个比较，O(n)，对表无要求。
- **折半查找（二分查找）**：
  - 要求：有序顺序表。
  - 思想：每次比较中间元素，缩小查找范围。
  - 时间：O(logn)。

### 2. 动态查找（有增删）
- **二叉排序树（BST）**：平均 O(logn)，最坏 O(n)（退化为链表）。
- **平衡二叉树（AVL）**：左右子树高度差 ≤ 1，查找、插入、删除均 O(logn)。
- **B - 树 / B + 树**：多路平衡查找树，用于数据库、文件系统。

### 3. 散列查找（Hash）
- **散列函数**：将关键字映射为地址（如除留余数法 `H(key)=key%p`）。
- **冲突处理**：
  - 开放定址法：线性探测、二次探测。
  - 链地址法（拉链法）：同一地址用链表链接，最常用。
- **特点**：平均查找时间 O(1)，效率最高。

## 八、排序（Sorting）（重中之重）

### 1. 排序分类
- **内部排序**：数据在内存。
- **外部排序**：数据在外存（磁盘），常用归并排序。

### 2. 内部排序算法（必背）

| 算法 | 基本思想 | 时间复杂度 | 空间复杂度 | 稳定性 |
| :--- | :--- | :--- | :--- | :--- |
| 直接插入 | 逐个插入有序区 | 最好O(n)，平均 / 最坏O(n²) | O(1) | 稳定 |
| 希尔排序 | 分组插入，逐步缩小增量 | O(n^1.3)~O(n²) | O(1) | 不稳定 |
| 冒泡排序 | 相邻比较，大的下沉 | 最好O(n)，平均 / 最坏O(n²) | O(1) | 稳定 |
| 快速排序 | 选基准，分治递归 | 最好 / 平均O(nlogn)，最坏O(n²) | O(logn)~O(n) | 不稳定 |
| 简单选择 | 选最小放有序区 | 始终O(n²) | O(1) | 不稳定 |
| 堆排序 | 建堆，选堆顶，调整 | 始终O(nlogn) | O(1) | 不稳定 |
| 归并排序 | 分治，两两归并 | 始终O(nlogn) | O(n) | 稳定 |
| 基数排序 | 按位分配收集 | O(d(n+r)) | O(n+r) | 稳定 |

### 3. 核心考点
- **稳定性**：相同关键字排序后相对位置不变（稳定：插入、冒泡、归并、基数）。
- **适用场景**：
  - 数据基本有序：直接插入、冒泡。
  - 数据量大、无序：快速、堆、归并。
  - 内存有限：堆排序（O(1)空间）。
  - 要求稳定：归并、基数。

## 九、高频考点速记清单
- 时间复杂度：`O(1) < O(logn) < O(n) < O(nlogn) < O(n²)`。
- 线性表：顺序表（随机存取）、链表（增删快）。
- 栈：LIFO；队列：FIFO；循环队列判满：`(rear+1)%MaxSize == front`。
- 二叉树性质：`n₀ = n₂ + 1`；遍历：先 / 中 / 后 / 层序。
- 哈夫曼树：WPL 最小；哈夫曼编码：前缀码。
- 图：邻接矩阵（稠密）、邻接表（稀疏）；DFS（栈）、BFS（队列）。
- 最小生成树：Prim（稠密）、Kruskal（稀疏）；最短路径：Dijkstra、Floyd。
- 查找：二分（有序）、散列（O(1)）。
- 排序：快排 / 堆排 / 归并 O(nlogn)；插入 / 冒泡 / 选择 O(n²)；归并 / 基数稳定。

## 十、易错点提醒
- 链表插入 / 删除：注意指针修改顺序，防止断链。
- 二叉树遍历：先 / 后序 + 中序可确定树，先 + 后不行。
- 图的邻接矩阵：无向图对称，有向图不一定。
- 快速排序：最坏情况（已序）退化为 O(n²)，需优化（随机选基准）。
- 堆排序：建堆 O(n)，调整 O(logn)，总 O(nlogn)。
- 散列冲突：链地址法优于开放定址法，无堆积问题。
- 稳定性：仅与算法有关，与数据无关。
