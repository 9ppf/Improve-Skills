# 单射、满射、双射（函数）

## 1. 基本定义

设函数 `f: X → Y`。

### 单射（injective）

若对任意 `x1, x2 ∈ X`，当 `x1 ≠ x2` 时，都有 `f(x1) ≠ f(x2)`，则称 `f` 是**单射**。

通俗说：**不同的输入，一定得到不同的输出。**

### 满射（surjective）

若对任意 `y ∈ Y`，都存在 `x ∈ X`，使得 `f(x) = y`，则称 `f` 是**满射**。

通俗说：**`Y` 中每个元素都至少被 `X` 中某个元素映到。**

### 双射（bijective）

若 `f` 既是单射又是满射，则称 `f` 是**双射**。

通俗说：**`X` 与 `Y` 中的元素一一对应。**

### 映射（函数）的基本要求

`f: X → Y` 是映射，需要满足：

1. `X` 中每个元素都有像
2. 每个元素的像唯一

## 2. 有限集判断要点

设 `|X|` 表示集合 `X` 的元素个数。

| 条件 | 结论 |
|---|---|
| `card(X) > card(Y)` | 不可能存在从 `X` 到 `Y` 的**单射** |
| `card(X) < card(Y)` | 不可能存在从 `X` 到 `Y` 的**满射** |
| 存在从 `X` 到 `Y` 的双射 | 必有 `card(X) = card(Y)` |

## 3. 第7题原题与解析

### 题目

设 `X = {1, 2, 3, 4}`，`Y = {5, 6, 7, 8, 9}`，给定 `f = {<1,5>, <2,6>, <3,7>, <4,8>}`。

下列选项中正确的是：

- A. `f` 是从 `X` 到 `Y` 的单射
- B. `f` 是从 `X` 到 `Y` 的满射
- C. `f` 是从 `X` 到 `Y` 的双射
- D. `f` 不是从 `X` 到 `Y` 的映射（函数）

### 解析

- `X` 中每个元素 `1, 2, 3, 4` 都有唯一的像，所以 `f` 是**映射**
- 像分别为 `5, 6, 7, 8`，互不相同，所以 `f` 是**单射**
- `Y` 中的元素 `9` 没有原像，所以 `f` **不是满射**
- 因为不是满射，所以也**不是双射**

**答案：A**

## 4. 单射例子

### 例子

设 `X = {1, 2, 3}`，`Y = {10, 20, 30, 40}`，定义 `f = {<1,10>, <2,20>, <3,30>}`。

### 分析

- 每个 `X` 中的元素都有唯一的像
- 像 `10, 20, 30` 两两不同，所以 `f` 是**单射**
- `Y` 中的 `40` 没有原像，所以 `f` **不是满射**
- 因此 `f` **不是双射**
- `f` 是从 `X` 到 `Y` 的**映射**

## 5. 从 `Y` 到 `X` 的单射问题

若 `X = {1, 2, 3, 4}`，`Y = {5, 6, 7, 8, 9}`，考虑从 `Y` 到 `X` 的单射。

因为 `|Y| = 5 > 4 = |X|`，根据**鸽巢原理**，从 `Y` 到 `X` 不可能存在单射。

因此**不存在**从 `Y` 到 `X` 的单射函数。

## 6. 双射例子

### 例子

设 `X = {1, 2, 3, 4}`，`Y = {5, 6, 7, 8}`，定义 `f = {<1,5>, <2,6>, <3,7>, <4,8>}`。

### 分析

- 每个 `X` 中的元素都有唯一的像
- 像 `5, 6, 7, 8` 互不相同，所以 `f` 是**单射**
- `Y` 中每个元素都有原像：`5←1, 6←2, 7←3, 8←4`，所以 `f` 是**满射**
- 因为 `f` 既是单射又是满射，所以 `f` 是**双射**

## 7. 总结口诀

| 名称 | 口诀 |
|---|---|
| 单射 | 不同输入，不同输出 |
| 满射 | 每个输出都至少被一个输入对应 |
| 双射 | 单射 + 满射，一一对应 |
| 映射 | 每个输入都有且只有一个输出 |
