# 二元关系的常见性质（自反/反自反/对称/反对称/传递）

> 说明：这里说的「集合的常见性质」，实际指集合 `A` 上的二元关系 `R ⊆ A × A` 的常见性质。

## 一、核心概念与前提条件

**二元关系定义**：给定论域 `A`，关系 `R` 是有序对集合，`R ⊆ A × A`。

**适用前提**：

- 必须先明确论域 `A` 中有哪些元素
- 判断性质时只看 `R` 中实际出现的有序对
- 自反性、反自反性都要对 `A` 中**每一个元素**检查

### 五性质速查表

| 性质 | 定义 | 判断要点 |
|---|---|---|
| 自反性 | 对任意 `a ∈ A`，`<a, a> ∈ R` | 每个元素都必须有自环 |
| 反自反性 | 对任意 `a ∈ A`，`<a, a> ∉ R` | 不能有任何自环 |
| 对称性 | 若 `<a, b> ∈ R`，则 `<b, a> ∈ R` | 每个有序对都要有反向对 |
| 反对称性 | 若 `<a, b> ∈ R` 且 `<b, a> ∈ R`，则 `a = b` | 不同元素之间不能双向同时出现 |
| 传递性 | 若 `<a, b> ∈ R` 且 `<b, c> ∈ R`，则 `<a, c> ∈ R` | 有两步路径，就必须有「一步捷径」 |

### 易混淆对比

| 性质 | 关键区别 |
|---|---|
| 对称性 | 允许不同元素之间**双向出现** |
| 反对称性 | **不允许**不同元素之间双向出现，但**允许自环** |
| 自反性 | 要求**所有自环都有** |
| 反自反性 | 要求**所有自环都没有** |

## 二、通用做题步骤

### 第一步：列论域和关系

- 写出 `A` 中所有元素
- 列出 `R` 中所有有序对
- 标出所有自环 `<a, a>` 和所有双向对 `<a, b>, <b, a>`

### 第二步：逐性质检查

| 性质 | 检查方法 | 不满足条件 |
|---|---|---|
| 自反性 | 检查 `A` 中每个元素 `a`，是否都有 `<a, a> ∈ R` | 缺一个就不自反 |
| 反自反性 | 检查 `R` 中是否完全没有自环 | 只要有一个自环就不反自反 |
| 对称性 | 对每个 `<a, b> ∈ R`，检查 `<b, a>` 是否也在 `R` | 缺一个就不对称 |
| 反对称性 | 检查是否存在 `a ≠ b`，使得 `<a, b>` 和 `<b, a>` 同时属于 `R` | 存在就不反对称 |
| 传递性 | 列出所有两步链 `a → b → c`，检查是否都有捷径 `<a, c>` | 缺一个就不传递 |

### 第三步：结束条件

- 每个性质**独立判断**
- 一个关系可以同时具有多个性质，也可能一个都不具有
- **没有两步路径时，传递性自动满足**

## 三、进阶考点与核心推导

### 1. 关系矩阵视角

设 `A = {a1, a2, ..., an}`，关系矩阵 `M_R` 中第 `i` 行第 `j` 列为 1 表示 `<a_i, a_j> ∈ R`。

| 性质 | 矩阵特征 |
|---|---|
| 自反性 | 主对角线**全为 1** |
| 反自反性 | 主对角线**全为 0** |
| 对称性 | 矩阵关于主对角线**对称** |
| 反对称性 | 非主对角线位置**不能同时出现对称的 1** |
| 传递性 | 若 `M_R²` 中某位置为 1，则 `M_R` 对应位置也应为 1，即 `R² ⊆ R` |

### 2. 关系图视角

| 性质 | 图的特征 |
|---|---|
| 自反性 | 每个点都有自环 |
| 反自反性 | 没有点有自环 |
| 对称性 | 每条边都有反向边 |
| 反对称性 | 不同点之间不能有双向边 |
| 传递性 | 任意两步可达，必须一步直达 |

### 3. 特殊关系结论

设 `A ≠ ∅`：

| 关系 | 性质 |
|---|---|
| 空关系 `∅` | 反自反、对称、反对称、传递；**但不自反** |
| 全域关系 `A × A` | 自反、对称、传递；若 `card(A) > 1`，则**不反自反、不反对称** |
| 恒等关系 `I_A = {<a, a> | a ∈ A}` | 自反、对称、反对称、传递；**不反自反** |

### 4. 传递闭包

关系 `R` 的**传递闭包**是包含 `R` 的最小传递关系，可理解为把所有「两步路径」补成「一步捷径」，直到不再产生新有序对。

## 四、易错点总结（排雷区）

| 易错点（错误做法） | 正确做法（避坑指南） |
|---|---|
| 只看到一个自环，就说具有自反性 | 自反性要求论域中**每个元素**都有自环 |
| 看到有自环，就说一定不反自反 | 对，反自反性要求**完全没有自环**；有一个自环就不反自反 |
| 把对称性和反对称性混为一谈 | 对称允许不同元素双向；反对称不允许不同元素双向 |
| 认为反对称就是「不能有自环」 | 反对称**允许自环**，只禁止不同元素双向 |
| 传递性只检查明显的一条链 | 要检查**所有**两步链 `a → b → c`，逐一找 `a → c` |
| 没有两步路径时误判为不传递 | **没有两步路径时，传递性自动满足** |
| 忘记先看论域 `A` | 自反性、反自反性都与**论域中每个元素**有关 |

## 五、例题补充

### 例题 1：判断对称性（第 6 题）

**题目**：设 `A = {1, 2, 3, 4}`，下列关系 `R` 满足对称性的是（ ）

- A. `R = {<1,1>, <1,2>, <2,1>, <3,3>, <3,4>, <4,3>}`
- B. `R = {<1,2>, <1,3>, <2,1>, <2,3>, <3,4>, <4,3>}`
- C. `R = {<1,1>, <1,2>, <2,2>, <3,3>, <3,4>, <4,4>}`
- D. `R = {<1,2>, <2,2>, <3,3>, <3,4>, <4,3>, <4,4>}`

**解析**：

| 选项 | 关键有序对检查 | 结论 |
|---|---|---|
| A | 有 `<1,2>` 和 `<2,1>`，有 `<3,4>` 和 `<4,3>` | **满足对称性** |
| B | 有 `<1,3>`，但缺少 `<3,1>` | 不满足 |
| C | 有 `<1,2>`，但缺少 `<2,1>` | 不满足 |
| D | 有 `<1,2>`，但缺少 `<2,1>` | 不满足 |

**答案：A**

> 避坑提示：对称性不是看有没有自环，而是看每个有序对是否都有反向对。A 中所有非自环有序对都有反向对。

### 例题 2：自反性与反自反性判断

**题目**：设 `A = {1, 2, 3}`，判断下列关系：

- `R1 = {<1,1>, <2,2>, <3,3>}`
- `R2 = {<1,1>, <2,2>}`
- `R3 = {<1,2>, <3,2>, <1,3>}`
- `R4 = {<1,1>, <3,2>}`

**解析**：

- `R1`：三个元素都有自环，具有**自反性**；有自环，**不反自反**
- `R2`：缺少 `<3,3>`，**不具有自反性**；有自环，**不反自反**
- `R3`：没有任何自环，具有**反自反性**；也**不具有自反性**
- `R4`：有 `<1,1>`，**不具有反自反性**；缺少 `<2,2>, <3,3>`，也**不具有自反性**

**答案**：`R1` 自反；`R2` 不自反；`R3` 反自反；`R4` 既不自学也不反自反。

> 避坑提示：反自反性只要求「没有自环」，不要求必须有其他有序对。例如 `R = {<1,2>}` 也满足反自反性。

### 例题 3：反对称性判断

**题目**：设 `A = {1, 2, 3}`，判断：

- `R1 = {<1,1>, <2,2>, <3,3>, <1,2>}`
- `R2 = {<2,1>, <1,2>}`

**解析**：

- `R1`：只有 `<1,2>`，没有 `<2,1>`；自环不影响反对称性，所以**具有反对称性**
- `R2`：同时有 `<1,2>` 和 `<2,1>`，且 `1 ≠ 2`，所以**不具有反对称性**

**答案**：`R1` 具有反对称性；`R2` 不具有反对称性。

> 避坑提示：反对称性允许自环，也允许单向有序对，只禁止不同元素之间的双向对。

### 例题 4：传递性判断

**题目**：设 `A = {1, 2, 3, 4}`，下列关系 `R` 中具有传递性的是（ ）

- A. `R = {<1,2>, <2,3>, <1,3>, <3,4>}`
- B. `R = {<1,2>, <2,1>, <1,1>}`
- C. `R = {<1,2>, <2,3>, <3,1>, <1,3>}`
- D. `R = {<1,2>, <2,3>, <1,3>, <3,3>}`

**解析**：

- A：有 `2 → 3 → 4`，需要 `<2,4>`，但缺失，**不传递**
- B：有 `2 → 1 → 2`，需要 `<2,2>`，但缺失，**不传递**
- C：有 `2 → 3 → 1`，需要 `<2,1>`，但缺失，**不传递**
- D：检查所有两步链：
  - `1 → 2 → 3`，需要 `<1,3>`，有 ✅
  - `2 → 3 → 3`，需要 `<2,3>`，有 ✅
  - `1 → 3 → 3`，需要 `<1,3>`，有 ✅
  - `3 → 3 → 3`，需要 `<3,3>`，有 ✅
  所有两步链都有捷径，**具有传递性**

**答案：D**

> 避坑提示：传递性要检查**所有**两步路径，不能只看一条。

### 例题 5：去掉某些有序对后是否仍传递

**题目**：设 `R = {<1,2>, <2,3>, <1,3>, <3,3>}`。

去掉 `<3,3>` 后，`R' = {<1,2>, <2,3>, <1,3>}` 是否仍具有传递性？

再去掉 `<2,3>` 后，`R'' = {<1,2>, <1,3>}` 是否仍具有传递性？

**解析**：

- `R'` 中唯一的两步链是 `1 → 2 → 3`，需要 `<1,3>`，已有，所以**仍传递**。`3` 没有出边，不会产生新的两步链。
- `R''` 中没有两步链：`1` 能到 `2` 和 `3`，但 `2`、`3` 都没有出边，所以**传递性自动满足**。

**答案**：两种情况都仍具有传递性。

> 避坑提示：传递性不是「边越多越传递」，而是「有两步路径就必须有捷径」。没有两步路径时自动满足。

### 例题 6：综合判断

**题目**：设 `R = {<1,1>, <1,2>, <2,1>, <3,3>, <3,4>, <4,3>}`，判断其对称性、反对称性、传递性。

**解析**：

- **对称性**：`<1,2>` 与 `<2,1>` 成对，`<3,4>` 与 `<4,3>` 成对，**满足对称性**
- **反对称性**：存在 `1 ≠ 2` 但 `<1,2>, <2,1>` 同时出现，**不满足反对称性**
- **传递性**：有 `1 → 2 → 1`，需要 `<1,1>`，有；但 `2 → 1 → 2`，需要 `<2,2>`，没有，所以**不传递**

**答案**：对称，不反对称，不传递。

> 避坑提示：一个关系可以对称但不反对称；判断传递性时要检查反向边产生的两步链。

## 六、一句话记忆

> **自反看全自环，反自反看无自环；对称看反向，反对称禁双向；传递看两步有没有一步捷径。**
>
> **没有两步路径，传递性自动成立；有一个反例，性质就不成立。**
