# 二元运算的结合律

## 一、基本概念

### 1. 二元运算

题目中的 `*` 是**自定义运算符号**，不是普通乘法。运算规则由等式右边定义，例如：

- `x*y = x-y`：表示对两个数做减法
- `x*y = y`：表示结果取第二个数
- `x*y = x+2y`：表示第一个数加第二个数的 2 倍

> 注意：左边的 `*` 是运算名称，右边的表达式才是实际计算规则。

### 2. 结合律定义

设 `*` 是集合上的二元运算。若对集合中**任意**三个元素 x, y, z，恒有：

```
(x*y)*z = x*(y*z)
```

则称运算 `*` 满足结合律。

**关键**：结合律是关于**三个元素**运算顺序的规则，因此验证时必须引入第三个元素 `z`。

## 二、判断结合律的方法

### 方法 1：代数推导法

步骤：

1. 写出结合律等式 `(x*y)*z = x*(y*z)`
2. 先算左边括号内的 `x*y`，把结果与 `z` 按定义运算
3. 先算右边括号内的 `y*z`，把 `x` 与结果按定义运算
4. 化简左右两边，看是否恒等

### 方法 2：举反例法

若怀疑不满足结合律，找一组具体的 x, y, z 代入，使左右两边**不相等**即可否定。

> 对于无限集，反例法往往更高效；代数推导能直接证明是否恒等。

### 代入技巧

括号相当于一个**整体变量**，代入时运算规则中「第一个位置」和「第二个位置」的系数或处理方式不变。例如对 `x*y = x+2y`：

- `(x*y)*z = (x*y) + 2z`（把 `x*y` 整体放第一个位置，z 放第二个位置，第二个位置系数是 2）
- `x*(y*z) = x + 2(y*z)`（x 放第一个位置，`y*z` 整体放第二个位置）

## 三、常见运算的结合律结论（速查表）

| 运算 | 是否满足结合律 |
|---|---|
| 左投影 `x*y = x` | ✅ 满足 |
| 右投影 `x*y = y` | ✅ 满足 |
| 加法 `x*y = x+y` | ✅ 满足 |
| 乘法 `x*y = xy` | ✅ 满足 |
| 最大值 `x*y = max(x,y)` | ✅ 满足 |
| 最小值 `x*y = min(x,y)` | ✅ 满足 |
| 减法 `x*y = x-y` | ❌ 一般不满足 |
| 除法 | ❌ 一般不满足 |
| 绝对值差 `x*y = abs(x-y)` | ❌ 不满足 |
| 线性式 `x*y = x+2y` | ❌ 不满足 |

### 投影运算恒满足结合律（记住可秒杀）

**左投影** `x*y = x`：

```
(x*y)*z = x*z = x
x*(y*z) = x*y = x
```

**右投影** `x*y = y`：

```
(x*y)*z = y*z = z
x*(y*z) = x*z = z
```

## 四、例题：第 8 题

**题目**：在自然数集 N 上，下列运算中满足结合律的是

- A. `x*y = x-y`
- B. `x*y = y`
- C. `x*y = |x-y|`
- D. `x*y = x+2y`

### 逐项分析

**A.** `x*y = x-y`

```
(x*y)*z = (x-y)-z = x-y-z
x*(y*z) = x-(y-z) = x-y+z
```

一般不相等，且自然数集上减法可能不封闭。**不满足结合律。**

**B.** `x*y = y`（右投影）

```
(x*y)*z = y*z = z
x*(y*z) = x*z = z
```

恒相等。**满足结合律。**

**C.** `x*y = |x-y|`

取 x=1, y=2, z=3：

```
(1*2)*3 = |1-2|*3 = 1*3 = |1-3| = 2
1*(2*3) = 1*|2-3| = 1*1 = |1-1| = 0
```

2 ≠ 0，反例成立。**不满足结合律。**

**D.** `x*y = x+2y`

```
(x*y)*z = (x+2y)*z = x+2y+2z
x*(y*z) = x*(y+2z) = x+2(y+2z) = x+2y+4z
```

一般不相等。**不满足结合律。**

**答案：B**

## 五、练习题

### 练习 1

下列运算中，满足结合律的是

- A. `x*y = x+y+1`
- B. `x*y = x`
- C. `x*y = 2x+y`
- D. `x*y = max(x,y)`

**练习 1 解析**：

- A：

```
(x*y)*z = (x+y+1)+z+1 = x+y+z+2
x*(y*z) = x+(y+z+1)+1 = x+y+z+2
```

满足结合律。

- B：左投影，满足结合律。
- C：

```
(x*y)*z = (2x+y)*z = 2(2x+y)+z = 4x+2y+z
x*(y*z) = x*(2y+z) = 2x+2y+z
```

一般不相等，不满足。

- D：最大值运算满足结合律。

**答案：A、B、D**

### 练习 2

在自然数集上，下列运算满足结合律的是

- A. `x*y = x²+y`
- B. `x*y = x`（左投影）
- C. `x*y = 2x+2y`
- D. `x*y = |x+y|`

**练习 2 解析**：

- A：取 x=1, y=1, z=1，左边 = (1²+1)²+1 = 5，右边 = 1²+(1²+1) = 3，不相等，不满足。
- B：左投影，满足结合律。
- C：

```
(x*y)*z = 2(2x+2y)+2z = 4x+4y+2z
x*(y*z) = 2x+2(2y+2z) = 2x+4y+4z
```

一般不相等，不满足。

- D：在自然数集上 x+y ≥ 0，`|x+y| = x+y`，即普通加法，满足结合律。

**答案：B、D**

## 六、易错点与总结

1. `*` 是**自定义运算**，不要当作乘法
2. 验证结合律**必须引入第三个元素 z**
3. 括号内整体代入时，运算规则中第一个位置、第二个位置的处理方式不变
4. **左投影、右投影恒满足结合律**
5. 减法、除法、绝对值差、非对称线性式通常**不满足**结合律
6. 判断口诀：

> 结合律看三元素，左右两边分别算；
> 括号整体当变量，代入规则不能乱；
> 投影运算必满足，减法除法多反例。
