# 二叉树遍历（先根/中根/后根）

## 一、原题

分别使用**先根法、中根法、后根法**遍历下图的二叉树。

**树结构（文字描述）：**

- 根节点 **a**：左孩子 b（叶子），右孩子 c
- 节点 **c**：左孩子 d，右孩子 e（叶子）
- 节点 **d**：左孩子 f（叶子），右孩子 g（叶子）

## 二、核心概念（口诀）

三种遍历的区别只在于「**根节点**」被访问的先后顺序：

| 遍历方式 | 访问顺序 | 记忆点 |
|---|---|---|
| 先根遍历 | 根 → 左 → 右 | 根在最**前** |
| 中根遍历 | 左 → 根 → 右 | 根在**中**间 |
| 后根遍历 | 左 → 右 → 根 | 根在最**后** |

> **口诀**：看「根」在哪里。根在最前就是先根，根在中间就是中根，根在最后就是后根。

## 三、解题技巧（三阶拆解法）

切忌一上来就瞎背，必须依靠「**递归思想**」把大树拆成小树：

1. **找总根**：把整棵树当整体，找出根节点（本题是 a）
2. **拆分树**：顺着根节点向下，明确它的**左子树**和**右子树**各包含哪些节点
3. **套规则，逐个击破**：把左、右子树分别当做一棵**全新的树**，重复上述步骤；拆分过程中严格按口诀顺序拼接结果

### 进阶小技巧

- **外围轮廓线法**：想象笔沿二叉树外侧边缘逆时针画一圈——经过节点**左侧**时记录 → 先根；经过节点**下方**时记录 → 中根；经过节点**右侧**时记录 → 后根。
- **验证法**：先根序列的**第一个**节点、后根序列的**最后一个**节点，绝对是整棵树的根。
- **叶子节点规律**：叶子在先根和后根序列中的相对顺序通常一致（本题 b, f, g, e 都是叶子，可自行观察验证）。

## 四、本题详细解答

### 1. 先根法（根左右）

- 总根 **a** → 左子树（只有 b）→ 右子树（以 c 为根）
- 进入右子树：根 **c** → c 的左子树（根 **d** → 左 **f** → 右 **g**）→ c 的右子树（只有 **e**）

**遍历结果：`a, b, c, d, f, g, e`**

### 2. 中根法（左根右）

- 总根 a 的左子树（只有 **b**）→ 总根 **a** → 总根 a 的右子树
- 进入右子树：c 的左子树（左 **f** → 根 **d** → 右 **g**）→ 根 **c** → c 的右子树（只有 **e**）

**遍历结果：`b, a, f, d, g, c, e`**

### 3. 后根法（左右根）

- 总根 a 的左子树（只有 **b**）→ 总根 a 的右子树 → 总根 **a**
- 进入右子树：c 的左子树（左 **f** → 右 **g** → 根 **d**）→ c 的右子树（只有 **e**）→ 根 **c**

**遍历结果：`b, f, g, d, e, c, a`**

### 三种遍历结果对比

| 遍历方式 | 规则 | 结果序列 |
|---|---|---|
| 先根 | 根左右 | `a b c d f g e` |
| 中根 | 左根右 | `b a f d g c e` |
| 后根 | 左右根 | `b f g d e c a` |

> **自检**：先根首节点 = 后根尾节点 = 根节点 a ✅

## 五、高频延伸：已知两序求树

| 已知条件 | 能否唯一确定二叉树 |
|---|---|
| 先根 + 中根 | ✅ 可以 |
| 后根 + 中根 | ✅ 可以 |
| 先根 + 后根 | ❌ **不行**（无法区分独生子是左孩子还是右孩子） |

**做法**：用先根的第一个（或后根的最后一个）在中根序列中**找根**，把中根序列一分为二（左边是左子树，右边是右子树），然后对左右两部分不断重复此过程，直到拆完。
